## 路線與地圖

- 玄壤深淵 `(28,50)` 的深裂口接往薪盡坡，再由南側道路到燼燈坊。
- 每境四圖串接，末圖回到同境城鎮；城鎮南端通向下一境第一圖。
- 所有跨圖口採手動觸發並提供回返道路。入口標示建議等級；現有傳送系統沒有新增故事或境界門禁。
- 城鎮為 `48×40`，野外為 `64×48`，保留分層地形、岔路、頭目場地、地標與採集點。尺寸是本次可遊玩的配置，不照搬故事概念稿的面積。
- 薪火城可前往 `天門遺址`。它是可返回的安全紀念區；七材合璧、一次性飛昇儀式及完整七境任務鏈仍屬故事設計，不以地圖敘述冒充已實作機制。

## 資源與製作閉環

- 礦石使用真正的可破壞礦格與挖礦流程；藥草使用既有草藥採集容器；獸骨、殼片等異材走怪物掉落。
- 材料帶有五行值，配方主材、輔材及建議投料須通過實際製作目錄載入及五行需求比對。
- 配方寫入服務端實際讀取的 `content/forging/recipes.json` 與 `content/alchemy/recipes.json`，不是新增一個執行時不會讀的旁支檔案。
- 物品來源索引同時納入礦脈，玩家能查到對應地圖和礦脈地標。
- 415 件新物品按類別沿用既有美術，提供 96/192 像素版本；`docs/artwork/late-game-icon-reuse.json` 記錄來源。這些是明確的模板圖示映射，不宣稱每件都有獨立新繪插圖。
- 高階掉落不沿用測試用的一次數十份材料；普通怪、精英、頭目區分風險、刷新時間及產物。

### 資料驅動礦脈

`GmMapDocument.mineralNodes` 設定 `{ x, y, name, itemId, level, damageChanceBps, destroyCount }`，只可配置於既有玄鐵礦結構格。啟動期驗證座標、重複設定、物品存在及機率範圍，並建成線性地塊座標索引；熱路徑直接查索引，不掃描全圖。

未配置礦脈的地圖保留既有礦石產物與等級。`format:2` 的編輯器序列化保留礦脈欄位，避免編輯地圖後丟失來源。礦脈仍使用原有地塊耐久、破壞及重生生命週期，不另建一套採礦作業。

## 破敗洞府

破敗洞府由測試遭遇整理為金丹支線「喚靈舊帳」：在燼燈坊向祝餘接取，經歸藏脈窟隙門擊敗喚靈真人，再持名牌返回交付。保留真人原有九個招式及受傷背景，移除極端測試弱化與大量材料掉落。名牌由頭目掉落，任務提交走現有資產扣除及獎勵流程。

## 生成與驗證

1. `pnpm build:shared`：準備共用規則與數值函式。
2. `pnpm generate:late-game`：依故事目錄與數值配置產出正式內容；保留原有非後期配方及資源。
3. `pnpm --filter @mud/server compile`：編譯服務端與怪物執行時數值。
4. `pnpm proof:late-game`：檢查生成穩定性、真實模板/技能/配方載入、物品取得來源、地圖與採集點可達性及洞府設定。
5. `node scripts/render-late-game-atlas.mjs`：產生 `.runtime/late-game/七境地圖圖鑑.html`，可離線開啟；圖鑑不是遊戲截圖。

數值校準使用現行角色基準、怪物解析與傷害規則；它提供可重現的配置基線，不等於所有功法流派、強化組合及多人配合的完整實戰驗收。後續調整應以同一基準重跑，並保留逐境的擊殺時間與承傷比較，不能只確認數值是有限正數。

### 戰鬥節奏參考

`scripts/lib/late-game-balance-proof.mjs` 對七境各圖的普通怪、精英、頭目使用真實傷害管線取樣，並檢查回血是否使戰鬥無解。模型使用同圖五件製作裝備及每息一次普攻的基準，不計玩家主動技能、走位時間或隊伍增益；78 級以上角色屬性是依 78 級實際比例與共用標準基線外推。

| 類型 | 此基準下的擊殺時間 |
|---|---|
| 普通怪 | 約 11–16 息 |
| 精英 | 約 38–58 息 |
| 頭目，單人 | 約 180–270 息 |
| 頭目，五人 | 約 36–54 息 |

頭目普攻平均承傷約為模型玩家生命的 3–4%，有地面預警的重招約 9–14%；重招保留 3 息預警。這些數字是模型比較口徑，不是宣稱所有角色都會在該時間內打完。

### 本批驗證紀錄與界線

- 通過 `verify:quick`、`verify:client`、shared 建置、隔離服務的協議審計、新礦脈 smoke、資源節點與怪物貨幣掉落 smoke。
- 後期整合 proof 驗證 36 張新增地圖、56 位人物、415 件物品、182 種怪物及 196 張配方；不寫入玩家資料庫。
- 415 件新物品在客戶端均有取得來源；62 種草藥與 68 種礦石正確分成採集與挖礦。
- 圖鑑已以桌面、手機直向、觸控橫向尺寸檢查，含明暗配色；不等於實體 iPhone/Safari 驗收。
- 既有通用稽核仍有未通過項：`check-content-reference-consistency` 的 `merit`/`wudao_yujian` 使用效果，`content-monster-spawn-smoke` 裂鋒原刷新數 61/37 舊斷言，`check-content-map-consistency` 仍按舊 `tiles` 格式解讀正式 `format:2` 地圖。新圖另外以正式 normalizer、模板載入器及可達性檢查通過。
- 物品來源全庫稽核剩六件既有特殊物品未列來源，新批次缺漏為零；不把這項全庫稽核記為通過。
- 未執行資料庫/full release 門禁，也未部署生產。

本批未更改玩家持久化結構、既有境界突破條件或生產部署設定。內容進入線上仍需另外完成發布流程。
