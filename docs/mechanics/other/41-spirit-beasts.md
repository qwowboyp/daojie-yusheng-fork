# 靈獸與宗門生產

本機制的數值、玩家流程與開發契約集中維護於 [靈獸與宗門生產系統](../../design/spirit-beasts/README.md)。

- 核心：五行掉蛋、孵化收養、倉庫召喚／收回、同品同星培養、五星融合。
- 生產：宗門工位、最強閒獸派工、人工技藝共用任務、採礦、種植與製作排程。
- 資產：服務端持久化交易、操作冪等、工位產物手動領取及重啟恢復。
- [150 種名冊](../../design/spirit-beasts/catalog.md)、[完整配對](../../design/spirit-beasts/fusion-recipes.csv)、[AGY 美術](../../design/spirit-beasts/artwork.md)。
