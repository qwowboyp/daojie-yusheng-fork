## §1 境界敘事定位

金丹修士結的是內景。內景要一種人間火燒不出的熱，劫火是唯一選擇。

三十年前起，劫火帶上開始「落星」：天外墜物燒穿山嶺，餘火百年不熄。修士與匠戶沿火帶而居，靠劫火鍛體、憑隕鐵煉器。燼燈坊因此而生，一戶一燈，出遠門未歸者，燈不滅。

但玩家抵達這裡之後，很快會發現撿隕鐵的人少了好幾個，坊裡的燈籍越記越長，未歸表上的名字一個壓一個。隕鐵不是自然現象帶來的禮物，是別人做到一半的活掉下來的邊角料。補天一脈在劫火帶上開過七次爐，想把天上的裂補回去，七次都沒成。第七次的殘爐裡，還有一個不肯收錘的匠人殘念。

本境界的敘事體驗是三層疊加的：

1. **活下來**：劫火帶不適合人住，玩家要先學會在灰雪、熔渠、燈峽、爐膛之間保命，並弄懂坊裡的規矩（燈規、爐規、坊規）。
2. **弄清楚**：追著劫鐵的來歷往裡走，一路遇到守著規矩不放的人、守著別人的命不放的人、守著一爐火不放的人。他們都記得一件事的一小段，誰也說不全。
3. **接過手**：主線末段，玩家取得第一片補天殘材。這不是戰利品，是補天一脈七次沒交出去的那一棒，這回交到了玩家手上。

本境界不寫世界毀滅，不寫一語道破的總答案。寫的是劫餘的匠氣：天沒補上，爐還得開，燈還得點。

## §2 城鎮：燼燈坊

### 2.1 地理

- 位置：劫火餘溫帶東緣一段餘火已退的焦台地上，四面環著還在冒煙的焦坡。
- 地基原理：坊子蓋在當年燒穿、後來又涼透的硬殼地層上。坊中人有一句話：「火吃過的地，才住得人。」
- 四向：北望薪盡坡，西臨熔渣河上游，南面可以遠望峽口方向的一線燈光，東側是日後開放的渡口坡。
- 距離感：坊子不大，一圈走完約半盞燈油的時間；出了坊口就沒有安全路，灰雪一蓋，路要自己認。

### 2.2 風貌

- 每戶門前掛一盞燈。出遠門的人帶走自己那盞行燈的燈芯，回來才取回；沒回來的，門燈不熄。
- 坊裡的燈分三種：門燈（家戶）、行燈（出遠門的人帶走）、公燈（坊口與夜路，公家添油）。
- 街是焦土夯的，走路帶灰；灰沾在燈罩上，誰家的燈多久沒擦，附近的人都知道。
- 夜裡最安靜的時刻是添燈油的時候，全坊只聽得見油壺的聲音。哪一盞燈滅了，隔天早上一定有人上門問。
- 坊中央立著一面「燈籍牆」，掛滿木牌，牌上刻名。牆上有兩種牌：回來的牌朝外，沒回來的牌朝裡。

| 燈籍坊 | 坊正所，燈籍牆所在 | 主線接頭、燈籍登記、未歸表、交材儀式場地 |
| 爐工坊 | 爐台、驗料場、爐籍架 | 鍛造、強化、材料回收、爐籍查詢 |
| 燈市 | 燈油鋪、燈芯攤、藥材鋪、舊料桌 | 商店、藥材與燈類道具來源、委託板所在 |
| 餘溫棧 | 客棧與飯堂 | 落腳、恢復、聽故事、承接傳聞 |

## §3 圖一：薪盡坡（realmLv 43-45）

### 3.1 等級段與定位

- 等級段：43-45。金丹期第一圖，全期難度最低的過渡圖。
- 定位：讓玩家一落地就明白劫火帶的規矩。這裡不打硬仗，先學會在灰裡認路、認燈、認哪些東西不能碰。
- 情緒關鍵：空、灰、走丟。玩家會第一次覺得「這裡的燈不是在照明，是在等人」。

### 3.2 地貌尺寸（設計建議）

- 總尺寸建議 140×90 格，長條形焦坡帶，高低差 2 至 3 層。
- 區段結構：

| 區段 | 等級 | 內容 |
|---|---|---|
| 坡口 | 43 | 入境落點，公燈、回城傳送、第一組灰燼系雜怪 |
| 灰雪道 | 43-44 | 灰雪會蓋路的中段，採集點密集，怪從側坡壓來 |
| 燈桿道 | 44 | 古道兩側插滿熄燈燈桿，光源少、襲擊多，撿鐵人遺物聚集處 |
| 無名燈台 | 45 | 頭目區，一座沒有名字的舊燈台，頭目戰與往圖二的出口 |

### 3.3 風景特色

1. 焦坡連綿，地表是燒結的暗紅硬殼，踩碎會露出底下仍燙的灰，走路有脆響。
2. 古道兩側插滿熄滅的燈桿，桿頭朝同一方向歪，那個方向是劫火帶深處。
3. 風過灰燼如雪。灰雪會蓋住路與腳印，同一條路走兩次，看不出是同一條。
4. 夜裡幾乎無光，少數燈芯草自亮，成片像有人在坡上點了一坡小燈。
5. 坡頂回望看得見燼燈坊的燈海；坡底往前看不到頭，只有風聲與灰。

### 3.4 植物與礦物

| 名稱 | 外觀 | 用途 |
|---|---|---|
| 燈芯草 | 莖心一線暗紅，無風自明滅，摘下來得含著才不熄。 | 製引魂燈油、續氣類藥引。 |
| 餘燼砂 | 灰白細砂，翻開仍有餘溫，夜裡冒白線。 | 淬體輔料、低階炙體藥。 |
| 琉璃化土 | 隕擊處燒結的彩色玻璃狀土殼，斷口鋒利如刃。 | 琉璃器皿、低階法器胚料。 |
| 殘燈屑 | 舊燈桿上剝落的燈罩碎片，摸起來還有一點體溫。 | 引魂香、喚靈儀式耗材。 |

| 名稱 | 一句特色 |
|---|---|
| 焦土小妖 | 從燒結土裡鑽出的焦黑小東西，見光就湊，打碎了散成一把灰。 |
| 灰燼遊魂 | 燒剩的人形灰影，風一吹就散，散了在原地又聚起來。 |

### 3.6 頭目：拾燈人（四問）

**外型**

灰袍老者，身量與常人無異，背卻永遠微微躬著，像常年提燈走路。左手提一盞破了口的舊燈，燈裡沒有火，只有一小團慢慢轉的灰白光。兜帽下看不清臉，只看見下巴與一縷灰鬚。他走過的地方，灰雪會讓開半步。

**特色**

- 來歷：沒人知道他的名字，他自己也記不得了。他只知道自己在「等人回來」，等誰、等幾個、等了多久，全答不上來。
- 執念：他的燈裡裝的不是自己的魂，是別人的殘魂。每一個沒能走出熄燈古道的人，最後一縷都會落進那盞燈。燈提得穩，是因為燈一晃，裡面的人就更散。
- 與地圖的關係：他是整條古道上「未歸」這件事的具象。玩家打他，不是除害，是替那些走丟的人把燈收回來。
- 台詞方向：「你的燈呢？沒人給過你燈嗎。那你也是自己走丟的。」

**法術（3-4 個具名）**

| 法術 | 效果方向 |
|---|---|
| 收燈式 | 收走場上一盞殘燈回復自身，並給燈中殘魂加一層（環境／回復）。 |
| 照魂焰 | 燈焰照向目標，標記並壓低其身法與命中（控制／減益）。 |
| 灰雪掩燈 | 吹起灰雪，全場視野與命中下降，燈芯草的光被壓剩一點（環境）。 |
| 一盞替一命 | 放出一道灰白殘影替自己擋一次傷害，殘影散去後自身短時減傷（召喚／自保）。 |

**掉落定向**

- 材料：殘燈屑、燈芯草、琉璃化土。
- 功法殘頁：引魂類功法殘頁（暫名《引魂燈訣》）。
- 任務物：破燈（喚靈線與主線關鍵物件）、撿鐵人的名牌。
- 部件：金丹前期護具部件（暫定：燈硝護腕）。
- 機制難點：場上散著幾盞沒熄的燈，他會逐盞收。玩家每熄一盞可斷他一次回復，但熄燈會讓場地變暗、命中下降。爭的是節奏，不是輸出。

### 3.7 傳送連結

- 前境界接口：玄壤深淵·深淵裂縫（28,50）→ 薪盡坡·坡口（單向入境）。
- 圖↔圖：薪盡坡·無名燈台 → 熔渠舊坊·舊市口（雙向，節點一結束後開放）。
- 圖↔城鎮：薪盡坡·坡口 ↔ 燼燈坊·坊口（雙向，節點一 B 簇結束後開放）。

### 3.8 場景互動與敘事痕跡

- 熄燈燈桿：可逐一查看，部分桿上有刻名或刻痕，主線與支線的拾物點。
- 灰雪堆：踩過會塌，塌過的點位當日不再顯示採集光點，逼玩家認路而不是掃圖。
- 無名燈台：台面沒有刻名，只有一圈磨痕。頭目倒下後磨痕裡會多一小截燒斷的燈芯，是往圖二方向的指路物。
- 撿鐵人遺物：散在燈桿道，收齊可交回餘溫棧登入未歸表。

## §4 圖二：熔渠舊坊（realmLv 46-48）

### 4.1 等級段與定位

- 等級段：46-48。金丹中期起點，第一張「規矩壓人」的圖。
- 定位：把劫鐵的來源與補天一脈的痕跡接上。玩家第一次意識到，這一帶的匠人做的不是買賣，是同一件事做過很多次。
- 情緒關鍵：舊、悶、守著不放。

### 4.2 地貌尺寸（設計建議）

- 總尺寸建議 160×110 格，網狀街道加中央巨爐，渣河自西北斜切坊市。

### 4.3 風景特色

1. 舊坊市半沉入熔渣河，屋頂露在渣面之上，門還鎖著，鎖孔裡塞滿渣。
2. 街道是冷凝的熔渠，渠面平滑如鏡，冬天也不冰，走上去能看見自己的倒影。

### 4.6 頭目：冷爐坊主（四問）

**外型**

身材高大，圍裙與袖套都是舊坊市制式，燒出的大洞用金屬片補過。臉的上半覆著一張冷卻後凝住的渣面罩，看不見眼。雙手沒有一處完好的皮膚，指節粗大如鉗。腰間掛一串舊爐鑰，按坊市規矩從大到小排；走路極慢，一步一步都踩在爐規刻的位置上。

**特色**

- 來歷：舊坊市最後一任坊主。坊市沉了、人走光了，他還在守中央巨爐，因為爐規第一條寫著「開爐，坊主在場」。
- 執念：巨爐幾十年前就不肯再開火了，他仍每天按規矩擦爐、備料、點名。他認規不認人：玩家踏進坊界，他就當玩家是來上工的學徒，該做的沒做就罰，該交的沒交就扣。
- 與地圖的關係：他是「規矩還在、理由沒了」的活證據。他守的不是爐，是「有人在等爐開」這件事本身。
- 台詞方向：「規矩沒改。爐沒開，是人沒到齊，不是爐壞了。」

**法術（3-4 個具名）**

| 法術 | 效果方向 |
|---|---|
| 爐規第一條 | 給目標掛「犯規」標記，標記期間每次出手受一次回震，標記可疊（控制／反傷）。 |
| 熔渠引流 | 把腳下熔渠改道，在場上劃出一條持續灼傷的流線（環境／區域）。 |
| 冷爐封火 | 封住目標的火系增益與回復，短時所有回復減半（控制／抑制）。 |
| 按規開爐 | 走到既定規位，讓巨爐噴一次沉睡幾十年的餘火，全場高傷並把人往外推（環境／爆發）。 |

**掉落定向**

- 材料：熔心琉璃、劫鐵、火苔。
- 功法殘頁：爐規類殘頁（暫名《冷爐守則》）。
- 任務物：坊主爐鑰、舊坊爐單、爐牌。
- 部件：金丹中期武器胚（暫定：舊坊錘胚）、護具部件（暫定：坊規護肩）。
- 機制難點：場上有數塊「規位」，他會輪流站。把他從規位引開會削弱他，但他在移動的每一拍都會抓玩家「犯規」。玩家與他爭的是站位，不是輸出。

### 4.7 傳送連結

- 圖↔圖：熔渠舊坊·舊市口 ↔ 薪盡坡·無名燈台（雙向）；熔渠舊坊·渣河下游 → 懸燈峽·北口（雙向，節點二 A 簇結束後開放）。
- 圖↔城鎮：熔渠舊坊·舊市口 ↔ 燼燈坊·坊口（雙向，節點二 A 簇中段開放）。
- 前後境界接口：無直接接口，本圖為境界內部鏈路。

- 爐規刻字：可逐段查看，讀全的幾句裡反覆出現「開爐」「在場」「交件」三個詞。

## §5 圖三：懸燈峽（realmLv 49-51）

### 5.1 等級段與定位

- 等級段：49-51。金丹中期收束圖，情緒最重的一張。
- 定位：把「未歸」從薪盡坡的個人規模，放大到一峽一冊的規模。玩家在此拿到補天一脈最後一批出遠門者的名冊。
- 情緒關鍵：亮、靜、替人守著。

### 5.2 地貌尺寸（設計建議）

- 總尺寸建議 90×180 格，狹長峽谷，兩壁高低差 3 至 4 層，峽底風道貫通。
- 區段結構：

| 區段 | 等級 | 內容 |
|---|---|---|
| 北口 | 49 | 圖入口，燈架較疏，第一組燈系雜怪 |
| 燈廊 | 49-50 | 兩壁燈架最密處，明暗交替，伏擊與採集交錯 |
| 無風段 | 50 | 峽風消失的一段，燈火不隨風動，燈聲測試與精英出沒 |
| 名冊台 | 51 | 頭目區，一處收燈人舊台，頭目戰與往圖四的出口 |
| 回燈坡 | 51 | 南端緩坡，往補天殘爐的出口所在 |

### 5.3 風景特色

1. 兩壁懸滿萬盞引魂燈，燈架一層疊一層，看不到頂。
2. 峽風過處燈聲如訴。不是鈴響，是燈罩互相碰出的低鳴，像很多人同時在低聲說話。
3. 深處的燈火不隨風動，那一帶的燈自己站著，火苗直得像畫上去的。
4. 峽底散落著沒有掛上架的燈，有些還有人名，有些只有一個刻痕。
5. 夜裡峽壁像兩條倒過來的燈河，峽底的影子比人短。

### 5.4 植物與礦物

| 名稱 | 外觀 | 用途 |
|---|---|---|
| 峽蘿 | 掛燈架而生，葉背有燈影狀斑紋，風大時整片藤輕輕發亮。 | 編燈架、軟甲襯裡。 |
| 燈蕊木 | 樹心如燈芯的木材，剖開有微光，久放會自己乾成燈芯狀。 | 養神法器柄材、燈座。 |
| 引魂燈燭 | 峽中沒收回的燈裡剩下的半截燭，燭淚不落。 | 引魂、喚靈儀式主耗材。 |
| 燈影琉璃 | 峽壁燈火烤出的薄琉璃，映出的人影總比本體多一個。 | 幻術類法器材料。 |

### 5.5 妖獸

| 名稱 | 一句特色 |
|---|---|
| 燈蛾 | 翼上帶燈紋的巨蛾，撲燈時燈會暗一瞬；牠記得每一盞燈的位置。 |
| 影侍 | 從燈影裡走出的人形，替燈主人守著那條沒收回的命；影子被踩到會翻臉。 |
| 提燈傀 | 峽道上提著自己那盞燈的乾屍，燈亮時不動，燈一滅就撲人。 |
| 燈下影童 | 燈下沒有身體的小影子，跟著人走，人停下時它貼上腳跟。 |
| 峽風燈魅 | 順峽風漂的燈魅，會把人的影子認成路，領著人往峽壁上撞。 |

### 5.6 頭目：萬燈姥姥（四問）

**外型**

個子很矮的老婦，背著一個比自己還高的舊燈架，架上插著九盞燈，一盞亮、八盞暗。頭髮全白，用一根燒黑的木簪挽起。手指細長，指腹全是燈油養出的厚皮。她看人時先看人腳下的影子，再看臉。

**特色**

- 來歷：年輕時是峽口的收燈人。入峽的人先把燈掛在峽口，平安回來的人自己把燈取走。
- 執念：後來進峽的人越來越少有人回來，燈越掛越多，她也就不走了。她留下來替所有人守燈。燈在，人就還在，這是她唯一肯認的道理。
- 與地圖的關係：峽裡每一盞燈都是一條沒收回的命，她替人守著。她不恨誰，也不放誰：玩家進峽，她就當玩家也是「掛了燈的人」。
- 台詞方向：「燈給你留著。取不取，你自己記著。」

**法術（3-4 個具名）**

| 法術 | 效果方向 |
|---|---|
| 一燈一命 | 每盞未熄的燈給她一層護體，熄燈才能削層；熄燈者會被記上一個名（控制／機制）。 |
| 萬燈點名 | 照名冊依次點燈，每點一盞給在場目標疊一層壓制（遞進控制）。 |
| 燈聲如訴 | 峽風與燈聲同起，持續壓低玩家命中與暴擊，時間越久越明顯（環境／減益）。 |
| 收燈回魂 | 把場上的燈一盞盞收回，每收一盞回一次血，並從影裡喚出一名影侍（召喚／回復）。 |

**掉落定向**

- 材料：燈蕊木、引魂燈燭、燈影琉璃。
- 功法殘頁：引魂類功法殘頁（暫名《引魂燈訣》）。
- 任務物：姥姥的燈鑰、名冊殘卷副本、沒收回的燈牌。
- 部件：金丹中期飾品（暫定：守燈指環）。
- 機制難點：她本體不強，強在滿峽的燈。玩家要在「熄燈速戰」與「留燈換安全」之間選；每熄一盞，場地更暗、她的護體更薄、玩家身上的名更多。

### 5.7 傳送連結

- 圖↔圖：懸燈峽·北口 ↔ 熔渠舊坊·渣河下游（雙向）；懸燈峽·回燈坡 → 補天殘爐·斷爐口（雙向，節點二 B 簇結束後開放）。
- 圖↔城鎮：懸燈峽·北口 ↔ 燼燈坊·坊口（雙向，節點二 B 簇中段開放）。
- 前後境界接口：無直接接口，本圖為境界內部鏈路。

### 5.8 場景互動與敘事痕跡

- 燈架：可逐盞查看，有人名的、只有刻痕的、空的，三種分別對應不同故事碎片。
- 名冊台：收燈人舊台，桌上有一本名冊與一盒沒用完的燈簽。頭目戰後名冊殘卷可帶走。
- 無風段：全圖唯一聽不見燈聲的地方，玩家在此能聽清自己身上的東西在響，是本圖的靜場設計。
- 回燈坡：坡上插著一排沒取走的燈，坡口寫著一句舊話的殘句：「燈在人……」後半句被磨掉了。

## §6 圖四：補天殘爐（realmLv 52-54）

### 6.1 等級段與定位

- 等級段：52-54。金丹後期收束圖，本境界主線終點。
- 定位：把隕鐵、爐規、名冊三條線收在一起，面對第七次開爐的人，取得第一片補天殘材。
- 情緒關鍵：大、靜、沒做完。

### 6.2 地貌尺寸（設計建議）

- 總尺寸建議 150×150 格，環形爐形山體，中央爐膛直徑約 40 格，外圍廢鑄坡三圈。
- 區段結構：

| 區段 | 等級 | 內容 |
|---|---|---|
| 斷爐口 | 52 | 圖入口，爐形山體的缺口，第一組爐火系雜怪 |
| 廢鑄坡 | 52-53 | 三圈廢鑄，失敗鑄件擺得整整齊齊，採集與巡邏密集 |
| 鑄場殘垣 | 53 | 舊鑄場遺址，爐壁工序刻字所在，精英出沒 |
| 爐膛前 | 54 | 頭目區，爐膛口平台，頭目戰與殘材吐出處 |

### 6.3 風景特色

1. 半座山被削成爐形。山壁是人工修過的弧形，爐口朝天，線條乾淨得不像自然。
2. 爐膛裡封著一縷未竟的「天火」，不旺不小，幾百年沒動過，光是直的。
3. 四周廢鑄遍地。成千上萬的失敗鑄件擺得很整齊，像有人在等它們冷卻，等了很久。
4. 爐壁內側刻滿工序。一道道劃掉又重寫，前六道還讀得出，最深的一道被人鑿去了。
5. 爐口向天，雨落不進。站在爐沿上看天，天像比別處低一點。

### 6.4 植物與礦物

| 名稱 | 外觀 | 用途 |
|---|---|---|
| 補天渣 | 失敗的補天殘料，五色混雜、脈理斷裂，敲之無聲。 | 匠修研究、殘材封裝外殼。 |
| 天火芯 | 爐膛裡封存的未竟天火，裝在陶管裡仍是熱的。 | 頂階煉器火源、金丹後期鍛體。 |
| 殘爐琉璃 | 爐膛內壁燒出的異色琉璃，經得起天火而不裂。 | 高階器皿、封材容器。 |
| 隕紋鐵母 | 從天外墜物最中心取出的鐵母，紋路如星圖，越夜越涼。 | 劫鐵裝備的最終主材，本境界畢業導向。 |

### 6.5 妖獸

| 名稱 | 一句特色 |
|---|---|
| 爐侍殘念 | 還在做事的爐侍殘念，一問三不知，手上的活從沒停過。 |
| 渣甲衛 | 失敗殘料澆成的甲衛，一走一掉渣，渣落地會自己爬回身上。 |
| 鑄殘傀 | 半成品的巨大傀，手腳沒鑄完就想站起來，站起來一次就散一次。 |
| 天火餘燼 | 爐膛邊飄出的一縷灰燼，貼著人燒；燒的不是皮肉，是氣。 |
| 廢渣爬獸 | 廢鑄堆裡爬出的獸形渣塊，會學玩家的動作。 |

### 6.6 頭目：補天匠·殘念（四問）

**外型**

巨人般的身量，半身已經石化，石紋從左肩一路爬到腰際。另半身還是血肉，皮膚被天火烤成深赭。右手握一把沒有柄的錘，錘面缺了一角；左手捧著一片不規則的天裂碎片，碎片邊緣是斷的。他臉上沒有表情，眼窩裡沒有眼珠，只有兩點沒熄的火。每走一步，石化那半邊先落地，聲音很沉。

**特色**

- 來歷：補天一脈留在殘爐的最後一位匠人，也是七次失敗的執行者之一。當年最後一次開爐時，被封回爐裡的天火與自己的半身一起留住了他。
- 執念：他記得自己要做什麼（把天補上），記得做到哪一步（最後一片殘材還沒歸位），卻不記得後來的事。他把一切靠近爐膛的人都當成來交件的學徒，只問一句「料呢」。
- 與地圖的關係：他是這座爐的活工序。玩家不是來殺他的，是來替他把最後一件料交出去。
- 台詞方向：「料呢。湊齊了，我就收錘……湊不齊，爐就不認你。」

**法術（3-4 個具名）**

| 法術 | 效果方向 |
|---|---|
| 一錘定縫 | 高傷單體錘擊，命中處留下短時裂縫減防（破防／高傷）。 |
| 補天式·第七回 | 重演第七次失敗的工序，場上按次序落火二至三段，位置固定但規律可記（環境／多段）。 |
| 天裂映照 | 舉起天裂碎片，映出在場者這一路的劫痕；被映到者短時負重，移動與出手變慢（控制）。 |

**掉落定向**

- 材料：補天渣、天火芯、隕紋鐵母。
- 功法殘頁：補天一脈手記殘頁（暫名《補天手記》）。

### 6.7 傳送連結

- 圖↔圖：補天殘爐·斷爐口 ↔ 懸燈峽·回燈坡（雙向）。
- 圖↔城鎮：補天殘爐·斷爐口 ↔ 燼燈坊·坊口（雙向，節點三 A 簇結束後開放）。

### 6.8 場景互動與敘事痕跡

- 爐壁工序：可逐道查看。前六道劃掉又重寫，第七道被鑿去；拓文是主線任務物。

- 天裂碎片：留在頭目手中，不作為掉落物。玩家只能看著，不能拿走，這是本境界的資訊邊界。

## §9 與前後境界的敘事接縫

### 9.1 前接：築基期

- 物理接口：玄壤深淵·深淵裂縫（28,50，既有描述已標「金丹期入口預留」）。
- 既有伏筆對接：玄壤深淵的在地 NPC 曾提過正南有一道被封死的深裂口。金丹期的入口設計沿用這條線，不新增入口。
- 認知落差：玩家從「臺」與「深淵」的秩序裡走出來，落進一條燒了幾十年的火帶。金丹期不承接築基期的任何謎題，只承接它的位置：更深處。

### 9.2 後開：元嬰期

- 出口：燼燈坊·渡口坡。主線節點三 B 簇交材儀式完成後，坡上三盞公燈亮起，開啟「劫潮海渡口」。
- 對接目的地：元嬰期首圖（劫潮海方向，首圖為漏聲灘）。
- 交接物件：記名燈、簡殘的半卷手記、姥姥名冊殘卷副本。三件東西都會在元嬰期再度出現。

### 9.3 痕跡進入元嬰期（世界連續感）

- 同名燈：交材儀式上，玩家在燈籍坊掛起一盞「記名燈」，燈上刻玩家與補天殘材的名字。守燈人·啞姑每日替它添油。元嬰期的殘響渡會出現一盞同名燈，證明真有人把燈帶過了海。
- 手記：記匠·簡殘把半卷《補天爐下記》交給玩家，說他這輩子只寫得完前半段。後半段的落點在元嬰期。
- 名冊：姥姥的名冊殘卷副本隨玩家離開。名冊最後一頁的名字，會是元嬰期某個 NPC 認得的名字。

### 9.4 喚靈線與既有測試圖處置

- 定位：破敗洞府（`ruined_cavern_manor`，mapLv 43，18×12）為支線「喚靈」線第一站，文檔標注「既有測試圖·待補完」。
