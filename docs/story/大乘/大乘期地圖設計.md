## §0 適用範圍與前置（前境界接縫、入口方式）

### 0.1 本境界的入口

天垣城的關樓之上還有一道門，門後是向上的路。合體期主線收束、取得關樓通行之後，玩家自關樓出關，沿牆根的舊棧道一路向上，風先於一切抵達：先是衣角被掀，再是耳裡嗡響，最後整個人像是走進了一條看不見的河。這條舊棧道的落點，是大乘期第一張圖劫風口的南面舊哨道。

合體期三條留痕在此兌現：

- 垣衛提點霍守拙簽發的「輪戍」調令副卷：鎮涯關守望衙認得垣衛的印，守望令賀滄見印即收，入清冊房備檔。
- 司筆崔醒抄錄的《補天者名錄》副本：清冊官聞攸會引用其中幾頁，作為清點七次補天遺址的比對底本。
- 老兵關復城講述的外壘舊事：往來商旅把這段口述帶上關城，成了拾遺丫頭小滿嘴裡「以前補過幾次」的來源。

### 0.2 本境界的出口

主線節點三收束後，鎮涯關頂關的登劫道開啟。登劫道自坡根直上，道口掛著全城最後一盞燈；燈外即是渡劫期「劫雲海」。本境界出口不開給剛入城的玩家，需完成《守關》全線並在天痕下的合鳴窪完成合鳴。

### 0.3 命名與家族約束

- 妖獸家族：劫風系、雷罰系、獸潮系。天痕下坡為三系症狀交匯之地，仍只取本境三系的混生形態，不引入他界家族。
- 材料家族字：劫／罰／潮／痕。四圖材料名稱一律帶其中一字（總綱 §4.6 已定名者沿用：劫風木、風蝕鐵、雷罰鐵、贖罪苔、壘心木、劫獸骨、天痕璃、反影草）。
- 頭目名號一律以總綱 §4.6 為準，不得更名。擋風人、執雷者、獸潮王、天痕使之中，獸潮王與天痕使符合大乘級稱謂（大士／使／王）；擋風人與執雷者為總綱既定名號，沿用不改（詳見文末附註）。
- 本境界自創名詞僅限：NPC 名、材料名、妖獸名、局部小地名與設施名，且皆已避開既有 40 圖地名與材料名。

### 0.4 世界觀揭示層（本境界只能揭到這裡）

- 玩家在本境界得知：天痕是舊天門的傷口；劫風、雷罰、獸潮皆是這個傷口的症狀，而不是三場各自獨立的災害。
- 玩家在本境界仍不知道：天痕能不能補。守望衙的清冊裡只有七次失敗的記錄，沒有一頁寫著「可以」或「不可以」。
- 「上面」是什麼、有沒有人，本境界從頭到尾不揭。天痕使傳下來的只有半句話，連他自己都不知道全句。

## §1 境界敘事定位

合體期的收束問題是「你上去，是替誰看」。到了大乘期，這個問題有了回答，也有了代價：玩家上到了最接近天痕的地方，看見的不是仙宮，是前線。

鎮涯關的人不談飛昇。他們談的是今夜誰當班、旗換了沒有、潮線移了半格沒有。這裡是全人間最接近那道裂的地方，也是唯一還把日子過成日子的地方：有人打鐵、有人記帳、有人頂著風教孩子走路。大乘修士在這裡明白自己不是最強的——是**最後一排**。天痕若再撐開一分，先沒的就是這一排人。

本境界的敘事節奏是四段遞進：上關報到、七址清點、殘片合鳴、傳話落地。玩家在四張圖裡學會的不是新的殺法，而是「站得住」：站得住隘口的風、站得住雷罰的罪名、站得住獸潮的不講理，最後站得住一句聽不全的話。

四張圖的主題與頭目一一對應：

| 圖 | 主題 | 頭目 | 頭目留下的那句話 |
|---|---|---|---|
| 劫風口 | 風的隘口 | 擋風人 | 風裡有話，聽久了就懂了 |
| 雷罰原 | 雷行罰 | 執雷者 | 一個都不冤 |
| 獸潮舊壘 | 最後防線 | 獸潮王 | 牠不說話；唯一的「話」是抬頭看關燈的那一下 |
| 天痕下坡 | 裂的正下方 | 天痕使 | 上面問：……幾時換班 |

## §2 城鎮：鎮涯關

### 2.1 地理

鎮涯關建在天痕正下方的坡根上。城不是平的，是順著坡度疊成三層：南面最低處是下關，一條長街通到南門哨口；中層是中關，守望衙署與望痕台都在這裡；最北、也是最高的頂關貼著坡根，是全城唯一能上登劫道的地方。城的北牆最厚，牆基直接砌進坡體；南牆最薄，因為風從北來。

關城的南門哨口正對劫風口的舊哨道，那是合體期上來的路，也是全城與人間其餘地方僅剩的兩條通路之一（另一條是商旅走的西側山道，圖外）。

方位的記法在關城很簡單：風從北面天痕下來，先去劫風口，再到城裡，最後從南門哨口洩出去。所以關城的人說「上風處」和「下風處」，指的不是城內，是整條風路。

### 2.2 風貌

全城的燈籠都罩鐵網。網眼大小是門手藝：太密，光出不去；太疏，劫風裡的火星會鑽進來。罩網的鐵絲每年換一次，換下來的舊網熔了打成補丁，補在別人的網上——所以每一盞燈的網都有別人的一段。

全城的屋頂朝南斜，屋脊壓著石頭。門簾不是布，是鐵片編的；風大的日子全城叮噹作響，本地人叫這個聲音「城在打拍子」。鐵旗巷的旗一個月換一面，舊旗回爐打成新旗，桑槐說這是關上唯一一件「用完還能變回原料」的東西。

孩子學會走路先學會頂風。關城的說法是：不會頂風的孩子，走得再快也出不了南門。

## §3 圖一：劫風口（103-105）

### 3.1 等級段與地貌尺寸

- 等級段：`realmLv 103-105`
- 地貌尺寸：約 110×120 格；自南面舊哨道向北收窄，中段最窄處僅 4 格寬，兩壁是風蝕岩槽；北坡接雷罰原。
- 通關條件：擊敗頭目擋風人，完成劫風口兩址清點（第一址舊哨樁、第二址風斷碑）。

### 3.2 風景特色（5 要點）

1. 隘口成哨：兩壁岩層被風削出一條條長槽，槽紋全部順風；站在槽口，風會被地形切成一股一股的。
2. 風分三層：貼地是滾石層，腰高是扯人層，高處是呼嘯層；站姿不同，受到的風也不同。
3. 鐵旗列：自舊哨道口到隘口深處插了一路鐵旗，旗面被風扯得半捲，舊旗回爐打新旗，一個月一面。
4. 聽風台與風斷碑：隘口中段一塊被磨平的石台，台面上一圈腳形石窩——那是站出來的人留下的；台後立著半截風斷碑，朝北那面已被風磨成平板，碑名只剩一個「風」字。
5. 風裡的人和聲：特定風速下，石槽互相摩擦，隘口會發出接近人聲的低語；老哨說那是風在說話。

### 3.3 植物與礦物（5 種）

| 名稱 | 外觀（一句） | 用途 |
|---|---|---|
| 劫風木 | 只長在隘口背風窪地、木紋全部扭成螺旋的老木 | 大乘期防具與陣材主料 |
| 風蝕鐵 | 隘口兩壁夾層裡的鐵塊，表面被風蝕出蜂窩般的孔 | 鍛兵與修哨 |
| 劫哨砂 | 風裡懸浮、一落靜地就凝成暗色細砂的砂粒 | 製哨器與風符 |
| 劫紋苔 | 只貼在背風岩面、紋路每逢換季就轉一次向的苔 | 抗風丹輔材 |
| 絞風藤 | 在背風窪地把自己絞成繩狀的藤，扯開會彈回 | 製索具與護具內襯 |

### 3.4 妖獸（6 種，劫風系）

| 名稱 | 一句特色 |
|---|---|
| 劫風獸 | 半透明的鹿形獸，跑動時身體先散後聚，散了就是風、聚了才咬人 |
| 扯旗妖 | 抓著鐵旗殘片當殼的妖物，見旗就撲，彷彿在奪回什麼 |
| 吹燈魈 | 專往燈火苗上撲的小魈，罩網也擋不住它從網眼裡鑽 |
| 頂風猿 | 逆風站著不動的灰猿，誰繞到它下風處，它就發狂 |
| 嚎風鴉 | 群飛成旋的鴉，叫聲散碎，聽起來像被風吹散的話 |
| 滾石傀 | 被隘口滾石裹住的舊行者殘骸，順風滾、逆風爬，永遠朝著北面 |

### 3.5 頭目：擋風人

**四問一·外型**

一個站著的人形，從背後看像插在隘口裡的一根舊樁。斗篷早被風磨成薄殼，貼在身上像第二層皮，看不出原本的顏色。臉朝北——風來的方向，眼睛半闔，睫毛上結著鹽霜似的砂。他腳下有一個深到腳踝的凹坑，那是站出來的。他不轉身迎人，只把耳朵稍微偏過來。

**四問二·特色（來歷與執念）**

守望的老哨換了一代又一代，他是最早的那一個：當年奉命「聽三天風」，一聽就沒再走。他不攔路，只問來人聽不聽得懂；聽不懂的，他讓風替他擋。他的執念是「把話聽全」——風裡的話他聽了半輩子，還差最後幾個字。舊哨樁這一址就在他腳下，清點第一址，繞不過他。

- 與地圖的關係：整個隘口是他的哨位；他不是隘口的守衛，是隘口的耳朵。
- 台詞方向（至多一句）：「風裡有話。聽久了，就懂了。」

**四問三·法術（4 個具名）**

| 法術 | 效果方向 | 對應地圖主題 |
|---|---|---|
| 逆風站位 | 他往玩家上風處一挪，場中風向倒轉，玩家位移被吹回原點 | 站姿與風向 |
| 三層風 | 依玩家站位高度分層打擊：貼地掃、腰高扯、高處壓，同一套路連打三層 | 風分三層 |
| 風裡的話 | 念出半句聽不清的風語，命中者短時聽不見技能提示，只聽見風 | 風裡的「話」 |
| 站成樁 | 低血階段他不再移動，把自身化入隘口風道，引來成群的劫風獸替他擋在身前 | 站了一輩子 |

**四問四·掉落定向**

- 材料：劫風木、風蝕鐵、劫哨砂、劫紋苔。
- 部件：擋風斗篷（披風位）。
- 殘頁：《聽風訣》殘頁（感知與預判向功法）。
- 清點交付：舊哨樁哨記拓片與風斷碑碑拓（完成兩址清點後由他讓開位置取得，非隨機掉落）。

**戰鬥定位（機制難點，無數值）**

難點在站位。風向每輪會變，站錯層位就要吃全額傷害；他不是木樁，是風的閘門——玩家要先學會站得住，才輪到打。

### 3.6 傳送連結

- 入口：天垣城關樓出關，沿牆根舊棧道上行（合體期出口）。
- 回城：鎮涯關風市哨口（完成節點一 A 簇後開啟）。
- 出口：隘口北坡，通往雷罰原（完成節點一 B 簇後開啟）。

## §4 圖二：雷罰原（106-108）

### 4.1 等級段與地貌尺寸

- 等級段：`realmLv 106-108`
- 地貌尺寸：約 130×130 格；平頂原面，中央一座判台，碑林環布全原；西側碑道接獸潮舊壘。
- 通關條件：擊敗頭目執雷者，完成雷罰原兩址清點（第三址判台基、第四址啞雷窪）。

### 4.2 風景特色（5 要點）

1. 落雷按律：雷不亂落，總在碑前停半息再落，像先宣判、再行刑。
2. 碑林記事：每塊碑刻著一個名字和一行「罰由」，字口被雷火燒得焦黑，名字卻留著。
3. 判台與啞雷窪：原心一座石台，台面刻著「罪與罰」三個大字，字口裡填著雷罰鐵；台西的啞雷窪是另一處清點址，雷落進窪裡就沒了聲，窪底積著歷次罰雷的殘響。
4. 鎖鏈入雲：從判台往上，一串雷鎖直插進天痕的方向，鎖上還在跑電，沒人敢碰。
5. 焦草留青：被雷火燒過的地面照樣長草，只是長成黑色的——當地人叫它「認罰的草」。

### 4.3 植物與礦物（5 種）

| 名稱 | 外觀（一句） | 用途 |
|---|---|---|
| 雷罰鐵 | 埋在原土裡、被雷火反覆淬過的深青色鐵塊，斷口泛電光 | 雷系法器與重甲主料 |
| 贖罪苔 | 只長在碑影裡的灰白苔，日照到就枯、碑影蓋回去又活 | 定神丹與鎮魂符 |
| 罰雷砂 | 碑座下積的暗紫細砂，遇水會爆響 | 製雷符與引信 |
| 焦心木 | 被雷劈過卻沒死的樹，木心焦黑、外皮還在長 | 抗雷法器柄材 |
| 判痕石 | 從被判過的碑上敲下的碎石，斷面隱約有字影 | 刻符與壓勝 |

### 4.4 妖獸（6 種，雷罰系）

| 名稱 | 一句特色 |
|---|---|

### 4.5 頭目：執雷者

**四問一·外型**

一團人形的雷。輪廓像一個穿甲的人，甲片的形狀清晰可辨，材質全是凝住的雷光。它臉上沒有五官，只有一道豎直的裂，裂裡是更深的光。它走過的地面留下焦黑的腳印，腳印成對、間距精準得不像走路，像丈量。手裡沒有兵刃，兩掌攏著一團不斷收縮又膨脹的雷球。

**四問二·特色（來歷與執念）**

執行天罰的雷靈之王。它不是被誰指派來的——它是「罰」這件事本身在人間凝出來的執行者。它堅信自己罰的每一個都不冤；這份堅信讓它從不遲疑，也讓它從不複核。原上每一塊碑都是它的判決書存根，它把碑當帳本，帳不平就不走。判台基與啞雷窪兩址便在它腳下：清點第三、第四址，得先過帳。

- 與地圖的關係：整座原是一個執行完畢、無人結案的法庭；它是唯一還在上班的人。
- 台詞方向（至多一句）：「一個都不冤。」

**四問三·法術（4 個具名）**

| 法術 | 效果方向 | 對應地圖主題 |
|---|---|---|
| 宣判 | 點名一名玩家，在其頭頂聚雷雲，數息後落雷；期間離開碑影也躲不掉 | 先宣判、再行刑 |
| 罰不及眾 | 把這一記雷分攤給場上所有人，分擔的人越多、單人越輕——逼玩家決定誰挨 | 罰有分擔之法 |
| 罪碑為證 | 召出碑影，碑影內的玩家無法獲得治療與增益 | 碑是存根 |
| 一雷不冤 | 低血階段不再閃避，把雷鎖拉回自身；每受一次傷害，下一擊就更重 | 不複核、不遲疑 |

**四問四·掉落定向**

- 材料：雷罰鐵、贖罪苔、罰雷砂、判痕石。
- 部件：執罰雷符（飾品位）。
- 殘頁：《承雷式》殘頁（抗雷與反擊向功法）。
- 清點交付：判台基罰單拓文與啞雷窪殘響拓文（完成第三、第四址清點後取得，非隨機掉落）。

**戰鬥定位（機制難點，無數值）**

難點在「躲不掉，但分得掉」。它按規矩罰，玩家得按規矩分；想一個人硬吃的人，會被累積的雷壓垮。

- 出口：原西碑道，通往獸潮舊壘（完成節點二 A 簇後開啟）。

## §5 圖三：獸潮舊壘（109-111）

### 5.1 等級段與地貌尺寸

- 等級段：`realmLv 109-111`
- 地貌尺寸：約 140×120 格；五道舊壘沿坡線折成鋸齒，一道比一道矮；壘後即鎮涯關東側；北坡為潮線。
- 通關條件：擊敗頭目獸潮王，完成第五址清點（初壘）。

### 5.2 風景特色（5 要點）

1. 壘線如鋸：五道舊壘沿坡線折成鋸齒，每補一次就矮一截，像替這條防線記年齡。
2. 骨堆成灘：壘前緩坡堆滿歷次劫獸潮留下的白骨，踩上去會陷下一個腳印。
3. 燈在壘後：從壘上回頭，能看見鎮涯關的燈——那是全圖唯一不隨風晃的光。
4. 潮線可見：坡下有一道被踩禿的線，叫潮線；獸潮每次衝到這裡就折返，而線一直在往上移。
5. 舊名掛壘：每道壘牆都掛著守壘人的名牌，牌是鐵的，字被風磨淡，摸得出凹痕。

### 5.3 植物與礦物（5 種）

| 壘心木 | 從壘牆芯裡長出來的老木，被壓得極密實，鋸開有壘石的紋 | 製壘料與重甲襯材 |
| 劫獸骨 | 潮裡帶上來的獸骨，比一般獸骨沉，敲起來有金屬聲 | 製骨器與丹藥引 |
| 潮壘砂 | 獸潮踩碎的骨與石混成的砂，永遠帶著潮氣 | 製壘料與護甲內襯 |
| 咬痕藤 | 沿壘牆攀生的帶刺藤，刺口一圈一圈像牙印 | 製陷阱與攔索 |
| 拾骨花 | 開在骨灘上的灰白花，摘的時候要連根下的骨一起摘 | 續命丹主材 |

### 5.4 妖獸（6 種，獸潮系）

| 名稱 | 一句特色 |
|---|---|
| 劫獸潮（成群） | 一浪接一浪的小獸群，單獨看很弱，成潮時能把壘啃掉一層 |
| 領潮獸 | 走在潮前頭的那幾隻，牠們停，潮就停 |
| 咬壘獸 | 一生只咬壘牆的短吻獸，牙磨平了就用骨頭啃 |

### 5.5 頭目：獸潮王

**四問一·外型**

一頭看不出原形的巨獸。身上長滿歷次潮的痕跡：火燒的疤、雷劈的裂、刀砍開又長合的口。牠的頭壓得很低，低到幾乎觸地，像永遠在起跑。四肢比身體短，跑起來是滾的。牠不叫——牠一動，骨灘上千萬塊骨頭一起響，那就是牠的叫聲。

**四問二·特色（來歷與執念）**

潮的「頭」。牠不是獸潮的王，牠是獸潮的方向本身：潮往上衝，牠就在前頭；潮散了，牠退回坡下等下一個浪。牠不憎恨人，只是照著本能往上衝。壘線是牠撞出來的——每一道壘，都是牠和守壘人一輪一輪撞出來的「停戰線」。初壘這一址就在牠撞出來的缺口裡：清點第五址，躲不開這一撞。

- 與地圖的關係：牠是「最後防線」的量尺——壘有多矮，潮就有多近。
- 台詞方向（至多一句）：牠說不出人話；唯一的「話」是牠抬頭看關燈的那一下。

**四問三·法術（4 個具名）**

| 法術 | 效果方向 | 對應地圖主題 |
|---|---|---|
| 起浪 | 伏地不動，召來一整坡的劫獸潮，浪頭隨牠的方向移動 | 潮的「頭」 |
| 骨灘翻 | 掀翻骨灘，場中陷足、位移被拖慢 | 骨堆成灘 |
| 撞壘 | 定向直撞：撞上壘牆則全場震盪，沒撞上則由玩家替壘牆擋這一下 | 壘是談出來的 |
| 不退 | 低血階段把退路踩平：不再後退，每一次被擊退都轉成下一次衝鋒的蓄勢 | 只會往上衝 |

**四問四·掉落定向**

- 材料：壘心木、劫獸骨、潮壘砂、咬痕藤。
- 部件：潮骨護腕（腕部位）。
- 殘頁：《壘戰式》殘頁（群戰與攔阻向功法）。
- 清點交付：初壘壘銘拓片（完成第五址清點後取得，非隨機掉落）。

**戰鬥定位（機制難點，無數值）**

難點在「潮不停」。玩家不是在打一隻王，是在打一波又一波的方向；力氣花在哪裡，決定壘線守不守得住。

### 5.6 傳送連結

- 入口：雷罰原西碑道。
- 回城：鎮涯關風市哨口。
- 出口：壘後關道，通往天痕下坡（完成節點二 B 簇後開啟）。

## §6 圖四：天痕下坡（112-114）

### 6.1 等級段與地貌尺寸

- 等級段：`realmLv 112-114`
- 地貌尺寸：約 120×140 格；自關城坡根向北一路抬升到坡頂；坡頂正對天痕；坡上影子反向。
- 通關條件：擊敗頭目天痕使，完成第六址（合鳴窪）與第七址（坡頂末碑）清點，並完成殘片合鳴。

### 6.2 風景特色（5 要點）

1. 影反向：全坡的影子都朝南（背著光的方向）；人往北走，影子在身前帶路。
2. 痕在天頂：抬頭即見天痕，雲從痕裡漏下來；風、雷、獸三個方向的聲音在坡上能同時聽見。
3. 半截碑與坡頂末碑：坡上立著歷代登坡者的半截碑，碑都只刻了一半——立碑的人沒回來刻完；坡頂立著最後一塊碑，是所有半截碑裡唯一刻完了的一塊，碑上只記七個日期，不記名字。
4. 合鳴窪：坡腰一處淺窪，把補天殘片帶進窪心，殘片會自己發出極輕的嗡鳴；越往上，響得越清楚。
5. 坡頂無雪：坡頂終年不積雪，地面是溫的，像坡的另一頭有什麼東西一直熱著。

### 6.3 植物與礦物（5 種）

| 名稱 | 外觀（一句） | 用途 |
|---|---|---|
| 天痕璃 | 坡上結出的透明碎晶，對著光看，裂紋的走向和天痕一致 | 大乘期飾品與陣材主料 |
| 反影草 | 葉面朝下、葉背朝上長的草，影子落在自己身上 | 匿蹤丹與定影符 |
| 痕路砂 | 歷代登坡者踩實的坡道細砂，砂裡混著極細的璃屑 | 製導向符與引路器 |
| 逆光梢 | 只往背光方向長枝的細梢灌木 | 匿蹤與遮蔽 |
| 溫痕石 | 坡頂附近溫熱的石頭，貼身能壓住舊傷 | 護脈丹輔材 |

### 6.4 妖獸（6 種，三系混生）

|---|---|

| 半碑骸（劫風系風乾遺骸） | 靠在半截碑上、再也沒站起來的舊骸，風一過就輕輕點頭 |

### 6.5 頭目：天痕使

**四問一·外型**

半人半劫。左半身還是人的樣子：舊斗篷、舊甲、一隻看得清的手。右半身是劫——不是燒傷，也不是殘缺，是某種東西從右邊往裡長，長成了他的另一半。長的那半邊一直在輕輕地「漏」：漏光、漏砂、漏聲音，偶爾漏出半句話。他站在坡頂，面朝天痕，像在等一封永遠不來的回信。全坡的影子都是反的，只有他的影子是正的。

**四問二·特色（來歷與執念）**

傳「上面」的話，也傳「下面」的話。他不是使者，是通道：當年他是登坡者之一，走到坡頂時天痕「響」了一次，他就成了這樣。上面的話從他那裡下來，下面的話從他那裡上去；兩邊的話都不完整，因為他記得住的只有中間那一段。他的執念是「把兩邊的話都傳對」——他到現在還沒傳完。合鳴窪就在他腳下，坡頂末碑就在他身後：清點第六、第七址，也是他等了最久的一件事。

- 與地圖的關係：他是坡的盡頭，也是「上面」與「下面」之間唯一還在通話的那條線。
- 台詞方向（至多一句）：「上面問：……幾時換班。」

**四問三·法術（4 個具名）**

| 法術 | 效果方向 | 對應地圖主題 |
|---|---|---|
| 傳話 | 把一句聽不全的話傳給玩家：命中者短時分不清敵我提示 | 傳話 |
| 漏 | 右半身漏出的一瞬，全場玩家身上的增益被漏掉一層 | 半身是劫 |
| 半身 | 分離出「上面的一半」與「下面的一半」兩個殘影分頭行動，本體不受傷害 | 兩邊的話 |
| 轉述 | 低血階段把玩家對他用過的招式「轉述」回去——不是複製，是隔了一層的、失真的版本 | 他記得住的只有中間 |

**四問四·掉落定向**

- 材料：天痕璃、反影草、痕路砂、溫痕石。
- 部件：痕使殘環（戒指位）。
- 殘頁：《傳痕錄》殘頁（感知與轉述向功法）。
- 清點交付：合鳴窪窪心拓文與坡頂末碑碑拓（完成第六、第七址清點後取得，非隨機掉落）。

**戰鬥定位（機制難點，無數值）**

難點在「分不清」。他的招式全是隔了一層的：話傳一半、招數失真、半身分離。玩家要在真假之間站得住，才輪得到聽最後那句話。

### 6.6 傳送連結

- 入口：獸潮舊壘壘後關道。
- 回城：鎮涯關望痕台步道（完成節點三 A 簇後開啟）。
- 出口：坡頂登劫道，通往鎮涯關頂關（完成節點三 B 簇後開啟）。

## §9 與前後境界的敘事接縫

### 9.1 前接合體

- 天垣城關樓出關之後的第一段路是向上的：合體期在牆下學會「怎麼守」，大乘期在坡下學會「守的是誰」。
- 三條留痕各有落點：垣衛輪戍調令副卷入清冊房備檔（聞攸會比對垣衛的印）；《補天者名錄》副本成為清點七址的比對底本；關復城的口述被商旅帶上關城，成了小滿嘴裡「以前補過幾次」的說法。
- 玩家帶著第五片補天殘材上關；殘材在經過劫風口隘口時會輕微發響，這是補天料的呼應，不給出更多資訊。

### 9.2 後開渡劫

- 頂關燈之外就是劫雲海（渡劫期 115-117）。本境界出口需完成《守關》全線與合鳴窪合鳴。
- 留痕一·守望調令：節點三收束後，賀滄依守望舊例簽發調令，命玩家帶「遺址清冊殘頁」副本與第六片補天殘材往薪火城備檔；渡劫期薪火守認得守望的印。
- 留痕二·清冊殘頁：聞攸在第七筆檔的日期欄裡填了一個「未」字的那一頁，抄了一份副本隨玩家下行；這是大乘期交給渡劫期最重的一頁紙。
- 留痕三·頂關燈：蘇盞託玩家帶一句話去薪火城——「那邊的燈比這裡亮，替我看看。」話是口述的，沒有紙。

### 9.3 被引用的可能性

本境界的後續引用一律以「痕跡」形式出現，不主動替渡劫隊補設定：守望調令、清冊殘頁、頂關燈、擋風人的半句話、天痕使傳下來的那一句。其餘細節留白。
