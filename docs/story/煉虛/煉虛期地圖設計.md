## §0 適用範圍與前置

### 0.1 境界入口

- 唯一入口：化神期末圖出口 `望涯驛·頂驛關門`。
- 進入方式：玩家推開頂驛最後一道門，門後不是崖，是「沒有崖」的地方。風聲在跨過門檻的一瞬消失，腳下由實地換成一片鬆軟、混色的灘——那是界隙邊緣堆積的異界碎屑。此處即 `碎界灘·灘頭`。
- 玩家落地後，會發現灘上插著幾根舟盟的 `泊樁`，樁上刻著泊位號，這是舟盟替上岸者留的引路記號。玩家循樁走向灘心的工棚，再由工棚引至 `虛舟市`。
- 入口不可逆：煉虛期地圖不回連化神期地圖，只保留回城（虛舟市）與境內互連。

### 0.2 境界出口

- 唯一出口：`虛舟市·牆根泊棧橋`。
- 開啟條件：完成主線節點三，並在虛舟市 `公證堂` 完成「泊籍公證」交材儀式（見劇情設計 §4、§7）。
- 出口去向：登上舟盟末航，順界隙的裂走到盡頭，抵達合體期入口 `垣門外壘`（91-93）。舟盟把那個泊位叫作「牆根泊」，老話說「船到牆根就回頭」——玩家是第一個不回頭的人。

### 0.3 境內閉環

- 四圖以航線串成一條向界隙深處推進的主線：碎界灘 → 虛獸巢帶 → 星骸舊港 → 無光海·裂。
- 每一圖皆有回舟點接回 `虛舟市`；舟市是境內唯一的補給、修理、公證與任務節點。
- 圖與圖之間為單向深入；已通過的首領區不再重置（首領可重複挑戰，但通路永久開放）。
- 傳送鏈路細節見 §7。

### 0.4 命名與家族約束

- 妖獸家族：界屑系、虛空系、無光系，三系依圖分工，不得與他界家族串用。
- 材料家族字：隙／骸／光。四圖材料名稱一律帶其中一字（總綱 §4.4 已定名者沿用：碎界砂、異壤、虛空藻、蝕界涎、星骸鐵、港燈油、無光露、深隙晶）。
- 頭目名號一律以總綱 §4.4 為準，不得更名。
- 本境界自創名詞僅限：NPC 名、材料名、妖獸名、局部小地名與設施名，且皆已避開既有 40 圖地名與材料名。

### 0.5 世界觀揭示層（本境界只能揭到這裡）

- 玩家在本境界得知：世界之外還有世界碎片，劫從界隙漏入。
- 玩家在本境界仍不知道：牆是誰築的。界隙深處那道「裂」的背面是什麼，本境界不揭；無光老祖只聽得出「裂那邊的東西不是我們的」，聽不出那是什麼。
- 「劫從外來」在本境界以證據形式落地，不以旁白形式說破：碎界灘的異界碎屑、虛獸啃薄的世界邊緣、星骸舊港三百年前的舊帳、裂那邊漏過來的動靜，四樣拼在一起，才夠拼出一句「劫不是從我們這裡長出來的」。誰在牆上、牆由誰築，留給下一境。

## §1 境界敘事定位

（擴寫總綱 §4.4 主題段）

化神修士走到世界的涯，看見涯外有天痕；煉虛修士要問得更遠：涯外不只是天，還有「別的世界的碎片」。天涯的盡頭不是虛無，是裂縫——界隙。世界與世界之間有薄如蟬翼的夾縫，夾縫裡漂著別的世界碎下來的地方。煉虛修士能以身入隙，於是有了舟盟：以巨舟航行界隙的商旅與拾荒者。

虛舟市就是停在界隙邊緣的商市。它不是建在土上，是建在舟上；巨舟以巨纜相連，浮成一片市面；又因為這一片無光之海沒有真正的白天，市面的光全靠船上自己點的燈。這裡的人不說「進城」，說「上舟」；不問你從哪來，只問你「帶了什麼貨」。煉虛期的修士社會，是一個把「邊界」當成生意的社會——禁忌之物在這裡有價，別的世界碎片在這裡有價，連一句「裂那邊的動靜」都能賣。

本境界主線《界隙行舟》。舟盟雇傭玩家替他們跑航線，第一趟就撞上虛獸洄游斷航；循著斷航的線索，玩家摸進一座早已死去的星辰殘骸——星骸舊港，港裡的舊規還在運行，港守傀儡還不承認港已經死了；再往裡，是沒有光、只能以神識航行的無光海，海的深處有一道橫貫的裂。玩家貼近裂，第一次「聽」到裂那邊有東西——那不是這一邊的。世界之外還有世界，劫不是從我們這裡長出來的，是從界隙漏進來的。

本境界的敘事節奏是四段遞進：撿別人的碎片、看洄游啃薄世界、撞上一座不肯死的舊港、在無光裡聽裂。玩家在煉虛期不是靠殺出一條路，而是靠「聽」與「辨」走進界隙最深處——到了最深處，才知道自己站的地方一直是漏口。

四張圖的主題與頭目一一對應：

| 圖 | 主題 | 頭目 | 頭目的執念 |
|---|---|---|---|
| 碎界灘 | 世界的碎屑 | 拾界人 | 撿了一輩子別人的碎片，想拼出「家」 |
| 虛獸巢帶 | 洄游帶 | 虛巢母獸 | 不攻擊，只是呼吸；牠活著，航線就塌 |
| 星骸舊港 | 星辰的殘骸 | 港守傀儡 | 照三百年前舊規驗貨，不承認港已經死了 |
| 無光海·裂 | 無光之處 | 無光老祖 | 住得最久，眼已無用，耳能聽出「裂那邊的東西」 |

## §2 城鎮：虛舟市

### 2.1 地理

虛舟市是一片以巨纜相連的舟群，漂在界隙邊緣的無光之海上。城的輪廓不是固定的：主體由一艘最大的 `錨舟` 定住位置，錨舟四周用數十條巨纜牽著三十餘艘 `支舟`，支舟隨無光之海的緩流各自擺動，纜繩一緊一鬆，整座市就像在呼吸。城沒有城門，只有泊位；靠上哪個泊，就從哪個泊入市。

- 錨舟位於中心，是舟盟總棧、公證堂與任務榜所在。
- 支舟按機能分泊：`貨棧泊`（儲貨）、`中市泊`（買賣）、`港泊`（舊物）、`深泊`（往無光海方向的補給）、`灘頭泊`（往碎界灘方向的補給）、`牆根泊棧橋`（境末出口方向）。
- 城內不配置常規野怪（沿用棲真渡、雲墟臺、望涯驛規格）。

### 2.2 風貌

- 城即舟，舟即市：店鋪開在船艙裡，攤位擺在甲板上，街道是連舟的纜橋。纜橋會晃，走慣的人不扶繩，新來的人走兩步就要扶一次。
- 認舟燈：每一艘支舟的船首掛一盞燈，燈的形制代表這艘舟的來路與行當——圓燈是貨舟，方燈是客舟，三角燈是修舟塢。舟市沒有自然光，燈就是路牌。燈油多半來自星骸舊港的港燈油，冷而不滅。
- 潮記：纜橋與艙壁上刻著一道道深淺不一的刻痕，是無光之海歷年的漲落記。舟人看潮記決定哪天出航，比看天準。
- 名舟：每艘支舟都有名，名字刻在船首，也記在舟盟的舟籍上。支舟沉了要報，名卻不銷——舟市把沉舟的名留在城冊裡，跟活舟並列。
- 聲規：無光之海的深處不能點燈，只能靠聽。因此舟市上空常年有極輕的鈴聲，由聲標風鈴發出，用來讓靠岸的船「聽著進泊」。老舟人說，進舟市要先用耳朵，眼睛在後面。

## §3 圖一：碎界灘（79-81）

### 3.1 等級段與地貌尺寸

- 等級段：`realmLv 79-81`
- 地貌尺寸：約 100×100 格；灘地自界隙邊緣向內堆疊，高低由不同世界的瓦礫堆成；主軸自 `灘頭`（入口）向灘心 `拼屋棚`（拾界人的工棚）推進。
- 通關條件：擊敗頭目 `拾界人`，完成「拾一片回去」。

### 3.2 風景特色（5 要點）

1. 異瓦層：腳下混雜著別處的瓦、別處的木、別處不知名的骨；灘壁的斷面能看到不同世界的土色一層壓著一層，像有人把好幾座城剁碎了鋪在這裡。
2. 界隙潮：灘外是界隙的緩流，退流時露出更多碎片，漲流時又把碎片捲走；拾荒者按潮記上灘，早一步晚一步，撿到的東西就不一樣。
3. 拼屋：拾界人用撿來的碎片拼出一間間不成套的屋子，屋瓦顏色各異，牆上嵌著別人家的門牌，門牌上的字沒有一個認得。
4. 無根樹：灘上長著從別界沖來的樹，根紮在碎片裡，樹種不屬於此界；樹活著，卻沒有一寸土屬於它。
5. 界縫光：灘的盡頭能看到界隙深處透出的冷光，光不隨風動，也不隨晝夜變，總停在視線邊上。

### 3.3 植物或礦物（5 種）

| 名稱 | 外觀一句 | 用途 |
|---|---|---|
| 碎界砂（總綱定名） | 界隙灘上磨得極細的混色砂，捧起來看不清是什麼顏色 | 研磨、制基、符料填充 |
| 異壤（總綱定名） | 不屬於此界的土，色澤與本地土格格不入，卻養得活東西 | 栽種、育材、培育界外靈植 |
| 隙紋蘚（自創） | 只在界縫光下生長的蘚，葉脈像蛛網一樣的裂紋 | 符墨、鎮陌、穩住鬆動地形 |
| 界骸木（自創） | 沖來的斷木，木質已半石化卻還留著年輪 | 舟具、護木、舟骨修補 |
| 拾光晶（自創） | 碎片表面凝出的小晶，夜裡能映出別的世界的一小片天 | 照明、法器芯、舟燈燈芯 |

### 3.4 妖獸（6 種）

| 名稱 | 一句特色 |
|---|---|
| 界屑蟲 | 從碎片縫裡鑽出的蟲，吃瓦礫為生，成群結隊地爬過一地就少一層 |
| 拾荒妖 | 撿碎片的人形小妖，會為了你手上那片「像它家的」圍上來 |
| 碎巢蛛 | 用碎片結網的蛛，網是碎的，看不出結在哪裡，走過去才知道 |
| 界隙鷗 | 在界隙流上盤旋的鳥，專叼閃光的東西，叼走後飛到灘盡頭就不見了 |
| 骸甲役 | 披著異界甲片爬行的獸，走起來叮噹作響，越安靜越靠近 |
| 縫間潛影 | 從界縫裡伸出的影，永遠只露出身體的一部分，抓一把碎片就縮回去 |

### 3.5 頭目：拾界人

**外型**：一個背著比自己還大的麻袋的老人，袋口永遠扎不緊，走一步漏一片。他身上穿的每一件都來自不同的世界：左袖是長袍、右肩是皮甲、腰上繫著別人的腰帶。他從不抬頭看人，只看腳下的碎片。他的臉上沒有一道疤，卻像被拼起來的，五官各是各的。

**特色**：來歷——他是最早一批在界隙裡迷航、再也回不去自家世界的人，三個世界的地名他都會說，卻沒有一個能回去。執念——他撿了一輩子別人世界的碎片，想拼出「家」；他相信碎片夠多就能拼回記憶裡那間屋子，可他想不起屋子長什麼樣，只記得屋簷下曾有一串風鈴。與地圖的關係——整片碎界灘都是他的材料堆，他熟悉每一片碎屑的來處，因此在這張圖上他永遠比玩家先一步站到有利的位置。台詞方向：「這片……像我家屋頂那片。」（至多一句）

**法術（4 個具名）**：

| 法術 | 效果方向 |
|---|---|
| 拾盡囊 | 召喚：抖開麻袋，倒出歷年攢下的碎片化為小怪圍上來 |
| 拼骨成家 | 環境／召喚：把場上碎片拼成一面不斷重組的短牆，改變走位與視線 |
| 落瓦 | 傷害：抓一把碎片擲出，單下不重但連綿，逼玩家不停移動 |
| 認親 | 控制：叫出玩家身上「像他家人的那一片」，短暫讓玩家行動遲滯（機制上為減速與封招，非真控制） |

**掉落定向**：功法殘頁《拾界錄》（步法與辨材向）、腰飾「拾界袋」部件、肩甲「拼瓦甲片」部件、材料碎界砂與異壤；頭目核心為 `拾界之囊`（袋類飾品主料）。

**戰鬥定位**：拾界人不追求高爆發，擅長把場地變成迷宮。場上未清掉的碎片越多，他的 `拼骨成家` 越強、走位越難。難點在「捨不得走」——玩家必須邊打邊清場地，而不是站樁硬拚。

### 3.6 傳送連結

## §4 圖二：虛獸巢帶（82-84）

### 4.1 等級段與地貌尺寸

- 等級段：`realmLv 82-84`
- 地貌尺寸：約 110×110 格；一條橫貫界隙的「帶」，地形由漂浮的界隙灘島與被啃薄的世界邊緣拼成；主軸沿虛獸洄游方向橫走，巢帶核心位於帶的中段。
- 通關條件：擊敗頭目 `虛巢母獸`，改通被斷的航線。

### 4.2 風景特色（5 要點）

1. 啃邊：世界邊緣被虛獸啃得半透明，走上去腳下會「軟」一下，站久了那一角就沒了；地形會隨區域事件坍缩一小塊。
2. 洄游線：成群的虛獸按固定路線游過，像一條活的河；牠們過處，原本的航線就薄一分——舟盟的航線因此年年改道。
3. 巢帶：由獸的蛻殼與啃剩的界塊堆成環帶，層層如巢；靠近時能聽見極沉的呼吸聲，整條帶隨著呼吸微微起伏。
4. 斷纜場：舟盟歷年在此折斷的纜與舟骨堆成一片墳，斷纜的半截還掛著舟名牌；這是舟盟留給後人的警示，也是航線的代價。
5. 薄界霧：世界最薄處浮著一層霧，霧裡看得到「那邊」的輪廓，卻看不真切，像隔著一層水看別人的家。

### 4.3 植物或礦物（5 種）

| 名稱 | 外觀一句 | 用途 |
|---|---|---|
| 虛空藻（總綱定名） | 漂在界隙流上的藻，根不著地，隨流擺盪 | 制餌、緩蝕、舟底防蝕塗料 |
| 蝕界涎（總綱定名） | 虛獸啃邊時留下的涎，能蝕穿尋常材料 | 淬毒、蝕刻、開銘 |
| 巢骸骨（自創） | 母獸蛻下的骨環，輕而韌，敲起來有回聲 | 舟材、護具、骨器 |
| 隙光藻（自創） | 吸界隙冷光而生的藻，夜裡泛藍，成片時像水底星空 | 照明、誘捕、聲標輔材 |
| 光塵涎（自創） | 蝕界涎曝於界隙光後凝成的粉，會自己發出微光 | 符墨、引航標、夜航照路 |

### 4.4 妖獸（6 種）

| 名稱 | 一句特色 |
|---|---|
| 蝕界虛獸 | 成群洄游的獸，所過之處世界邊緣被啃薄，航線因此改道 |
| 巢衛 | 守在巢帶外圈的巨獸，不吃人，只把人撞開，撞完就回到原位 |
| 涎喉獸 | 喉裡含著蝕界涎的獸，一噴涎，連甲帶地都蝕出洞 |
| 洄游幼崽 | 落單的幼獸，會跟著任何移動的東西走，赶不散也殺不絕 |
| 薄界魘 | 活在薄界霧裡的影，只在世界的另一邊露出半身，攻擊它的這一半沒有用 |
| 噬纜蟲 | 專啃舟纜的蟲，舟盟最恨；斷纜場的纜多半是牠咬的 |

### 4.5 頭目：虛巢母獸

**外型**：像鯨又像島的東西，看不出頭尾，身上覆著歷年蛻下的殼，殼縫裡長著別的世界沖來的小樹。牠不移動——一整條巢帶就是牠的身。牠的呼吸從不間斷，每呼一次身體就脹一次，周圍的世界邊緣便跟著塌一段。牠沒有攻擊的姿態，甚至沒有眼睛，只有一身隨呼吸起伏的殼。

**特色**：來歷——牠比舟盟更早住在界隙，靠啃世界邊緣維生，是界隙本身餵養大的東西。牠不憎恨誰，牠只是活著。與地圖的關係——舟盟恨牠，因為牠每一次呼吸，都讓一條航線消失；而玩家要開的那條被斷的航線，正從牠的身邊穿過。台詞方向：牠不說話，只有一聲像遠雷的呼吸。

**法術（4 個具名）**：

| 法術 | 效果方向 |
|---|---|
| 一次呼吸 | 環境／位移：全場地塊隨呼吸起伏，站位被動搖，部分地形暫時塌陷 |
| 洄游引潮 | 召喚：引來一圈洄游虛獸繞場環游，形成緩慢移動的傷害帶 |
| 蛻殼 | 召喚／增益：蛻下一層殼，殼化為巢衛協戰，母獸本體短暫變薄、防禦下降 |
| 啃邊 | 環境／持續傷害：場地邊緣持續被啃薄，可站立的範圍一圈圈縮小 |

**掉落定向**：功法殘頁《洄游譜》（御獸與閃避向）、飾品「虛巢筋」部件、巢衛甲片與材料巢骸骨、光塵涎；頭目核心為 `巢母之息`（飾品與舟底防蝕材料的關鍵）。

**戰鬥定位**：母獸本體不主動攻擊，難點在「場地在縮」——玩家必須在不斷收窄的立足點上輸出，同時處理被召出的洄游獸與巢衛。這是全境最考驗續航與走位的首領，不是考驗爆發。

### 4.6 傳送連結

- 入口：`碎界灘·界縫口`（完成節點一 A 簇後開啟）→ `虛獸巢帶·外灘`。
- 回城：外灘 `舟盟泊樁` → `虛舟市·中市泊`。
- 出口：巢帶另一端 `薄界隘`，完成主線節點二 A 簇後開啟，通往 `星骸舊港`。

## §5 圖三：星骸舊港（85-87）

### 5.1 等級段與地貌尺寸

- 等級段：`realmLv 85-87`
- 地貌尺寸：約 120×120 格；一座死去的「星辰」殘骸（巨大的球狀暗體）浮在界隙裡，古港建在殘骸的凹側裂口內；主軸自 `棧橋` 向 `港心倉區` 深入。
- 通關條件：擊敗頭目 `港守傀儡`，取回舊港帳本。

### 5.2 風景特色（5 要點）

1. 星辰殘骸：一整座發暗的球狀巨物，表面是熄滅的星紋；它不是石頭，敲下去有金屬的悶響。港就建在它被人鑿開的裂口裡。
2. 舊港規：港中處處是三百年前的規矩——貨要過秤、人要報名、單要蓋印；規矩還立在牆上，卻沒人知道是誰定的、為什麼還沒廢。
3. 傀儡檢貨：港守傀儡仍在驗貨，排在牠面前的貨單早已無人遞交；牠驗完一單就換下一單，驗的是空。
4. 港燈：港裡點著一種不滅的燈，燈油是從星骸裡滲出來的；燈光冷，照得見路，卻照不暖人。
5. 帳房：堆滿三百年前帳本的艙房，帳上的人名一個也認不得了；帳本卻按年份排得整整齊齊，像還有人在管。

### 5.5 頭目：港守傀儡

**外型**：一具比成年人高三尺的青銅傀儡，關節處全是補過的鉚釘。牠胸前掛著一枚早就磨平的港印，右手提著一把驗貨的鉤，左手永遠托著一本帳。牠的眼睛是兩點不滅的港燈油火，火照著帳本，卻照不到自己的腳。牠走路的聲音很規律，一步一響，像在替整座港打卡。

**特色**：來歷——三百年前舊港還活著時，牠是驗貨的管事傀儡；港民走光之後，牠沒接到停工的命令，就一直驗下去。執念——牠只認舊規，不認人，也不承認港已經死了；誰拿東西從牠面前過，都算「待驗貨」。與地圖的關係——整座舊港的規矩都靠牠一個人維繫，牠不停，港就還「活著」。台詞方向：「單呢？」（至多一句）

| 舊規 | 傷害／場控：按三百年前港規逐條執法，每一條是一道具名判罰，連續落下 |

**掉落定向**：功法殘頁《舊港規》（守位與化解向）、飾品「港守環」部件、武器部件「星骸刃」、材料星骸鐵與港燈油；頭目核心為 `港印`（飾品與舟籍相關功能的關鍵）。

## §6 圖四：無光海·裂（88-90）

### 6.1 等級段與地貌尺寸

- 等級段：`realmLv 88-90`
- 地貌尺寸：約 130×130 格；界隙最深處，全圖無光，只能以神識航行；深處一道橫貫的裂；主軸自 `無光緣`（入口）沿聲標向 `裂口` 推進。
- 通關條件：擊敗頭目 `無光老祖`，取得第四片補天殘材，完成「聽裂」。

### 6.2 風景特色（5 要點）

1. 無光：沒有光，玩家的視野被壓到最小，只能靠神識與聲音辨位；遠處偶爾一點深隙晶的微光，是唯一的座標。
2. 橫裂：界隙最深處一道橫貫的裂，裂的兩邊不同——一邊是這一邊的世界，一邊是別處；貼近裂能感到兩種「邊」貼在一起的涼。
3. 聲標：老舟人沿裂布下的聲標，是敲響會回聲的樁；聲標連成的線就是唯一的航路，斷一根就要摸黑。
4. 聽聲舟：舟盟在此航行不點燈，全靠聽；船上的舵手一輩子沒見過自己開的路，只知道哪一聲是岸、哪一聲是裂。
5. 裂那邊：貼近裂時會「聽」到裂那邊有東西經過——不是聲音，是別的世界漏過來的動靜，極輕，像隔著牆聽見隔壁翻身。

### 6.3 植物或礦物（5 種）

| 名稱 | 外觀一句 | 用途 |
|---|---|---|
| 無光露（總綱定名） | 無光處凝出的露，不反光，只在神識裡「看得見」 | 斂息、匿蹤、無光航行輔材 |
| 深隙晶（總綱定名） | 裂壁深處結的晶，內部封著極微的光，捻亮即暗 | 法器、燈芯、傳訊 |
| 骸聲木（自創） | 裂邊生長的樹，敲一下會替你把聲音傳得極遠 | 聲標、舟舵、傳聲器 |
| 隙眠苔（自創） | 覆在聲標上的苔，能吸收多餘的聲音，讓聲標只回一聲 | 斂聲、防窺、潛行 |
| 光引砂（自創） | 摻入神識可短暫「看見」輪廓的砂，用一次亮一次 | 引航、應急照明、探路 |

### 6.4 妖獸（6 種）

| 名稱 | 一句特色 |
|---|---|
| 無光獸 | 適應無光的獸，靠聽與觸感獵食，貼身才咬，咬到才現形 |

### 6.5 頭目：無光老祖

**外型**：一個瘦到見骨的老人，坐在裂邊一塊突出的岩上，一動不動。他的眼睛是閉著的，眼皮塌下去，已經沒用了——不是瞎，是他自己不再需要。他的耳朵比臉還大，耳廓張著，像在聽什麼永遠聽不完的東西。他身上的衣料是老的，看不出顏色，因為這裡沒有光。他腳邊擺著一排聲標，哪一根不響了，他就換一根。

**特色**：來歷——他是最早來到這道裂邊、住得最久的老人，比舟盟還早。他眼已無用，耳能聽出「裂那邊的東西」——不是聽聲音，是聽那邊的動靜。執念——他守的不是裂，是「別讓人聽錯」；他怕後來人把裂那邊的動靜當成這一邊的，然後把航線領進不該去的地方。與地圖的關係——整道裂的聲標都由他一個人維護，他不停，航路就還在。台詞方向：「你聽——那不是我們的。」（至多一句）

**法術（4 個具名）**：

| 法術 | 效果方向 |
|---|---|
| 聽裂 | 環境／控制：全場陷入無光，玩家被剝奪視野，只能靠招式音效與足音判斷 |
| 聲標 | 召喚／場控：敲響場上聲標，聲波沿固定路線掃過，未避開者受創並被標記 |
| 裂那邊 | 傷害／幻象：引來裂那邊的動靜具現成影，傷害不重但會擾亂站位判斷 |
| 閉目聽 | 反制／增益：老祖閉目，玩家每一次出招都在他腦中留下聲音；重複同一招會被預判 |

**掉落定向**：**第四片補天殘材**（於主線節點三 B 簇「聽裂交材」取得，非隨機掉落）、飾品「聽裂耳」部件、裂壁部件、材料深隙晶與無光露；頭目核心為 `裂聽之耳`（具備無光航行與聽聲辨位功能的關鍵部件）。

**戰鬥定位**：老祖在無光中作戰，難點在「看不見」與「不能重複」——玩家需靠聲與節奏定位，且招式需輪替，否則被預判。設計上這是全境最考驗操作與耐心的首領，但數值不高，靠機制而非碾壓。

### 6.6 傳送連結

- 入口：`星骸舊港·帳房閘門`（完成節點二 B 簇後開啟）→ `無光海·裂·無光緣`。
- 回城：無光緣 `深泊聲標` → `虛舟市·深泊`。
- 出口：裂口外 `牆根航道`，完成主線節點三且於虛舟市公證堂完成「泊籍公證」後開啟，通往合體期 `垣門外壘`。

## §9 與前後境界的敘事接縫

### 9.1 前接化神期

- 物理接口：`望涯驛·頂驛關門` 推門入隙 → `碎界灘·灘頭`。
- 敘事接口：玩家帶著第三片補天殘材與「親眼看過涯」這件事進入界隙。舟盟以驛憑樣式認出玩家來自涯上（承接化神期 §9.2）。
- 痕跡承接一·人的痕跡：望涯驛驛丞喬望山之女 `喬晚` 已隨下崖商隊離城，名籍出現在虛舟市的舟盟雇工冊上，成為引航學徒（承接化神期 §9.3 痕跡一）。
- 痕跡承接二·物的痕跡：葉望星抄的星圖拓本流落至虛舟市舊貨灘，被攤主溫拾收著（承接化神期 §9.3 痕跡二）。
- 痕跡承接三·記號的痕跡：望涯驛「一階一印」的驛印樣式出現在碎界灘的貨單上，成為識別「從涯上來的貨」的記號（承接化神期 §9.3 痕跡三）。

### 9.2 後開合體期

- 物理接口：`虛舟市·牆根泊棧橋` 登舟盟末航 → `垣門外壘` 南棧道（91-93）。
- 敘事接口：玩家帶著第四片補天殘材、舟盟舟憑，以及「劫從界隙漏入」這層認知上岸。舟盟老話「船到牆根就回頭」，玩家是第一個不回頭的人。
- 認知接口：無光老祖聽了一輩子的「裂那邊的東西」，在合體期才知道那道裂的背面就是世界之牆；此層認知由合體期展開，本境界只留接口，不越界解釋。

### 9.3 跨境界痕跡（依總綱 §6 延伸規則）

1. 留痕一·組織的分號：舟盟在 `牆根泊` 設有一間分號，專收「牆根那邊」的貨；分號舊址與帳本隨玩家下行，合體期 `垣門外壘` 的商旅仍認舟盟的舟憑。
