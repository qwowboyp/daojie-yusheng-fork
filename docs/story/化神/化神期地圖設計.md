## §0 適用範圍與前置

### 0.1 境界入口

- 唯一入口：元嬰期末圖出口 `殘響渡外港`。
- 進入方式：潮退之後，外港露出一條貼著崖腳走的石道（下崖道）。擺渡人只送到崖腳，不再往前；玩家踏上 `斷崖階·下崖渡口` 即正式進入化神期。
- 入口不可逆：化神期地圖不回連元嬰期地圖，只保留回城（望涯驛）與境內互連，讓「往上一階」在體感上是一條單向的路。

### 0.2 境界出口

- 唯一出口：`望涯驛·頂驛關門`。
- 開啟條件：完成主線節點三，並在頂驛完成「封匣過驛」交材儀式（見劇情設計 §4、§7）。
- 出口去向：越過關門即抵達煉虛期入口 `碎界灘`（79-81）。

### 0.3 境內閉環

- 四圖以階路串成一條向上的主線：斷崖階 → 律動雷原 → 古觀星台 → 涯底風獄。
- 每一圖皆有回驛道接回 `望涯驛`；驛城是境內唯一的補給、修理、交材與任務節點。
- 傳送鏈路細節見 §7。

## §1 境界敘事定位

（擴寫總綱 §4.3 主題段）

化神修士的神魂第一次能與天地相感。這種相感不是看見，是「感覺到了形狀」：天地不是無限鋪開的，它有邊。這個體感先落在修士自己身上，然後才逼著人往邊的方向走。

望涯驛就建在邊上。這座驛城背貼無盡崖壁，屋簷一律朝外，居民進門之前，習慣先看一眼涯。看一眼是做什麼用的，城裡說法不一：有人說是要記得自己住在哪裡，有人說是要記得下面還有路，也有人說，是怕哪天看完就不想進門了。

本境界主線《望涯》。斷崖階是登崖會一代一代壘出來的石階，階越壘越高，走到半途停下的人越來越多。律動雷原的雷照著某種韻律落，像是有人在打拍子，卻沒人知道打拍子的是誰。古觀星台的欄杆與刻痕全部朝著同一個方向，台上的人一代一代記錄那個方向的變化，記錄到一半斷了。涯底風獄在崖的最深處，坑裡關著從邊外吹進來的風，守獄的老人一生只記著一件事：別讓風出去。

玩家在本境界會完成三件事：

1. 沿著別人壘的階走到邊上。
2. 站上觀星台最高一階，親眼看見世界有邊，並看見邊外的天上橫著一道痕。
3. 走進風獄的坑底，明白「守」在這裡不是把誰關著，而是把什麼壓著。

看見涯之後，玩家不會得到任何解釋。天痕是什麼，玩家不知道；是誰在打拍子，沒人知道；風從哪裡來，守獄人只說「外面」。這一境界給的是實體：涯是真的，痕是真的，守是真的。剩下的留給下一境。

## §2 城鎮：望涯驛

### 2.1 地理

- 位置：世界之涯的崖階中段，一處天然的貼壁崖坪。
- 全城貼著崖壁而建，自下而上分三層：崖腳的 `下驛泊`、崖坪的 `驛街`、崖壁最上方的 `頂驛`。
- 城的正面是望不到底的涯；背面的每一扇門都開在崖壁上。城的左右兩側各有一條回驛道，分別接四張圖的入口。
- 城內不配置常規野怪（沿用棲真渡、雲墟臺規格）。

### 2.2 風貌

- 屋簷全部朝外：所有房屋的屋簷都朝涯的方向伸出，背面直接嵌進崖壁。居民進門之前習慣先看一眼涯，這個動作已經變成日常禮數。
- 階即是街：城裡沒有平路，全是緩階與平台；挑夫、驛卒、壘階人一天上下不知多少趟。
- 編號石：城牆、階沿、門框上到處能看到刻了號碼的石塊，號碼與登崖會的階圖對應。
- 風囊與繩：家家戶戶門邊掛著風囊與粗繩；風大的日子繩索全被綁死，城裡一整天只有風聲。
- 望樓與燈：夜裡各層望樓會點燈，燈的大小按當天風勢調整；風太大就只留頂驛一盞。

### 2.3 機能分區

| 分區 | 位置 | 內容 |
|---|---|---|
| 下驛泊 | 崖腳 | 收繩台、貨棧、腳伕棚；所有上崖者從這裡起步 |

## §3 圖一：斷崖階（67-69）

### 3.1 基本資訊

| 項目 | 內容 |
|---|---|
| 地圖名 | 斷崖階 |
| 主題 | 無盡石階 |
| 等級段 | 67-69 |
| 妖獸家族 | 石階系（併少量風系） |
| 地貌尺寸 | 全圖約 240×240 格；主階自南向北爬升，垂直切為 11 段階台；兩側為崖壁與空面 |
| 頭目 | 登崖石人 |

### 3.2 段落結構

1. `下崖渡口`：崖腳泊地，石階的起點；收繩台、挑夫棚、回城點。
2. `遺囊坡`：緩階段，行者遺蛻與行囊散落；背囊傀與石階行者出沒。
3. `斷階三疊`：三處斷了又補的階段，補痕年代不一；開採階紋石、風磨礫。
4. `歇腳台`：登崖會的中途補給台，已半廢；崖柏魈與歇腳影聚集。
5. `石人階`：長階；登崖石人所坐之處；首領通過後開放往律動雷原的階口。

### 3.3 風景特色

1. 石階看不到頂：能看見的階段一段比一段窄，最遠的階段細成一條線，最後沒入白氣裡。
2. 階石有年輪：每一段階石顏色不同，舊階發青、新階發白，壘階的年代一眼可辨。
3. 階沿的編號：階沿偶爾能看到刻著號碼的石塊與半埋的行囊；號碼到某一段就停了。
4. 回頭是海：走到高處回頭，元嬰期的海面橫在下面，岸線像一條沒收完的線。

### 3.4 植物與礦物

| 名稱 | 外觀（一句） | 用途 |
|---|---|---|
| 崖柏 | 貼壁而生、根扎進石縫的柏樹，樹身被風壓得朝崖外傾 | 樑柱、階欄、焚香（總綱已定） |
| 登階苔 | 只長在被踩過的階面上，越往上越厚 | 續行丹、止血藥（總綱已定） |
| 階紋石 | 斷階斷面上有天然橫紋的石，紋路像一層層的帳 | 築階修階主料，可磨成階紋粉（自創） |
| 風磨礫 | 長年被崖風打磨得圓而輕的礫石，握久了手心發熱 | 打磨材、風囊配重、投擲器（自創） |
| 懸階藤 | 從階沿垂下、藤尖卻永遠朝上長的藤 | 繩索、綁紮、止血（自創） |

### 3.5 妖獸

| 名稱 | 一句特色 |
|---|---|
| 石階行者 | 還在往上走的乾屍，走十步退一步，從不停下 |
| 背囊傀 | 死在半途的行囊成了精，馱著主人的東西繼續爬，誰碰行囊就撲誰 |
| 風剪 | 崖風裡成形的剪刀狀風影，不切肉，專切衣角與繩結 |
| 階縫蜈 | 住在階縫裡的大蜈蚣，被踩到才竄出來，一出就是一群 |
| 崖柏魈 | 老柏根成了精，用枝幹擋路，不讓人踩壞新苔 |
| 歇腳影 | 躲在階上影子裡的東西，玩家一坐下歇息，它才動 |

### 3.6 頭目：登崖石人

**外型**

一個坐在長階正中的灰白人影，衣袍已經和石面連成一體，褶皺變成岩紋。他的右手還保持著撐膝欲起的姿勢，指節鑿進階面半寸。五官還在，眼睛是兩道沒有風化的淺溝。背上的行囊也石化了，囊口朝天，裡面裝著半囊碎石。

**特色**

- 來歷：他是最早一批壘階人之一。走到這一階時坐下歇腳，就再也沒起來。不是死了，是「還在歇」。
- 執念：肉身已經石化，執念還在走。每隔一段時間他會微微前傾一次，像要起身；每一次前傾，整段長階跟著響一聲。
- 與地圖的關係：他坐在唯一的通路正中。他不主動攻擊，但誰踩上他面前那一階，誰就是「插隊的人」。
- 台詞方向：「借過一下。」

**法術**

| 法術名 | 效果方向 |
|---|---|
| 再走一階 | 前傾時階面同時震盪，站著的玩家被推向階沿，跌落回上一段（環境／傷害） |
| 借過 | 從階縫與階下喚出石階行者與背囊傀，替他清路（召喚） |
| 歇一歇 | 全身石面泛白，短時極難破防，逼停玩家的輸出節奏（自身強化／減傷） |
| 半步 | 起身半步，長階範圍內移速與命中大幅下降，階石開始鬆動（控制／場域） |

**掉落定向**

- 材料：階紋石（大量）、風磨礫、懸階藤、登階苔。
- 殘頁：《壘階錄》殘頁（登崖會壘階與樁功的殘篇）。
- 裝備部件：石人殘石（護腕、腰墜向）。
- 一般掉落：67-69 裝備部件與驛城通用物資。

**戰鬥定位（機制難點）**

- 他不追擊、不位移。難點是「不讓他起身」：起身計數一旦累滿，全階重壓，玩家有機率被推落階段，得從頭再上。
- 建議圍繞「階面起伏」設計，讓玩家在有限落腳點之間移動，體現石階主題。

**傳送連結**

- 入口：元嬰期 `殘響渡外港` → `下崖渡口`。
- 出口：`石人階` 通過後 → 律動雷原 `聽雷硿口`。
- 回城：`下崖渡口` 與 `歇腳台` 各有回驛點，接 `望涯驛·下驛泊`。

## §4 圖二：律動雷原（70-72）

### 4.1 基本資訊

| 項目 | 內容 |
|---|---|
| 地圖名 | 律動雷原 |
| 主題 | 有韻律的雷 |
| 等級段 | 70-72 |
| 妖獸家族 | 風雷系 |
| 地貌尺寸 | 全圖約 300×300 格；開闊抬升草原，中央為雷擊窪地群 |
| 頭目 | 司律雷君 |

### 4.2 段落結構

1. `聽雷硿口`：入口，一道風口；丁拾的料棚與回城點。
2. `伏草帶`：淺草伏地，草尖一律朝著雷來的方向；聽雷草、司律獸。
3. `擊雷窪`：雷擊窪地群，窪底結晶；落點蟲、律雷晶。
4. `記拍坡`：雷擊木林，木上刻滿正字；數拍魈、亂拍影。
5. `雷君土台`：首領區兼出口；雷符鴉；接古觀星台的星階隘口。

### 4.3 風景特色

1. 雷按韻律落：間隔可以數，像有人在外頭打拍子；落在空處的雷，比落下的更嚇人。
2. 草伏成圈：雷擊處的草向外伏倒成一圈圈同心紋，遠看整片草原像被指節敲過的鼓面。
3. 舊雷擊木上的記號：一格一格的刀刻，全是正字；刻到某處就亂了。
4. 天上沒有雲：雷從晴空落下，雲在更上面；有雲，但雷不理雲。

### 4.4 植物與礦物

| 名稱 | 外觀（一句） | 用途 |
|---|---|---|
| 律雷晶 | 被雷擊過的土裡結出的晶，晶裡有一段固定的亮滅節奏 | 雷系丹藥、法器核心、對拍器具（總綱已定） |
| 聽雷草 | 貼地生長的草，雷未落先伏倒 | 預判雷位、定神藥材（總綱已定） |
| 拍律藤 | 攀在雷擊木上，一節一節順著雷擊節奏生長的藤 | 定神與節律丹藥的副料（自創） |
| 律紋鐵 | 鐵礦在反覆雷擊下自然形成律紋 | 鍛造法器、驛城器具（自創） |

### 4.5 妖獸

| 名稱 | 一句特色 |
|---|---|
| 司律獸 | 會「跟拍」的獸，雷落在第幾拍，牠就在第幾拍動 |
| 雷符鴉 | 被雷劈過未死的鴉，羽上有焦痕，叫聲像雷前的悶響 |
| 數拍魈 | 蹲在草裡掰著手指數數的小妖，數錯了就發火 |
| 落點蟲 | 爬在雷擊點上的蟲，殼硬能導雷 |
| 亂拍影 | 不按韻律落雷處的影子，專挑空拍偷襲 |

### 4.6 頭目：司律雷君

**外型**

一名披著焦邊雷紋長袍的老人，袍角隨著遠近的雷聲起伏。腰間掛著一面拍牌，牌上密密麻麻刻著正字，刻痕深淺不一。左手指節全是舊灼傷，右手始終在膝上輕輕數拍。頭頂懸著一小圈發暗的雷球，隨他的呼吸明滅。腳下踩著一塊被雷擊平的土台，台面畫滿間隔刻度。

**特色**

- 來歷：聽雷人一脈最後一個還能把拍子背全的人。他的祖母教他數雷，數到第八代，雷暴真的照著記下來的譜走。
- 執念：把雷的間隔一格一格記下去，他相信總有一天能記到「第一拍」，就知道是誰在打拍子。
- 與地圖的關係：雷原本是亂的，記拍人來了之後才有了譜。他守著記拍坡的每一根雷擊木，不讓人刮掉上面的正字。
- 台詞方向：「你數到第幾拍了？」

**法術**

| 法術名 | 效果方向 |
|---|---|
| 一拍·定身 | 重拍落下，全場短暫定身（控制） |
| 三拍·連雷 | 三段落雷，第三拍最重（傷害） |
| 亂拍·錯節 | 打亂玩家的技能與步伐節奏，冷卻錯位（干擾） |
| 收拍·靜場 | 全場雷停一息，接著整片場地同時落下一次總雷（環境／爆發） |

**掉落定向**

- 材料：律雷晶、律紋鐵、拍律藤、聽雷草。
- 殘頁：《聽雷譜》殘頁（聽雷人一脈的譜法殘篇）。
- 裝備部件：司律袍部件（法袍、腰帶向）、節律法器部件。
- 一般掉落：70-72 裝備部件與雷系耗材。

**戰鬥定位（機制難點）**

- 玩家要學會「踩空拍」：雷落點與拍點對應，站在拍上必被打，站在空檔才能輸出。
- 雷君會臨時改譜，打斷玩家背下來的節奏；機制上建議把「拍」做成可讀的場地提示。

**傳送連結**

- 入口：斷崖階 `石人階` → `聽雷硿口`。
- 出口：`雷君土台` 通過後 → 古觀星台 `星階隘口`。
- 回城：`聽雷硿口` 有回驛風道，接 `望涯驛·驛街` 側門。

## §5 圖三：古觀星台（73-75）

### 5.1 基本資訊

| 項目 | 內容 |
|---|---|
| 地圖名 | 古觀星台 |
| 主題 | 觀天外的台 |
| 等級段 | 73-75 |
| 妖獸家族 | 星砂系 |
| 地貌尺寸 | 全圖約 260×260 格；三層台體加一圈星軌環道 |
| 頭目 | 守台瞽者 |
| 主線節點 | 台頂 `不語階` 為節點二高潮：玩家在此親眼見涯 |

### 5.2 段落結構

1. `星階隘口`：入口，階石上刻著曆圖線。
2. `曆圖下台`：台下石面刻滿曆算；刻痕蟲、星砂傀。
3. `器架中台`：殘破的觀星器械與軸座；星紋鐵、守台殘影。
4. `星軌環道`：外圈環道，蘚沿刻線生長；夜巡鴟。
5. `不語階與台心`：台頂見涯點；守台瞽者；眺星藤；往涯底風獄的垂降井。

### 5.3 風景特色

1. 欄杆全部朝同一個方向：欄杆一律朝外、朝上；玩家此時只覺得它們在看什麼。
2. 沒刻完的星圖：台頂刻著一段星圖，刻線到某處歪了、斷了，像一句沒寫完的話。
3. 砂裡有亮點：觀星砂在夜裡自己發亮，像有人把星星篩進了地面。
4. 台上的風是直的：別處的風打旋，這裡的風直直往同一個方向走。

### 5.4 植物與礦物

| 名稱 | 外觀（一句） | 用途 |
|---|---|---|
| 觀星砂 | 台頂積了千年的細砂，砂裡混著極小的亮點，夜裡自己會亮 | 明目藥材、拓圖定影、星砂傀儡材料（總綱已定） |
| 星紋鐵 | 觀星器械軸座用的鐵，紋路像星軌，千年不鏽 | 精密器具、飾品部件（總綱已定） |
| 星軌蘚 | 只沿著觀星台刻線生長的蘚，刻線到哪，蘚長到哪 | 拓圖輔料、定神藥材（自創） |
| 眺星藤 | 爬到欄杆上、藤尖永遠朝著天痕方向的藤 | 纖維、綁紮、藥引（自創） |

### 5.5 妖獸

| 名稱 | 一句特色 |
|---|---|
| 守台殘影 | 舊觀星人的影子還在巡台，看到有人碰星圖就擋 |
| 星砂傀 | 星砂聚成的人形，步伐照著星位走，一步不亂 |
| 夜巡鴟 | 台頂的夜梟，雙眼像兩顆星，盤旋時畫出星軌 |
| 刻痕蟲 | 啃食刻線的蟲，啃過的地方星圖就斷 |
| 落星蛾 | 順著天痕方向飛的蛾，撞到欄杆就碎成砂 |

### 5.6 頭目：守台瞽者

**外型**

一位盲眼老人，眼上覆著一條舊布，布上繡著點點星位。手杖是半截斷掉的窺管，管口朝上。身上披著褪色的觀星官袍，袍角綴著星砂，走動時有微光。腳下的台面刻著一圈圈星軌，他每一步都踩在刻線上，從不踩空。

**特色**

- 來歷：台上最後一個觀星人的後代。他生來看得見，後來為了讀完那張沒刻完的星圖，把自己的眼「看壞了」。
- 執念：把星圖刻完。可是他的刻刀已經拿不穩了，最後那段線，他刻一次歪一次。
- 與地圖的關係：他看不見玩家，靠星軌的震動知道誰站在哪顆星上。守台不是職責，是他唯一還會做的事。
- 台詞方向：「你不該踩第七顆。」

**法術**

| 法術名 | 效果方向 |
|---|---|
| 星軌引 | 沿刻線牽引玩家，把人從一個星位拖到另一個星位（位移／控制） |
| 數星 | 點名場上星位，引落星砂擊打（傷害） |
| 蔽目 | 揚起觀星砂，玩家的命中與視野受限（減益） |
| 瞽者的預判 | 讀出玩家下一步，短時反傷；看不見的人最懂「下一步」（反制） |

**掉落定向**

- 材料：觀星砂、星紋鐵、星軌蘚、眺星藤。
- 殘頁：《觀星錄》殘頁（觀星人一脈的記錄殘篇）。
- 裝備部件：星紋飾品部件（手環、額飾向）。
- 任務道具：星圖拓本（可收藏，亦為節點三儀式前置的來源之一）。
- 一般掉落：73-75 裝備部件與星砂耗材。

**戰鬥定位（機制難點）**

- 玩家要記住台面星位順序；他看不見，卻會預判。站在刻線上會被牽引，站在線外會被星砂追打。
- 打斷他的「刻圖」讀條會讓他從頭數一次星，這是可控的節奏點。

**傳送連結**

- 入口：律動雷原 `星階隘口` → 古觀星台 `星階隘口`。
- 出口：`不語階` 旁的垂降井 → 涯底風獄 `垂降井`。
- 回城：`星階隘口` 有回驛道，接 `望涯驛·驛街` 側門。

## §6 圖四：涯底風獄（76-78）

### 6.1 基本資訊

| 地貌尺寸 | 全圖約 220×220 格；環形深坑，坑壁九層壓風陣，坑心為陣眼平台 |
| 頭目 | 風獄尊者 |
| 核心產出 | 第三片補天殘材（陣心，需完成對星壓風儀式） |

### 6.2 段落結構

1. `垂降井`：入口豎井，沿崖壁垂降；獄風靈。
2. `獄門環道`：坑壁第一圈環道；風囚、鎮風石。
3. `陣壁九層`：三層平台與壓風古陣；壓壁獸、枷木傀。
4. `獄卒歇所`：舊時守獄人的飯棚與鋪位，每月送飯的老規矩在此；拖痕魈。
5. `陣心`：首領與第三片補天殘材所在，風壓最重處。

### 6.3 風景特色

1. 風是關著的：坑裡的風沿坑壁轉圈，轉到某處會撞上一道看不見的牆，折回來。
2. 坑壁刻滿壓風古陣：陣紋一路刻到人搆不到的高處，刻痕有新有舊。
3. 沒有回聲：在坑裡喊一聲，聲音被風帶走，不回來。
4. 陣眼卡著不屬於這裡的東西：坑心陣眼卡著一片材質陌生的東西，走近才認出它與玩家身上的殘材相同。

### 6.4 植物與礦物

| 名稱 | 外觀（一句） | 用途 |
|---|---|---|
| 風髓 | 風被壓進石頭裡凝成的髓，敲開石頭才見得到 | 風系法器、風囊核心、鎮縫材料（總綱已定） |
| 獄柵木 | 長在陣縫裡的木，木質紋理永遠逆著風 | 關風的柵料、陣材（總綱已定） |
| 鎮風石 | 古陣基座上的石，摸上去不涼，風繞著它走 | 陣法材料、風囊配重（自創） |
| 囚風蘚 | 只長在無風處的蘚；有它在的地方，風進不來 | 止血藥、靜室鋪材（自創） |

### 6.5 妖獸

| 名稱 | 一句特色 |
|---|---|
| 風囚 | 被關久了、忘了自己原本是什麼的風影人形，貼著坑壁走 |
| 獄風靈 | 陣眼裡生出的小風精，見縫就鑽 |
| 壓壁獸 | 四肢撐著坑壁、不肯落地的獸，一落地就被風捲 |
| 拖痕魈 | 順著別人留下的風痕爬的小妖，會把東西拖回窩裡 |
| 枷木傀 | 獄柵木的斷樁成了精，守著陣眼，不讓人靠近 |

### 6.6 頭目：風獄尊者

**外型**

一個站在陣眼上的老人，身上綁著幾十個舊繩結，結的大小不一，數不清。手裡沒有兵器，只握著一根從獄柵上鋸下的短木。衣袍朝同一側鼓起，像永遠有風從他背後吹。耳後各壓著一片鎮風石，用繩勒著。他不看人，只看腳下的陣眼。

**特色**

- 來歷：守獄人一代傳一代。到他這一代，已經沒有人來換班了。他不是被派來的，是沒走。
- 執念：「別讓風出去。」他身上的每一根繩結，都是一次曾經鬆動過的風口；解一個結，風就出去一點，所以他終生不解繩。
- 與地圖的關係：他不是看守犯人，是看守一道口子。坑裡的風恨他，也怕他。
- 台詞方向：「別開門。」

**法術**

| 法術名 | 效果方向 |
|---|---|
| 壓風式 | 以自身為陣眼壓下大範圍風壓，範圍內移動與攻擊遲滯（場域／減速） |
| 解一結 | 解開一個繩結，風壓升一階並喚出獄風靈（召喚／階段強化） |
| 風門閉 | 短時封住一塊區域的進出與技能施展（控制） |
| 逆風刃 | 借風成刃，從玩家背後繞回來（傷害／位移） |

**掉落定向**

- 材料：風髓、獄柵木、鎮風石、囚風蘚。
- 殘頁：《壓風訣》殘頁（守獄人一脈的壓風法殘篇）。
- 裝備部件：尊者腰結部件（腰帶、護臂向）。
- 核心掉落：第三片補天殘材（於陣心取得，需先完成對星壓風儀式；詳見劇情設計 §7）。
- 一般掉落：76-78 裝備部件與風系耗材。

**戰鬥定位（機制難點）**

- 分階段：他每解一結，場地風壓上升一階、可站立區域縮小一圈。
- 玩家必須在風壓填滿前壓制他，或先完成對星壓風儀式。逃跑不是選項，坑裡沒有順風的方向。

**傳送連結**

- 入口：古觀星台 `不語階` 垂降井 → `垂降井`。
- 出口：沿垂降井回程 → `望涯驛·頂驛`。
- 境界出口：`頂驛關門` 於完成封匣過驛後開啟，單向通往煉虛期 `碎界灘`。
