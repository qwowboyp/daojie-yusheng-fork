## §0 適用範圍與前置

### 0.1 境界接縫

- 入口：金丹末圖「補天殘爐」取得第一片補天殘材後，經燼燈坊主線末端開啟「劫潮海渡口」。玩家乘渡船入海，於劫潮海岸的渡口大鎮 **殘響渡** 登岸，再由殘響渡渡頭轉往外港 **漏聲灘**。
- 出口：殘響渡外港在回瀾淵線收束、第二片補天殘材交付後開啟，航線通往化神期首圖「斷崖階」。
- 過渡設計要點：金丹期玩家在劫火帶學會「劫有餘溫」；元嬰期第一次把神識放進海裡，學會「劫有回聲」。兩章共用同一場災（天穹殘宮墜落），但一在陸、一在海，互為同一事件的兩半。

### 0.2 本章主線與組織

- 主線：《潮裡的聲音》——錄聲尋源 → 沉鐘現世 → 殘片在潮裡發聲 → 循聲入海眼
- 組織：**聽潮者**——劫潮海岸上收集舊世之聲的隱修團體。他們相信沉進海裡的那半座天穹殘宮沒有真正死去，只是「沉進了水裡繼續響」。聽潮者不拜神、不煉丹，只做兩件事：錄聲、鎮魂。
- 妖獸家族基調：潮聲／海骨／沉沒系（三系互相滲透，不得串用他界家族）
- 材料家族字：聲／潮／沉／月（自創材料名一律帶其中之一；總綱既有名沿用不強改）
- 稱謂：元嬰級頭目用 真君／客／魃；不得越級使用「老祖／大能／尊者」

### 0.3 世界觀揭示層（本章份額）

- 玩家在本章第一次**聽懂潮裡的「話」**：那不是雜音，是被海水記住的舊世界殘響。
- 由此得知：「劫有源頭」——劫不是天災隨機落下，背後有來處。
- **仍不知道**：源頭在哪。玩家只拿到方向感，沒有答案。
- 母題「涯」在本章第一次以**聲音**現形：潮裡的聲音拖著一個音，聽起來像「涯」。沒人知道那是什麼字的意思。

### 0.4 「殘片發聲」的固定場景

第二片補天殘材在回瀾淵由回瀾真君鎮守。玩家取得後不直接收進揹包——殘片一離水，整片潮會**圍著殘片響一次**：潮聲退開，露出一段極短、極清楚的「話」，尾音拖著一個像「涯」的音，随即散去。這一幕是元嬰期唯一一次「殘片主動發聲」，也是玩家確信「殘片不是死物、潮不是雜音」的依據。場景細節見《元嬰期劇情設計.md》§7。

## §1 境界敘事定位

元嬰修士的神識可以離體。離體的神識第一次下到海裡，會發現一件事：海不是空的。半座天穹殘宮當年沉進劫潮，海水自那一刻起開始「記東西」——它記住的不只是殘宮本身，還有殘宮裡曾有的聲音、人、名、話。潮起時，整片海岸響起舊世界的聲音，當地人叫它「潮講話」。

本章不是「打怪撿寶」的海邊圖，而是讓玩家在**被聲音牽著走**的過程裡，一步步意識到三件事：海在說話；海說的是別人的過去；海的記憶有一條線，線的那頭通向一個更深的地方——海眼。

四張圖按「聲音的形態」遞進：

- 漏聲灘：聲音**散在灘上**，一段一段，聽不全。
- 沉鐘澥：聲音被**收在一口鐘裡**，鐘一響，十里皆聾，聽太清反而聽不見。
- 千帆骨場：聲音**鎖在航程裡**，一群沒有終點的人反覆啟航。
- 回瀾淵：聲音**從海眼出來**，潮從此出、也從此歸；這裡是所有聲音的來處與去處。

## §2 城鎮：殘響渡

### 2.1 地理

- 位置：劫潮海岸中段，一段隆起的舊海堤與礁臺之上。堤內是鎮，堤外是海。
- 地形：前堤後崖，街巷沿堤脊鋪開，越往內地勢越高；外港在堤的東南角，港口無天然屏障，全靠「聲堤」——一圈以錄聲貝嵌成的舊堤，把最兇的潮聲擋在鎮外。
- 與海關係：鎮子離潮太近，潮起時全鎮能聽見海在「說話」；因此殘響渡的屋子一律把窗開向內陸，門朝海的一側掛貝。

### 2.2 風貌

- 屋簷低壓，多為補了又補的舊木與沉船板；牆面嵌碎貝、刻聲紋。
- 每戶門上掛一只「錄聲貝」，記錄戶主最後一次離家時說的話——沒回來的人，貝還掛著。
- 街面鋪的不是石板，是壓平的舊船甲板；走上去有空洞的回聲。
- 鎮中央有一口不敲的鐘，鐘身焊死，聽潮者叫它「默鐘」——象徵只聽不說。
- 潮起時，整鎮會短暫靜默，人人停下手上的事，聽一遍海；潮落才復工。

### 2.3 機能分區

- **聽潮臺**：鎮子最高處的礁臺，聽潮者議事與錄聲尋源的起點。玩家入鎮第一落點。
- **聲市**：錄聲貝、聲材、潮材、月材的交易區；也賣「聽過的話」——一整段潮裡錄下的舊聲，裝在貝裡按段賣。
- **渡頭**：擺渡人調度處，通往漏聲灘等外港；也是殘響渡與外界唯一的常規出入口。
- **靜室**：鎮魂調息區。潮聲聽久了會「入耳」，需在此以默聲之法把耳裡的舊話清出去。
- **修貝巷**：修補錄聲貝、整備聲器、材料回收的匠作區。
- **錄聲館**：聽潮者的檔案庫，存放歷年錄下的聲，按「聽得懂的／聽不懂的／不敢再聽的」三欄分架。

### 2.4 NPC 群像（8 人）

| NPC | 身份 | 作用 | 一句人設 |
|---|---|---|---|
| 聞潮叔·岑老 | 聽潮者宿老，錄聲尋源的主持者 | 主線交接、殘片發聲的見證者、交材儀式主持 | 他聽了一輩子潮，只承認自己聽懂過一句半 |
| 渡頭執事·商引 | 殘響渡擺渡調度 | 主線入圖、外港開啟、跨境界航線審批 | 他記得住每一條航線的潮期，卻記不住任何一個乘客的臉 |
| 聲市掌櫃·檀娘 | 聲市主人，收售聲材 | 材料回收、聲市買賣、支線觸發 | 什麼聲音都敢收，唯獨不肯收自己丈夫那段 |
| 修貝匠·蒲老 | 修貝巷匠人 | 裝備與聲器整備、材料鑑定 | 他能從一只貝的裂縫聽出它最後錄的是哪句話 |

### 2.5 設施與機能

- 傳送：鎮內各分區之間以固定傳送點連通；渡頭設通往四圖外港的傳送陣（需主線推進解鎖）。
- 交易：聲市（材料/聲材/消耗品）、修貝巷（裝備部件/聲器）。
- 恢復：靜室提供狀態清除與「聽聲入耳」的本章專屬負面狀態處理。
- 任務：聽潮臺（主線）、渡頭（入圖）、聲市與靜室（支線）。
- 倉儲與其他：沿用既有城鎮機能口徑，不新增系統。
- 無常規野怪（沿棲真渡/雲墟臺規格）；潮聲在鎮內只作氛圍，不結算傷害。

## §3 圖一：漏聲灘（realmLv 55-57）

### 3.1 基本定位

- 主題：**會說話的灘**——退潮時露出成片舊船骸，每艘船的殘艙裡都留著一段「循環的話」。
- 等級段：55-57
- 地貌尺寸：`58×50`（橫長灘地，潮線斜切，退潮區與漲潮區分層）
- 位置：殘響渡外港首站；劫潮海岸最外的一圈淺灘。

### 3.2 風景特色

1. **潮線即界線**：灘分兩層——漲潮時全淹的外灘、退潮才露的內灘。內灘的舊船骸一退潮就「開艙」，一段段循環的話從艙裡漏出來。
2. **會說話的殘艙**：每艘船骸的艙裡鎖著一段短話，反覆播放；靠近能聽清幾個字，但永遠聽不完全。這是本圖最核心的景觀語言。
3. **聲紋砂**：灘上細砂被潮聲震出同心紋，踩上去會把足音「存」進去，幾息後在別處重播。
4. **灘螢藻夜光**：退潮凹窪裡的藻類，夜裡隨潮聲一亮一暗，像灘在呼吸。
5. **無風的浪**：外灘的浪不隨風動，只隨鐘聲（沉鐘澥方向）定節奏，為下一圖埋伏筆。

### 3.3 植物／礦物（5 種）

| 名稱 | 外觀一句 | 用途 |
|---|---|---|
| 錄聲貝 | 巴掌大、殼面有同心聲紋的灰白貝 | 錄一段聲、鎮一次魂；本境界核心聲器材料 |
| 潮音石 | 灰藍色、敲之有回音的圓石 | 鎮潮、製聲器底座；素材主料之一 |
| 灘螢藻 | 退潮凹窪裡會隨聲發光的細藻 | 消耗品輔料、靜室鎮魂配方 |
| 聲紋砂 | 被聲震出同心紋的細砂 | 記錄類材料、任務交付物 |
| 月落灘鹽 | 月夜退潮結在灘面的薄鹽 | 凝神、聽潮調息類消耗品材料 |

### 3.4 妖獸（5 種）

| 名稱 | 一句特色 |
|---|---|
| 潮聲鬼 | 由灘上散落的話聚成的半透明形，會用你聽過的聲音喊你 |
| 貝甲沙民 | 背著大貝的灘民殘念，動作慢，一出手是一整片沙 |
| 拾聲童 | 由童聲聚成的小妖，會模仿誰喊過的名字引你走 |
| 錄聲水母 | 半透明水母，觸手纏著一段循環的話，纏身即靜音 |
| 回音螺 | 只會複述的螺妖，把你的上一擊原樣打回你自己 |

### 3.5 頭目：螺中客

- **外型**：一個瘦高的流浪者，赤腳，腰間掛著七八只小貝。背上一只巨螺，比他本人還高，螺口用舊布堵著。他走起路來微微側身，像永遠在讓開什麼。他的眼睛是濁的，不看你，只看海。
- **特色**：他是聽潮者最早的一批「錄聲人」之一。年輕時他把聽到的每一段話都收進自己的螺裡，聽了一輩子，螺裡最後只剩一個名字——他自己也記不清是誰的名字。他在灘上不停走，是為了找那個名字的主人；找到之前，他不肯讓螺裡的聲音停。台詞方向：「你別急著聽清。聽清了的，都走不遠。」
- **法術攻擊**：
  1. `螺音喚名`：召出灘上數段舊聲化形為幻影，幻影會用玩家的舊識之聲喊話，干擾判斷。
  2. `回聲疊刃`：把玩家剛打出的一次傷害記下、延遲反打，傷害越高回升越重。
  3. `聽海成牢`：以一圈聲場把玩家定在原地數息，需以位移或默聲之法打斷。
  4. `名字的重量`：螺中那一個名字落地成壓，範圍內持續承受壓力與減速。
- **掉落定向**：殘材線指向回瀾淵（本圖不掉殘材）；掉 錄聲貝 群、`螺紋聲環` 部件（頭部/飾品）、聽潮者功法殘頁。機制難點：不能硬衝——硬打會被回聲疊刃放大，需在「喊名」的間隙輸出。

### 3.6 傳送連結

- 殘響渡渡頭 ↔ 漏聲灘外灘（主入口，需主線節點一解鎖）
- 漏聲灘內灘深處 ↔ 沉鐘澥淺海（主線節點二解鎖）
- 漏聲灘設回殘響渡的回城傳送點（入口附近）
- 前接：金丹期「劫潮海渡口」→ 殘響渡 → 漏聲灘

## §4 圖二：沉鐘澥（realmLv 58-60）

### 4.1 基本定位

- 主題：**海底天鐘**——內海海床沉著一口天鐘，鐘身刻滿無人識得的紋；鐘一響，十里皆聾。
- 等級段：58-60
- 地貌尺寸：`62×56`（內海盆地，中央為鐘坑，四周環繞聾水帶）
- 位置：漏聲灘以內的海域，海水在此深且靜。

### 4.2 風景特色

1. **沉鐘之坑**：海床中央陷出一個巨大鐘形坑，天鐘半埋其中，鐘口朝下。鐘身的紋繞著鐘身一圈圈，像被誰刻了一輩子還沒刻完。
2. **聾水帶**：鐘響過後，水會短暫「失聲」——這片水域聽不到任何聲音，連自己的心跳也聽不見，是本章最壓迫的環境。
3. **銅鏽落雨**：鐘身剝落的銅鏽在水中緩緩下沉，觸之如酸；鏽落之處會長出聲歸藻。
4. **回聲牆**：海床四周的岩壁把鐘聲來回反射，聲音在牆間疊成「一句聽不清的話」。
5. **敲鐘的節奏**：鐘並非亂響，而是按一個固定的間隔一響；當地人說那是「有人在敲，只是看不見人」。

### 4.3 植物／礦物（5 種）

| 名稱 | 外觀一句 | 用途 |
|---|---|---|
| 沉鐘鱗 | 從鐘身剝落的青銅薄片，邊緣帶聲紋 | 聲器/防具主料，本圖核心產出 |
| 海魂珊 | 鐘坑邊生長的暗紅珊瑚，隨鐘響開合 | 消耗品輔料、魂息類配方 |
| 聲歸藻 | 銅鏽沉處長出的銅綠色藻 | 材料，用於鎮聾、洗耳配方 |
| 潮鎖苔 | 附在回聲牆上的藍灰苔蘚 | 材料，用於固定聲場類裝備 |
| 沉月砂 | 鐘坑底積的月色細砂 | 凝神類消耗品材料 |

### 4.4 妖獸（5 種）

| 名稱 | 一句特色 |
|---|---|
| 聾鰩 | 鐘聲中唯一不聾的鰩，循聲偷襲，聽得見的反而最兇 |
| 鐘鏽蟹 | 由鐘身銅鏽剝落所化的硬甲蟹，周身帶蝕性鏽霧 |
| 撐鐘傀 | 沉在鐘下撐鐘的枯骨殘念，鐘一沉就被壓醒 |
| 靜潮僧影 | 當年敲鐘誦經者的殘影，不攻擊，只在旁邊跟著數拍 |
| 海魂珊蟲 | 寄在海魂珊裡的小蟲，成群時能讓整片水「嗡嗡」作響 |

### 4.5 頭目：守鐘魃

- **外型**：一具與天鐘長在一起的人形——他的下半身已經融進鐘身，上半身還保持著敲鐘的姿勢，一隻手永遠舉著。皮膚是銅綠色的，臉上沒有表情，只有一口一合的嘴在數數。鐘身上有一圈凹陷，正是他幾百年來敲出來的。
- **特色**：他是當年的敲鐘者之一。天穹殘宮沉海的那一夜，他被指派留守鐘樓，敲鐘示警；鐘還沒敲完，海已經蓋了上來。他與鐘融為一體，殘念只剩一句「不能停」。他不是在攻擊誰——他是在繼續敲鐘，因為他相信只要鐘不停，外面的人就還聽得見警。台詞方向：「不能停。停了，他們就聽不見了。」
- **法術攻擊**：
  1. `一響十里聾`：全場沉默，玩家短期內無法施法、無法聽見提示。
  2. `鐘波盪海`：環形聲波擊退並打斷動作，靠牆會被二次震盪。
  3. `銅鏽落雨`：鐘身剝鏽，範圍持續腐蝕與降防。
  4. `不能停`：每次被強制打停一次，敲鐘間隔就縮短一次，愈打愈快。
- **掉落定向**：本圖不掉殘材；掉 沉鐘鱗、`鐘耳殘片` 部件（護符/法器）、聽潮者功法殘頁、鐘身紋拓（任務交付物）。機制難點：不能一味打斷——打斷越多鐘越快，須在鐘響的空檔處理本體與鐘身的連結。

### 4.6 傳送連結

- 漏聲灘內灘深處 ↔ 沉鐘澥淺海（主入口）
- 沉鐘澥鐘坑深處 ↔ 千帆骨場邊緣（主線節點二解鎖）
- 回殘響渡回城傳送點（淺海入口處）
- 前接：漏聲灘；後開：千帆骨場

## §5 圖三：千帆骨場（realmLv 61-63）

### 5.1 基本定位

- 主題：**船隊墳場**——上古渡劫船隊的墳場，桅杆化石成林，帆化白骨。
- 等級段：61-63
- 地貌尺寸：`66×58`（廣闊沙場，桅林密布，船骸成排）
- 位置：沉鐘澥以遠的淺海沙脊，海水最淺、骨最多。

### 5.2 風景特色

1. **桅林**：成百上千根桅杆斜插沙中，早已石化成灰白林柱；風過時，柱間發出像帆鼓動的空響。
2. **帆骨**：帆布朽盡，只剩白骨的帆架還張著，遠看像一整片不肯落下的帆。
3. **斷舟之街**：船骸沿一條早已不存在的航道排成一列，像一支永遠沒開完的船隊。
4. **無終航線**：整片骨場的地形順著古航道往同一個方向傾斜，走進去會不由自主順著走，像被航程牽著。
5. **船首像群**：每艘船骸的船首都立著一只船首像，姿態全部朝前，沒有一只回頭。

### 5.3 植物／礦物（5 種）

| 名稱 | 外觀一句 | 用途 |
|---|---|---|
| 帆骨木 | 石化成骨的帆架木，輕而韌 | 弓/杖類主料，本圖核心產出 |
| 怨桅鐵 | 嵌在桅柱鐵箍裡的舊鐵，帶怨氣 | 武器/防具部件材料 |
| 沉舟脂 | 從船骸注水孔滲出的深色油膏 | 消耗品輔料、防腐類配方 |
| 潮骨藤 | 纏繞桅柱而生的白藤 | 材料，用於綁縛類聲器 |
| 月帆棉 | 帆骨間殘留的舊棉絮，月色 | 消耗品材料，用於修帆、修聲器 |

### 5.4 妖獸（5 種）

| 名稱 | 一句特色 |
|---|---|
| 帆骨妖 | 骨帆成妖，一張一合之間刮起割骨風 |
| 桅影 | 桅柱投下的影子裡走出的人形，只在逆光時可打 |
| 骨浪手 | 從沙下骨浪裡伸出的手，成片抓扯 |
| 碎槳魂 | 附在斷槳上的殘念，會把你當「要划的方向」推 |
| 船首啞僕 | 船首像的隨從，無聲衝撞，撞上才知痛 |

### 5.5 頭目：斷桅將軍

- **外型**：最後一艘船的船首像活了過來。他是一尊半是木、半是骨的人像，斷了一根桅臂，斷口插著一截殘帆。身上披著早已看不出顏色的舊旗。他站姿筆直，面朝前方，無論你從哪個方向來，他都不回頭。他的腳下始終有一小片水——那是他的船，雖然已經不存在了。
- **特色**：他是那支渡劫船隊最後一艘船的船首像。船隊受命航向一個「更高的地方」，途中遇到劫潮，全隊沉沒；船首像留在船首，記住了「啟航」這件事，卻沒有記住「抵達」。他守著一段沒有終點的航程，認為只要他還站著，船隊就還在航行，總有一天能到。台詞方向：「船還沒到。你們先別下。」
- **法術攻擊**：
  1. `斷桅橫掃`：以斷桅作長兵器橫掃，大範圍擊退並破防。
  2. `船首衝角`：循航線直線衝撞，被撞者順航道被推遠。
  3. `骨帆蔽日`：張開殘帆遮住天光，召出桅影群協同。
  4. `無終航程`：把玩家納入「航程」，持續朝同一方向位移，離開航道才解除。
- **掉落定向**：本圖不掉殘材；掉 帆骨木、怨桅鐵、`斷桅旗骨` 部件（飾品/披風）、聽潮者功法殘頁、船隊名冊殘頁（任務交付物）。機制難點：全場在「被牽著走」，需利用航道反方向的地形反制。

### 5.6 傳送連結

- 沉鐘澥鐘坑深處 ↔ 千帆骨場邊緣（主入口）
- 千帆骨場最深處 ↔ 回瀾淵外環（主線節點三解鎖）
- 回殘響渡回城傳送點（骨場入口）
- 前接：沉鐘澥；後開：回瀾淵

## §6 圖四：回瀾淵（realmLv 64-66）

### 6.1 基本定位

- 主題：**海眼**——海中央的無底漩渦，淵底隱約有光；潮從此出，也從此歸。
- 等級段：64-66
- 地貌尺寸：`60×60`（環形結構，外環為潮牆、中環為迴聲廊、內環為海眼）
- 位置：劫潮海域最正中，所有潮聲的來處與去處。

### 6.2 風景特色

1. **海眼**：海中央一個望不到底的漩渦，水一圈圈往下轉；淵底有極淡的光，像是有人在很深的地方點了燈。
2. **潮牆**：繞著海眼立起的水牆，由無數層折疊的潮聲疊成，穿牆時會聽見自己一生聽過的所有聲音同時響起。
3. **迴聲廊**：中環一圈順著漩渦盤旋的廊道，你說的每一句話都會在幾息後從背後回來，回來的聲音比你自己的更慢、更沉。
4. **沉宮殘影**：淵壁上隨處可見半沉的天穹殘宮構件——樑、柱、瓦，其上紋樣與金丹期劫火帶出土的殘件同源。
5. **潮的進出**：此處潮不漲不落，只有一個方向——往淵裡去；像是海把聽到的東西全部收進這裡。

### 6.3 植物／礦物（5 種）

| 名稱 | 外觀一句 | 用途 |
|---|---|---|
| 回瀾晶 | 受海眼旋壓而生的螺旋狀透明晶 | 本圖核心產出，聲器/法寶類主料 |
| 深月露 | 淵壁凹處凝的月色水珠 | 元嬰期高階消耗品主料 |
| 聲底砂 | 淵底積的極細砂，握之能聽見極遠的聲 | 任務交付物、聲器輔料 |
| 沉光螺 | 吸了淵底光、殼內發亮的螺 | 材料，用於照明/探測類聲器 |
| 潮心核 | 海眼核心凝出的水核，隨潮搏動 | 高階符/核類材料 |

### 6.4 妖獸（5 種）

| 名稱 | 一句特色 |
|---|---|
| 迴聲獸 | 會把你說過的每一句話變成攻擊打回來的獸 |
| 深壓妖 | 生於深水重壓之下，攻擊帶「壓」，越深越強 |
| 無面潮使 | 潮裡走出的無面使者，替海眼「傳話」 |
| 捲瀾鰻 | 纏著漩渦盤旋的長鰻，把你往下拖 |
| 沉光傀 | 淵底光屑聚成的傀儡，遇聲則亮、遇靜則隱 |

### 6.5 頭目：回瀾真君

- **外型**：一個看上去不過中年的男子，一身早已泡得發白、卻仍整齊的沉宮舊臣服色。他沒有影子——他的影子在腳下的水裡，與他不同步。他一手攏在袖中，另一手時常虛按在耳邊，像隨時在聽什麼。他說話極慢，每個字都像從很深的地方撈上來。
- **特色**：他是那半座天穹殘宮沉海時留在宮中的舊臣。海蓋上來時，他沒有逃——他守在宮裡，靠聽潮活了三百年。他把潮裡所有聽得懂的、聽不懂的都聽了一遍，最後認定自己不是被困的人，而是「報信的」：他相信潮裡的話是外面傳進來的消息，只要他繼續聽、繼續轉達，總有一天會有人順著聲音找到這裡。台詞方向：「你來了就好。我這裡，攢了三百年的話，不知道該往哪裡送。」
- **法術攻擊**：
  1. `回瀾聽潮`：預讀玩家下一個動作，提前位移或格擋。
  2. `潮生潮滅`：拉扯玩家的位置，把目標往海眼方向吸。
  3. `三百年一語`：延遲數息後落下一記極重一擊，對應他「話說得慢」。
  4. `海眼開闔`：使場地可站區域週期性收縮，逼玩家在極窄的落點上取捨。
- **掉落定向**：**第二片補天殘材**（本境界殘材，於本圖取得）；掉 回瀾晶、深月露、`瀾心舊臣珮` 部件（核心飾品）、聽潮者功法殘卷。機制難點：他的「聽潮」會懲罰重複同一套連招，需多變起手；海眼開闔逼站位，不能站樁。

### 6.6 傳送連結

- 千帆骨場最深處 ↔ 回瀾淵外環（主入口）
- 回瀾淵內環（海眼）為本圖終點，擊敗回瀾真君後開啟回程與外港航線
- 回殘響渡回城傳送點（外環）
- 後開：殘響渡外港 → 化神期「斷崖階」

## §9 與前後境界的敘事接縫

### 9.1 前接金丹

- 金丹期在劫火帶追查隕鐵來源，得到「天穹殘宮不是唯一掉下來的東西」與第一片補天殘材。
- 元嬰期承接同一場災的另一半：那半座沉進海裡的殘宮。金丹期玩家看的是「劫火燒出來的地」，元嬰期看的是「海水記住的聲」。
- 入口無需重講金丹劇情：玩家帶著第一片殘材與「劫有餘波」的認知，從劫潮海渡口登岸，殘響渡的人只關心他「聽不聽得見」。

### 9.2 後開化神

- 回瀾淵證明：海眼是潮聲的來處與去處，淵底的光與沉宮同源，而沉宮「來自更高的地方」——這個「更高」在本章只是一個方向，不給答案。
- 玩家帶著這份方向感上崖，化神期第一次親眼望見世界的邊——「涯」。
- 跨境界留痕（詳見劇情設計 §2、§5）：
  - 記名僧·石默的名冊最後一頁永遠空白；他會託玩家把一枚「同聲之貝」帶去下一境界，交給任何一個還願意聽的人。
  - 守默婆·沉姑留下的一塊殘碑拓，載著一段聽不全的潮聲——後在化神期崖階上被認出與「涯」音同源。
  - 聽潮者組織本身留下一句口號式的規矩：「只聽，不答。」這句規矩會以刻字形式出現在化神期斷崖階的石階上。

### 9.3 命名建議

- 本隊自創名詞（NPC 名、材料名、妖獸名、局部小地名）皆已避開既有 40 圖地名/材料名。經檢索，暫無與總綱衝突之處。
- 若總編認為「殘響渡」與其他境界城鎮的字感不齊，建議僅作記錄，本隊不擅自改動，統一由總編裁決。
