## §0 適用範圍與前置

### 0.1 境界接縫

- 入口：大乘末圖「天痕下坡」坡頂，鎮涯關頂關的登劫道開啟後，道口外即是 **劫雲海**。玩家完成《守關》全線並在天痕下的合鳴窪完成第六片殘材合鳴，方得放行。
- 出口：天人五衰崖頂可見天門舊址的光；《薪火》節點三 B 簇完成、確認最後一願後，飛昇台開放，進入飛昇終章（127）。
- 過渡設計要點：大乘期玩家明白自己「是最後一排」；渡劫期玩家承接這件事的下半句——**最後一排之後，只剩自己**。三劫不是外敵，是自己走到終點前必須親手了斷的三件事。

### 0.2 本章主線與組織

- 主線：《薪火》——三劫備戰 → 心魔鏡城中與「心中我」了斷 → 天人五衰崖上確認最後一願 → 登飛昇台
- 組織：**薪火守**——最後的守火人。相傳每一次道劫前夜，都有人把一簇火留在人間；火種不斷，人族就能重來。薪火守不問來處、不看出身，只看一件事：你願不願意在登門之前，把火接過去。
- 妖獸家族基調：劫雲／雷液／心魔系（三系分屬三圖，第四圖為衰相系，仍取本境三系混生形態，不得串用他界家族）
- 材料家族字：劫／雷／心／衰／薪（自創材料名一律帶其中之一，不得撞既有 40 圖材料名）
- 稱謂：渡劫級頭目用 君／守／我真身／法身；不得越級使用「老祖／大能／尊者」

### 0.3 世界觀揭示層（本章份額）

- 玩家在本章登臨飛昇台前，已從大乘期得知：天痕是舊天門的傷口，劫風雷罰皆是症狀。
- 本章推進最後一層：**道劫全貌**在飛昇終章揭曉，本章只把玩家逼到門前，讓玩家自己確認「要不要跨」。
- 母題「涯」在本章收口：涯＝天門檻。跨過涯，就是飛昇。這個答案不在本章說死，留給終章儀式。
- **不得一語道破**：三劫是每個人的劫，無法替人承受；薪火守知道火要傳下去，卻不知道火從何來。

### 0.4 「登門一念」的固定場景

《薪火》節點三收束後，天人五衰崖頂。玩家在崖頂望向天門舊址的光；薪火守把最後一簇薪火交到玩家手上，說：「這個火，不是給你的。是給門後面的人看的。」玩家在此**確認最後一願**——不是許願，是承認自己帶著什麼上路。這一幕是渡劫期唯一一次「火離開人間」，也是飛昇終章的引信。場景細節見《渡劫期劇情設計.md》§7。

## §1 境界敘事定位

渡劫不是變強，是**把自己結算一次**。

修士走到人間絕巔，前面的路已經沒有海拔可以爬——只剩下自己身上三件沒了結的事：雷劫（外力對你的考驗）、心魔劫（你自己對自己的清算）、天人劫（你與天地、與必朽之間的和解）。這三劫不是敵人派來的，是修到這一步必然要遇見的。

薪火城是本章唯一的落腳點。這座城中央燃著一簇不滅薪火，全城只有一個方向：向上。城裡的人不是不怕——他們是怕過了，還選擇把日子過下去、把火接下去。四張圖按「劫的三種面目＋終局」遞進：

- 劫雲海：劫**在頭上翻**，你乘穿雲舟從雲底穿過，滿天是別人的天劫。
- 雷池第九重：劫**在腳下滾**，第九重的水不是水，是雷液；池底有人影在走。
- 心魔鏡城：劫**在心裡住**，它具現成一座城，城裡全是你的舊人、舊債、舊憾。
- 天人五衰崖：劫**在身上退**，天人五衰之相依次顯現——這不是打敗誰，是看懂了衰。

## §2 城鎮：薪火城

### 2.1 地理

- 位置：天痕正下方的一片高臺地上，四面無險可守，全靠這座城自己站著。
- 地形：城不大，近乎圓，中央是薪火臺，街巷以薪火臺為心一圈圈向外；越靠外越矮，像是整座城都在往中央看。
- 與天痕關係：城的正上方就是那道裂，夜裡能看見痕裡的光。城中屋頂一律向內斜——不是為了擋風，是為了不讓雨打進薪火臺。

### 2.2 風貌

- 城中央一簇不滅薪火，無柴而燃，火色偏暖白。傳說薪火斷則人族絕；全城沒人敢賭這句話是假的。
- 全城只有一個方向：向上。巷子往上修，階梯往上鑿，連晾衣桿都朝上斜。
- 城牆不高，牆上嵌滿「登門牌」——每一位登過飛昇台的先人一面，絕大多數是空的。
- 街上最多的聲音是磨刀、補甲、唸經，沒有人喊價——最後一段路上，錢沒用。
- 城門只有一道，朝下；象徵進城的人都知道，來處在下面。

### 2.3 機能分區

- **薪火臺**：城心，薪火所在，玩家入城第一落點；薪火守駐此。
- **登門坡**：通往天人五衰崖的坡道起點，飛昇台方向；分「備劫」「問願」兩級臺階。
- **記劫樓**：薪火守的檔案與記劫處，存放三劫記錄與遺址清冊。
- **補天坊**：整備最後裝備、殘材校驗、七片拼圖的拼合準備區。
- **照心廊**：心魔劫的預備區，供修士在入鏡城前先照一次自己的心。
- **守火居**：薪火守起居與傳火之處；也是「最後一願」確認後領取薪火的地方。

### 2.4 NPC 群像（8 人）

| NPC | 身份 | 作用 | 一句人設 |
|---|---|---|---|
| 守火人·柏明 | 薪火守首席，本境主線交接者 | 主線交接、第七片殘材交付、登門一念主持 | 他一生只做一件事：不讓手裡的火熄，也從不問火從哪來 |

| 造舟匠·魯直 | 穿雲舟匠，唯一敢在劫雲裡行舟的人 | 入圖交通、裝備整備、支線「不翻之舟」 | 他說穿雲舟不是造來贏的，是造來回來的 |

### 2.5 設施與機能

- 傳送：城內分區以固定傳送點連通；登門坡設通往四圖的傳送陣（需主線推進解鎖）。
- 交易：補天坊（裝備最後整備、材料回收）、薪火臺側（消耗品）。
- 恢復：照心廊（心魔前淨心）、診衰人處（五衰狀態處理）。
- 任務：薪火臺（主線）、登門坡（入圖）、記劫樓與守火居（支線）。
- 倉儲與其他：沿用既有城鎮機能口徑，不新增系統。
- 無常規野怪（沿棲真渡/雲墟臺規格）；劫雲在城頂只作氛圍，不結算傷害。

## §3 圖一：劫雲海（realmLv 115-117）

### 3.1 基本定位

- 主題：**雲的海**——終年翻湧的劫雲海，雲層裡有電光人影；穿雲舟是唯一渡法。
- 等級段：115-117
- 地貌尺寸：`64×60`（立體縱深為主，雲層分下、中、上三層）
- 位置：薪火城之下、天痕之下第一片劫場；登劫道的第一段。

### 3.2 風景特色

1. **無底的雲海**：腳下沒有地，只有翻湧的劫雲；離舟即墜，墜落會一直墜到「下面」，是以幾乎沒人敢離舟。
2. **雲中電光人影**：雲層裡不時閃過電光，電光裡站著人影——那是歷來在此渡劫失敗者的殘影，他們仍在重複自己最後一次的劫。
3. **穿雲航道**：唯一可走的是一條「穿雲航道」，航道隨雲流日日改道，需以舟勢順之，逆則翻。
4. **劫雲的顏色**：雲有深淺，越深處劫越重；淺雲能行舟，深雲會吸舟。
5. **雲上垂落的天痕光**：天痕的光從上方垂直落下，雲層被照亮處像開了一扇扇不會進人的門。

### 3.3 植物／礦物（4 種）

| 名稱 | 外觀一句 | 用途 |
|---|---|---|
| 劫雲絮 | 從雲層邊緣凝下的絮狀物，觸之微麻 | 劫材主料、穿雲舟續航 |
| 避雷梭 | 生在航道兩側的梭形輕材，能引雷偏轉 | 避雷、製舟與護具部件 |
| 劫渡苔 | 附在穿雲舟底的灰藍苔蘚，隨劫強弱變色 | 材料，用於舟體防劫與感應 |
| 雲雷髓 | 劫雲深處凝出的雷芯，握之耳鳴 | 高階消耗品主料、雷系強化 |

### 3.4 妖獸（5 種，劫雲系）

| 名稱 | 一句特色 |
|---|---|
| 劫雲獸 | 生於劫雲的獸，身影半透，隨雲流捲人入雲 |
| 雲中人影 | 渡劫失敗者的殘影，不主動攻擊，卻會把玩家拉進「重演」 |
| 穿雲鴉 | 成群在航道上亂竄的鴉，撞舟即散，散後引雷 |
| 電光鱗 | 雲層裡游動的帶電鱗片，遇舟則聚成電網 |
| 雲噬蠅 | 專噬舟帆的細小飛蠅，一群能把一艘舟啃成骨架 |

### 3.5 頭目：劫雲君

- **外型**：劫雲裡最早凝成的那一團。它沒有一具完整的身形——勉強看得出是一個披著舊袍的人形輪廓，由翻湧的劫雲擠成，五官是雲的凹洞。它周身不停有細雷炸開，衣袍下擺一直在淌電。它說話時不張嘴，聲音從整片雲裡同時響起。
- **特色**：它是這片劫雲海裡「最早的那一團」——上一次道劫留下的第一縷劫氣，三百年來越滾越大，成了君。它不記得自己是誰，只記得**每一次天劫是怎麼落下的**；它守在航道上，不是攔人，是「提醒」——它認為所有想上去的人都該先經歷一遍它記得的天劫。台詞方向：「我記得每一道。你也會被我記住。」
- **法術攻擊**：
  1. `劫雲覆頂`：遮蔽航道，使穿雲舟短時失去方向，玩家在雲中迷航。
  2. `重演`：召出一個渡劫失敗者的殘影，重演其最後一擊，逐次累加威力。
  3. `細雷成林`：周身細雷落地成柱，布成雷林封路。
  4. `記得你`：記下玩家首次使用的主要招式，其後每隔數息以此招反打一次。
- **掉落定向**：本圖不掉殘材；掉 劫雲絮、避雷梭、`穿雲舟骨` 部件（舟/披風）、劫系功法殘頁。機制難點：戰場是「沒有地的雲」，需在舟上取捨位移，離舟即敗。

### 3.6 傳送連結

- 薪火城登門坡 ↔ 劫雲海航道口（主入口，主線節點一解鎖）
- 劫雲海航道盡頭 ↔ 雷池第九重上緣（主線節點一 B 簇解鎖）
- 劫雲海設回薪火城的回城傳送點（航道口）
- 前接：大乘期「天痕下坡」→ 鎮涯關頂關 → 劫雲海

## §4 圖二：雷池第九重（realmLv 118-120）

### 4.1 基本定位

- 主題：**雷池最深處**——傳說雷池有九重，第九重的水不是水，是雷液；池底有人影在走。
- 等級段：118-120
- 地貌尺寸：`58×58`（環形下沉結構，八重邊壁環繞，中為第九重池心）
- 位置：劫雲海之下；越往下劫越實，到了第九重，劫已凝成「水」。

### 4.2 風景特色

1. **雷液之池**：池中的「水」是流動的雷，表面有細密的電紋走動；踏錯處即被電牢扣住。
2. **八重雷壁**：環繞第九重的八重雷池壁，逐重電色加深，壁上刻著歷代渡劫者留下的「到此一重」記號。
3. **池底人影**：雷液之下隱約可見人形在走，步伐整齊，像在排隊；他們不看你，只往同一個方向走。
4. **冷與暖**：此地雷不燒人，只「溫」人——被雷液浸過之處不痛，卻會冷上一世。這也是雷池守那句問話的來處。
5. **無聲之雷**：第九重的雷不響，只有極低的震動；耳朵聽不見，骨頭聽得見。

### 4.3 植物／礦物（4 種）

| 名稱 | 外觀一句 | 用途 |
|---|---|---|
| 雷髓 | 雷液沉澱結成的髓狀晶，觸之光冷 | 本圖核心產出，雷系主料 |
| 池底砂 | 雷池底積的細砂，砂粒間仍有電 | 消耗品輔料、導雷材料 |
| 雷池藻 | 生於雷液邊緣的白藻，隨電紋開合 | 材料，用於抗雷與護脈 |
| 液雷砂 | 雷液凝成半固態的砂，能儲雷 | 高階符/核類材料 |

### 4.4 妖獸（6 種，雷液系）

| 名稱 | 一句特色 |
|---|---|
| 雷池靈 | 由雷液凝成的靈體，動作隨電紋，擊中會短路般亂竄 |
| 液雷獸 | 液態巨獸，被斬即散、散後復聚，須以導雷之法斷其根 |
| 雷池鰐 | 潛在雷液下的硬甲鰐，一咬即拖人入池 |
| 液雷蛭 | 附在池壁吸雷的小蛭，成群時能抽空一片雷液 |
| 第九影 | 池底排隊人影裡落單的一個，走近才發現它在等替 |
| 溫雷蛾 | 撲向「尚暖之人」的蛾，被撲者體溫漸失 |

### 4.5 頭目：雷池守·第九

- **外型**：一具由雷液撐起的人形，身高逾丈，通體半透，體內的雷紋像血脈般流動。它沒有明顯的臉，只有一處凹陷如口。它站在第九重池心，一動不動時幾乎與雷液一體，只有走近才看得出那是「站著的雷」。它身邊的地面永遠是乾的——雷不敢沾它。
- **特色**：它是第九重雷池的守者。雷池本是熬人的地方，歷來有人熬不過、有人熬過；它是熬到最後、被雷池留下的那一個——成了守，不再是修士。它不阻人入池，只問一句；答錯的，它就讓人「留下來當水」。它記不清自己答對過什麼，只記得那個問題。台詞方向：「來渡劫，還是來取暖？」
- **法術攻擊**：
  1. `九重鎖雷`：以雷液鎖住腳步，被困者每動一次，雷鏈緊一分。
  2. `液雷覆頂`：整片雷液上湧，將全場變成淺池，逼玩家在導電地面取捨。
  3. `問一句`：以問題為法，玩家若不應，威力逐息遞增；若亂應，反噬自己。
  4. `當水`：對「答錯者」施加持續下沉，緩慢拖入池底人影之列。
- **掉落定向**：本圖不掉殘材；掉 雷髓、液雷砂、`雷池守甲` 部件（甲/護符）、雷系功法殘頁。機制難點：全場為導電地面，位移本身就是風險；「問一句」逼玩家在戰鬥中做出選擇而非站樁。

### 4.6 傳送連結

- 劫雲海航道盡頭 ↔ 雷池第九重上緣（主入口）
- 雷池第九重池心深處 ↔ 心魔鏡城城門外（主線節點一收束後解鎖）
- 回薪火城回城傳送點（上緣）
- 前接：劫雲海；後開：心魔鏡城

## §5 圖三：心魔鏡城（realmLv 121-123）

### 5.1 基本定位

- 主題：**心魔劫具現**——心魔劫具現成一座「城」，城裡住著玩家的執念：舊人、舊債、舊憾。
- 等級段：121-123
- 地貌尺寸：`60×54`（城鎮式結構，街巷迷宮化，中心為鏡心）
- 位置：三劫之中最內的一重；不是地理上的地方，是心魔的具現。

### 5.2 風景特色

1. **鏡城**：整座城是鏡面築的，街道兩側的牆映出玩家，但映出的「自己」動作總慢半拍、或先一步。
2. **執念之街**：街巷按玩家的過往重組——走過的路、住過的屋、去過的地，都能在這裡遇見一個「該在卻不在」的人。
3. **舊人舊債**：城裡有玩家這一路的舊識殘影，他們不說責備的話，只重複當年的某一句；那句話比刀重。
4. **無出口的巷**：城的道路會隨玩家的心念改變——越想出去，巷越深；不想出去時，出口才在腳邊。
5. **鏡心**：城的正中心是一片鏡面空地，也是「心中我」所在之處；鏡心之上無天，只有玩家的倒影。

### 5.3 植物／礦物（4 種）

| 名稱 | 外觀一句 | 用途 |
|---|---|---|
| 心魔藤 | 攀滿鏡牆的黑藤，反射心念而生 | 心系主料、鏡心相關 |
| 鏡心花 | 開在鏡心旁的白色花，花瓣會映人 | 高階消耗品主料、淨心 |
| 心執苔 | 附在舊人殘影足下的暗苔，觸之心緒翻湧 | 材料，心劫相關配方 |
| 心鏡砂 | 鏡心地面磨出的細砂，映得出人影卻照不出臉 | 任務交付、鏡系輔料 |

### 5.4 妖獸（6 種，心魔系）

| 名稱 | 一句特色 |
|---|---|
| 執念形 | 由玩家執念聚成的形，會變成你最不想面對的那個人 |
| 心上影 | 玩家心魔的碎片，只在你分神時出手 |
| 舊人像 | 城裡舊識的殘影，不像敵人，更像當面質問 |
| 憾影 | 由「假如當初」聚成的影，會誘你走回過去的路 |
| 鏡中人偶 | 鏡牆裡走出的人偶，動作與玩家同步，打它等於打鏡 |
| 悔意蛾 | 撲向悔意而生的蛾，纏身時讓人反覆想起同一句話 |

### 5.5 頭目：心中我

- **外型**：與玩家一模一樣的身形，僅有的差別是它的影子在腳下，而玩家的影子在身後。它穿著玩家走這一路以來的行頭——不是現有的，是玩家「本可能成為」的那一套。它說話用玩家的聲音，語氣卻更平靜，像一個早就想通了的自己。
- **特色**：它不抹黑玩家，**它太誠實**。它會用玩家這一路的每一個選擇反問玩家——那些為了活下去做的、為了走更高做的、沒能救下的、沒能回頭的。它不是來殺玩家的，是來討一個「承認」。台詞方向：「你打得過我，是因為我就是你。你打不過我，也是。」
- **法術攻擊**：
  1. `如你所為`：完全複製玩家最近的打法，並用它反問。
  2. `舊人之聲`：招出玩家過往舊識的殘影，殘影重複當年的話，亂其心神。
  3. `非此即彼`：把一個兩難擺在玩家面前，逼玩家在兩種「失去」之間選一個；無正確答案。
  4. `心魔本相`：當玩家停止攻擊、選擇承認時，它不還手——這一階段不是考輸出，是考「過不過得去自己這關」。
- **掉落定向**：本圖不掉殘材；掉 心魔藤、鏡心花、`照心鏡骨` 部件（飾品/法器）、心系功法殘卷。機制難點：全程「不能只靠輸出」——某些階段（尤其終段）以「選擇」而非傷害推進，逼玩家面對自己的路線。

### 5.6 傳送連結

- 雷池第九重池心深處 ↔ 心魔鏡城城門外（主入口）
- 心魔鏡城鏡心深處 ↔ 天人五衰崖崖腳（主線節點二收束後解鎖）
- 回薪火城回城傳送點（城門外）
- 前接：雷池第九重；後開：天人五衰崖

## §6 圖四：天人五衰崖（realmLv 124-126）

### 6.1 基本定位

- 主題：**五衰之相**——渡劫前最後一崖，天人五衰之相依次顯現；崖頂可見天門舊址的光。
- 等級段：124-126
- 地貌尺寸：`62×60`（一面貼崖而上的陡階崖，崖頂為平緩望門臺）
- 位置：薪火城之上、飛昇台之下的最後一道崖。

### 6.2 風景特色

1. **五衰之階**：貼崖而上的階梯分五段，每上一段，天人五衰之相依次顯現一次——不是幻覺，是自己身上的實相被照出來。
2. **崖頂望門臺**：崖頂一片平緩臺地，正上方即是天門舊址的光；站在原地仰望，光的形狀像一道門框。
3. **衣袍自行褪色**：崖上之物，衣袍、兵刃、甲胄都會慢慢褪色；色褪盡處，物性也淡。
4. **不落之塵**：五衰之相顯現時，空中會浮起細塵，聚而不落，像整個天地都在慢慢認可「你該退了」。
5. **崖根的薪火光**：崖下能看見薪火城的那點火；越往上，火越像一粒米——這是本地圖唯一的「暖」，也是玩家退路的象徵。

### 6.3 植物／礦物（4 種）

| 名稱 | 外觀一句 | 用途 |
|---|---|---|
| 五衰花 | 開在五衰之階的花，花瓣隨衰相一瓣一瓣落下 | 衰系主料、抗衰配方 |
| 薪火葉 | 生在崖根、被薪火光暖著的葉，是此地唯一不褪色之物 | 高階消耗品主料、護脈 |
| 衰筋鐵 | 五衰之相凝出的鐵，色灰而脆，能定人 | 材料，用於封衰類器 |
| 薪燼苔 | 寄生於薪火葉背的絨苔，觸之回暖 | 材料，續火與回溫 |

### 6.4 妖獸（5 種，衰相系）

| 名稱 | 一句特色 |
|---|---|
| 衰相妖 | 五衰之相凝成的妖，會讓玩家身上顯出對應的衰相 |
| 末路獸 | 走到盡頭卻不肯停的獸，攻擊帶著「再往前一步就回不了頭」的勢 |
| 五衰影 | 玩家自己的一衰之相，擊敗它只是承認了那一衰，不代表躲過 |
| 衰骨鴉 | 啄食褪色之物的鴉，被啄處連同物性一起淡去 |
| 歸墟鹿 | 只在崖頂出沒的鹿，安靜不攻擊，像早一步到了的人的坐騎 |

### 6.5 頭目：五衰法身

- **外型**：五衰之相依次凝聚而成的一具法身，身高隨五衰逐段變化——每顯一衰，身形就薄一分。它不是實體，更像一件被歲月穿舊了的舊衣，撐在一個不肯散的人形上。它的面容始終模糊，越到後段越淡，直到只剩一線輪廓。
- **特色**：它不是誰的心魔，是**五衰本身**凝成的法身。它不憎恨玩家，也不阻人——它只是讓「衰」有了一個可以被面對的樣子。擊敗它不代表躲過衰，只代表看懂了衰：人都要衰，火要傳下去，火不傳才算真衰。台詞方向：「你打敗的不是我。是我讓你看見的東西。」
- **法術攻擊**：
  1. `一衰`：顯「衣色褪」，持續削減玩家增益與防護。
  2. `二衰`：顯「身力散」，降低移動與攻擊的穩定。
  3. `三衰`：顯「神識昏」，干擾視野與提示。
  4. `五衰同現`：五衰齊顯，全場進入「褪色」狀態；此階段不是考硬打，是考玩家是否還記得自己為何而登門。
- **掉落定向**：本圖不掉殘材；掉 五衰花、薪火葉、`望門舊衣` 部件（披風/核心飾品）、薪火系功法殘頁。機制難點：全程是「減法」——玩家各項能力被逐段削弱，須在被削盡之前看懂五衰、走到崖頂。

### 6.6 傳送連結

- 心魔鏡城鏡心深處 ↔ 天人五衰崖崖腳（主入口）
- 天人五衰崖崖頂望門臺 → 飛昇台（節點三收束、確認最後一願後開啟，進入終章 127）
- 回薪火城回城傳送點（崖腳）
- 前接：心魔鏡城；後開：飛昇終章

## §9 與前後境界的敘事接縫

### 9.1 前接大乘

- 大乘期在鎮涯關守望，確認七次補天失敗的遺址，於合鳴窪完成第六片殘材合鳴。
- 大乘期「留痕」在本章落地（承接《大乘期地圖設計.md》§9.2、《大乘期劇情設計.md》§2.2）：
  - **留痕一·守望調令**：薪火城守望信使·常渡認得守望的印，憑調令為玩家辦理入城備檔。
  - **留痕二·遺址清冊殘頁**：記劫官·紀冬收下清冊殘頁副本，將其與三劫記錄併檔；那一頁日期欄填著、狀態欄空著。
  - **留痕三·頂關燈的託付**：蘇盞託的那句話「那邊的燈比這裡亮，替我看看」，在薪火臺上被柏明接住——他只回一句：「替我謝他。」
- 天痕使傳下來的那一句（大乘期「上面問：……幾時換班」），在薪火城被記劫官紀冬收進檔中，作為終章問答的一條伏線。

### 9.2 後開飛昇終章

- 玩家在天人五衰崖頂確認最後一願，領受薪火，踏上飛昇台。
- 七片補天殘材在本章集齊，於終章合璧；道劫全貌在終章揭曉。
- 本章留給終章的三件事（不在本章說死）：
  1. 七片殘材合璧能否重開天門。
  2. 「涯」＝天門檻究竟意味著什麼。
  3. 上去之後是什麼——留白。
- 跨境界留痕：薪火城的薪火由玩家帶上飛昇台；空了的薪火臺在城中央留下一處舊火痕，成為後來者所見的「門開之前的城」。
