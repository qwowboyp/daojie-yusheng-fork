## §1 終章定位

### 1.1 問題意識

前七個境界問的都是「你能不能走到這裡」。終章問的是最後一句：**「上去之後，是什麼？」**

終章不回答這句話。它做的是：把七片殘材合上、把天門打開、把道劫的來處說清楚，然後**把門檻留在畫面裡，讓玩家自己跨**。真相給全，但「門後面」永遠留白——這是全作的收束方式，不是遺漏。

### 1.2 氛圍關鍵詞（6 個）

- 七片合一
- 門檻就是涯
- 天門重開
- 劫有來處，補有前人
- 人間開始修復（以年為單位）
- 上去之後，是什麼

### 1.3 終章不做的事

- 不評判玩家這一路的選擇（不給「功過總結」）。
- 不把「上去之後」寫成任何具體的新世界（不開新專名）。
- 不寫世界毀滅、不寫毀天滅地的大戰。
- 不替全服玩家判定唯一結局（多人共存的默認仍成立）。

## §2 儀式序列

終章由四段主體＋一段收尾構成，逐段承接總綱 §4.8。

### 2.1 第一段：台前·七片合璧

**類型**：`submit_item` → 場景演出

**內容**：

1. 玩家於飛昇台前取出七片補天殘材。它們在玩家這一路的手上聚齊——自金丹期劫火帶的第一片，到渡劫期薪火守交付的第七片。
2. 殘材一同觸發「合鳴」：先是輕響，再是共振；七片的紋路在台心上自行對合，缺口互相咬住，像七塊拼圖終於知道自己是同一面鏡子。
3. **天門（舊仙界通道）自天痕中重開。** 天痕那道裂第一次不是「更開」，而是「歸位」——痕的邊緣向內收了一寸，光從痕裡透下來，是暖的。
4. 薪火在玩家手上亮了一次，與天門的光相認。

**敘事作用**：兌現總綱 §1.5 與 §4.8（七片殘材合璧於飛昇台）。這一段是全作最大的一次「物歸其位」。

### 2.2 第二段：真相·道劫全貌

**類型**：`talk` → 場景演出（不設獨白式長篇；拆成多個「他人所說」的碎片，由玩家自行拼合）

**內容**（總綱 §1.3 第七層揭曉）：

1. **道劫＝上古一次「開天門」（仙界通道開啟）的失敗。** 失敗的餘波砸落人間，是為道劫。這不是天譴，不是神罰，是一次「差一點成功」的嘗試留下的傷。
2. **天穹殘宮＝上一次的渡台。** 凡人期看到的墜落殘宮、練氣期的五行錯層帶、金丹期的劫火帶、元嬰期的劫潮海……都是同一件事的碎片：有人曾在此建台、登門、失敗。
3. **宮主＝那一次的守門人。** 母題「涯」的來處收口：守門人留下的半句遺言與「涯」有關；涯即天門檻——跨過涯，就是飛昇。玩家站在這裡才明白，七境的「涯」理解是一條線。
4. **七片殘材＝補天一脈七次失敗的遺證。** 每一片都是一次「重鑄天空」的嘗試留下的殘料；玩家集齊的不是寶物，是七次沒成功的決心。

**呈現方式**：不設單一「揭曉者」。真相由三處並置，玩家自行拼合：

- 天門內透出的舊聲（呼應元嬰期「潮裡的聲音」——那半座沉宮記住的聲音，在此第一次聽全）。
- 記劫官紀冬檔中歷代登門者的記錄（承接渡劫期支線「清冊末欄」）。
- 宮主遺言的回響（承接凡人篇 `chapter-06-liu-bai.md` 已鋪的半句）。

**紅線**：真相雖給全，但不設「一語道破的總答案」句式；不分角色長篇獨白。玩家若不去拼，仍只是一個模糊的輪廓——這是刻意保留的解釋自由度。

### 2.3 第三段：登門·帶著什麼上去

**類型**：`talk` → `realm_stage` → 場景演出

**內容**：

1. 天門已開。薪火城的薪火在玩家手上；城裡的火弱了一分，全城向上望。
2. 玩家把薪火帶到門檻前。這裡是全作唯一一次「火離開人間」——但火不是被熄滅、也不是被獨佔，是**被帶上去**。
3. `realm_stage`：飛昇。玩家跨過涯（門檻），完成飛昇階段確認。
4. 畫面收在門檻：玩家的背影跨過去，光把輪廓收沒；門外是什麼，畫面不給。

**敘事作用**：承接渡劫期「薪火不是給你的，是給門後面的人看的」。玩家帶上去的不是力量，是一點火。

### 2.4 第四段：人間·劫餘

**類型**：場景演出（全服可見的狀態變化，非個人結算）

**內容**（總綱 §4.8）：

1. **世界不會被判死。** 門開之後，劫風漸歇，天痕緩慢癒合——以「年」為單位。
2. 人間開始修復。薪火城仍在，火種仍在；後來者見到的是一座「門開之前的城」，以及一處舊火痕。
3. 各境界的「劫餘」在此第一次顯出意義：雲來鎮（凡人）、棲真渡（練氣）、雲墟臺（築基）、燼燈坊、殘響渡、望涯驛、虛舟市、天垣城、鎮涯關、薪火城——它們不是廢墟，是熬過來的鎮。
4. 修復是緩慢的、在地的、不戲劇化的：潮線退半格、燈多亮一夜、孩子學會走路先學會頂風。寫堅韌，不寫狂歡。

**紅線**：不寫「世界得救」的宏大收尾；不寫「劫從此消失」。癒合以年計，且未完成——留給未來版本。

### 2.5 收尾：上去之後，是什麼

**類型**：留白（無任務、無演出強制）

**內容**：

- 終章收束在一句不作答的話上。玩家跨過門檻之後見到什麼，遊戲不給。
- 結局不寫死：門仍可再開，涯外之涯仍可再做文章，為未來版本留門。
- 呼應「劫餘」之名：故事結束在修復開始處，而不是在毀滅結束處。

> 註：第三至第五片來源以各境界子文檔為準；本文檔只承接其「集齊」結果，不重複設計。

### 4.2 合璧演出

1. 七片於飛昇台前合鳴。合鳴不是爆炸式特效，是「對位」——七道紋路像七道舊傷，終於找到彼此的邊。
2. 天門自天痕中重開。天痕邊緣向內收，光透下來，是暖的。
3. 薪火與天門的光相認。玩家帶火登門。
4. 合璧之後，殘材不復為殘片——它是完整天門的一部分。玩家不再持有「道具」，只帶走「一件事：有人試過七次」。

### 4.3 敘事約束

- 合璧是「物的歸位」，不是「力量的覺醒」。不寫「玩家因此變強」。
- 七片的意義是「七次失敗的遺證」——集齊七片，等於替七代人把話說完，這是終章最重的一層情感。

## §5 道劫真相全貌（七層揭示收束）

終章是全作真相的唯一一次「合攏」。以下七層為各境界逐步揭開的結果，在門前並置呈現（表現方式見 §2.2 三處並置）：

| 層 | 境界 | 揭開內容 |
|---|---|---|
| 1 | 金丹 | 天穹殘宮不是唯一從天上掉下來的東西 |
| 2 | 元嬰 | 劫潮裡有舊世界的聲音，劫有源頭 |
| 3 | 化神 | 世界有邊，邊外有天痕 |
| 4 | 煉虛 | 世界之外還有世界碎片，劫從界隙漏入 |
| 5 | 合體 | 天垣是人為的擋劫之牆，牆後是真相；補天計畫為何失敗 |
| 6 | 大乘 | 天痕是舊天門的傷口，劫風雷罰皆是症狀 |
| 7 | 渡劫／飛昇 | 道劫全貌；七片殘材合璧可重開天門 |

**收束口徑**：

- 第 7 層的答案不是「天門能補」，而是「有人試過，失敗了，並把這件事傳了下來」。成功與否，終章不判——只把門打開。
- 「牆是誰築的／補天為何失敗」等問題，在合體、大乘兩層已給出各自的答；終章不再補答。
- 真相是全作的，不是玩家一人的。寫「很多人一起知道的真相」，不寫「主角發現的獨家秘密」。

## §6 母題「涯」的收口

總綱 §1.4 的遞進線在終章收口：

- 金丹：匠修說「涯」是老坊志裡的古地名，指劫火帶的盡頭。
- 元嬰：潮裡的聲音拖著一個音，像「涯」。
- 化神：玩家親眼望見天涯——世界的邊緣。
- 合體：涯外之涯——牆後還有一道涯。
- 渡劫／飛昇：**涯＝天門檻。跨過涯，就是飛昇。**

**收口方式**：

1. 宮主遺言的半句話在門前被補全語境——不是補全字句（原句仍半截），而是玩家終於聽懂它指的是什麼。
2. 「涯」不再是一個地方，是一道門檻的讀音。七境的走動，都是在朝這道檻靠近。
3. 終章不把「涯」寫成一個具體地名或新專名——它保持為一個「理解」，而非一個新設定。

## §7 開放式收尾

### 7.1 不寫死的三件事

1. **上去之後是什麼**——畫面不給，敘事不答。這是全作最大的一塊留白。
2. **劫會不會再來**——癒合以年計，且未完成。留給未來版本。
3. **玩家與世界的後續**——不給個人結算，不給「從此幸福」的收尾；玩家跨過門檻，世界繼續過日子。

### 7.2 為未來版本留的門

- **涯外之涯**：門後仍可能是另一道涯——此門不關，是續作的介面。
- **薪火未斷**：薪火城的火種仍在，後來者仍可走到門前；世界長期可玩。
- **七片已合，天門已開，但亦可再開**：不把天門寫成一次性消耗品，為版本迭代保留敘事空間。

### 7.3 與「劫餘」之名的呼應

故事不結束在毀滅，也不結束在勝利，而是結束在**修復的開始**。人間仍在過日子——潮線退半格、燈多亮一夜、孩子學會走路先學會頂風。這才是「劫餘」的完整意思：不是劫後餘生的慘，是劫裡餘下的那點堅持。

## §8 全章紅線

1. **不寫死結局**：結局收束在留白，不寫「世界得救」或「劫從此消失」。
2. **不設一語道破的總答案**：真相給全，但由三處並置、玩家自行拼合；不設長篇獨白揭曉。
3. **不寫世界毀滅**：修復以年計，未完成；寫堅韌，不寫末世。
4. **不新增總綱之外的跨境界專名**：登場者、地名、殘材名一律用既有。
5. **不評判玩家選擇**：不設「功過總結」，不因玩家的路線改寫結局好壞。
6. **不寫新世界**：門後具體為何，永不落字。
7. **不搬用任何既有作品專有名詞**。
8. **多人共存默認成立**：終章不判定唯一結局；同服玩家各自走完自己的門前即可。
