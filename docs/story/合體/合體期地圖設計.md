## §0 適用範圍與前置（前境界接縫、入口方式）

### 0.1 本境界的入口

界隙深處的航線走到底，不是虛無，是一道牆。煉虛期的舟盟把船停在牆根，這一段泊位被舟人叫作「牆根泊」。玩家自煉虛末圖「無光海·裂」順裂而下，抵達本境界第一張圖垣門外壘的南棧道。無光老祖聽了一輩子「裂那邊的東西」，到了這裡才知道，那道裂的背面就是這道牆。

垣門外壘的南棧道是進入天垣城的唯一陸路。古城門就在外壘的盡頭，門上有匾，匾上的字已經被風磨平，只認得出一個「垣」字。

### 0.2 本境界的出口

通關天垣城關樓後，關樓外即是劫風口（大乘期 103-105）。本境界出口不直接開給剛入城的玩家，需完成主線節點三並取得關樓通行。

### 0.3 命名與家族約束

- 妖獸家族：鏡影系、法晶系、垣石系，三系依圖分工，不得與他界家族串用。
- 材料家族字：垣／鏡／法。四圖材料名稱一律帶其中一字（總綱 §4.5 已定名者沿用：垣晶、舊壘鐵、鏡我蓮、照心萍、法骸晶、啞陵草、井心苔、垣髓）。
- 頭目名號一律以總綱 §4.5 為準，不得更名。
- 本境界自創名詞僅限：NPC 名、材料名、妖獸名、局部小地名與設施名，且皆已避開既有 40 圖地名與材料名。

### 0.4 世界觀揭示層（本境界只能揭到這裡）

- 玩家在本境界得知：天垣是人為築起的擋劫之牆，牆後是真相。
- 玩家在本境界仍不知道：補天計畫為何失敗。法骸陵裡只葬結局，不葬答案；歷代補天者全部沒有好下場，且成功者一個都沒有埋在那裡。
- 牆上的門後是什麼，本境界從頭到尾不揭。垣衛的規矩只回答「怎麼守」，不回答「為什麼」。

## §1 境界敘事定位

合體修士天人合一，在牆根下第一次「感覺」到牆的意圖：它在擋什麼。

玩家從界隙上岸，眼前的景象比任何一張圖都硬：牆是直的、壘是疊的、名字是刻上去的。這是一個把所有東西都做成「制度」的地方。垣衛守牆，靠的是點名；出去的人要報名，回來的人要應名；一頁名冊的最後一行永遠留空。玩家在四張圖裡會反覆撞上同一件事：這裡的人不談牆後有什麼，只談誰還在、誰沒回來。

本境界的敘事節奏是四段遞進：牆下照規矩報名、澤心照見自己、陵中看見前人的結局、井心被問最後一句話。玩家在合體期不是變得更強才過關，而是被一層一層問住之後，還願意往上走。

四張圖的主題與頭目一一對應：

| 圖 | 主題 | 頭目 | 頭目問的那句話 |
|---|---|---|---|
| 垣門外壘 | 牆門外的舊戰場 | 守垣將 | 還有誰沒到 |
| 鏡我之澤 | 另一個自己 | 鏡我 | 你是誰（以你的聲音反問） |
| 法骸陵 | 法則的墓地 | 葬法老人 | 你們還在用這些法嗎 |
| 垣心之井 | 牆心的豎井 | 垣心守 | 你上去，是替誰看 |

## §2 城鎮：天垣城

### 2.1 地理

天垣城建在世界之牆的南根下，城的北牆不是城牆，就是世界之牆的牆體本身。城的輪廓順著牆根鋪開，成一彎長弧；東西向的主街全部與牆平行。關樓貼著牆體而建，是全城最高處，也是唯一能上牆與下井的入口。牆上的門正對關樓北側，門前有一段空出來的石坪，坪上不許擺攤、不許晾曬、不許停留。門常年閉著。

### 2.2 風貌

全城的屋頂都朝牆外側斜。當地人的說法是「讓劫風把東西吹走，別往城裡落」。城裡每隔一段路立一根名柱，柱身刻滿未歸者的名字，一面刻滿就換下一面，一根刻滿就換下一根。夜裡關樓會點一盞候名燈，燈亮著，代表今夜還在點名；燈滅了，才輪到城裡的更夫喊「今夜無人未歸」。

城裡沒有大型廣場，最寬的地方是名冊房前的名柱廣場，柱影拉得長，白天總有人站在柱下找自己認識的名字。

## §3 圖一：垣門外壘（91-93）

### 3.1 等級段與地貌尺寸

- 等級段：`realmLv 91-93`
- 地貌尺寸：約 120×120 格；主軸自南棧道向北逐層抬升，共七層壘台；最高處為點名石台，台下是進城的舊道。
- 通關條件：擊敗頭目守垣將，完成「收名」。

### 3.2 風景特色（5 要點）

1. 壘台層疊：七層舊壘一層壓著一層，石料顏色一代比一代深，像把歷年的敗仗砌進了牆裡。
2. 點名石台：外壘最高處的圓形石台，台面被腳步磨得發亮，台下插著一圈沒拔走的舊旗。
3. 門樓遠影：從壘上任何一段抬頭，都能看見世界之牆上的門樓；門樓沒有旗，也沒有燈。
4. 牆根晶脈：牆體與壘牆的接縫處長出淡金色垣晶簇，夜裡會亮，像牆在呼吸。
5. 風聲成句：穿過壘道的風被舊旗與斷戟切碎，聽起來像有人在遠處點名。

### 3.3 植物與礦物（5 種）

| 名稱 | 外觀（一句） | 用途 |
|---|---|---|
| 垣晶 | 嵌在壘縫裡的淡金晶簇，夜裡泛著牆根的光 | 合體期防具與陣材主料 |
| 舊壘鐵 | 不同年代疊壓的壘牆鐵屑，斷口還留著舊符紋 | 鍛兵與修壘 |
| 垣階苔 | 只長在壘階背風處的鐵灰色苔 | 煉製斂息丹，藏形匿氣 |
| 垣銘石 | 被歷代點名聲浸泡過的白色殘石，貼耳能聽見模糊的回名 | 製傳名符與陣眼 |
| 垣燼砂 | 舊名冊焚盡後沉積的細砂，混著沒燒透的字畫 | 書符與殘頁修補 |

### 3.4 妖獸（6 種，垣石系）

| 名稱 | 一句特色 |
|---|---|
| 壘衛殘魂 | 穿著各代壘甲、仍在沿壘巡邏的半透明殘影 |
| 撞門獸 | 撞角已經磨平的巨獸，一生只會朝門的方向頂 |
| 名砂傀 | 由垣燼砂與碎甲聚成的人形，誰靠近就朝誰伸手點名 |
| 垣壁行者 | 貼著牆面爬行的石化武者，像在修牆，其實在等人 |
| 舊甲蟻 | 以舊壘鐵為食的鐵蟻，會把掉落的甲片拖回巢裡補牆 |
| 望門鴉 | 不吃不喝的灰鴉，只落在門樓方向，歪著頭看門 |

### 3.5 頭目：守垣將

**四問一·外型**

一身舊甲由七代壘甲的碎片焊成，顏色深淺不一，像地層。右手永遠舉著一卷點名冊，左手按刀不拔。鎧縫裡長出細細的垣晶，像牆縫裡凝出的霜。他的臉被盔影蓋住，只看見下頷一動一動，像在念字。名冊每翻一頁，四周的殘魂便應聲直起。

**四問二·特色（來歷與執念）**

最後一任守門將。門關上那一夜，他奉命守在外壘，他知道門後不能進，卻不知道為什麼。他點名等全員歸列，點到最後，名冊上只剩他一個。他不承認那叫做結局，於是每晚重來一次。

- 與地圖的關係：整座外壘是他點名的場地，七層壘台就是歷代「守門失敗」的層層堆疊。
- 台詞方向（至多一句）：「守垣將……到。」（他點自己的名，自己應）

**四問三·法術（4 個具名）**

| 法術 | 效果方向 | 對應地圖主題 |
|---|---|---|
| 點名 | 喊出一串無人應答的名字；被點到者若不站回指定守位，持續受軍令反噬 | 點名制度 |
| 合冊壓陣 | 名冊高舉，歷代守門人的名字化成壘牆虛影壓落，範圍傷害附短暫定身 | 層層疊疊的舊壘 |
| 守位不移 | 站在點名石台時減傷大幅提升；玩家必須把他引離石台 | 守位與規矩 |
| 末列歸營 | 低血階段把外壘殘魂全數點回，殘魂歸位時爆開；每少一個殘魂，他的攻勢便漲一分 | 名冊上只剩他一個 |

**四問四·掉落定向**

- 材料：舊壘鐵、垣晶、垣燼砂。
- 部件：守垣甲片（肩甲位）。
- 殘頁：《垣門守式》殘頁（守位與化解向功法）。
- 任務道具：守垣將名冊殘頁（主線必掉）。

**戰鬥定位（機制難點，無數值）**

難點全在「守位」二字。他站在石台上時幾乎打不動，玩家必須用位移、引誘或控場把他拉離石台；而他的點名又逼玩家離開自己的安全位。整場戰鬥是「誰先離開自己的位置」的拉扯。

### 3.6 傳送連結

- 入口：煉虛期虛舟市，舟盟末航「牆根泊」，抵達南棧道。
- 回城：城門安檢口（完成節點一 A 簇後開啟）。
- 出口：北澤口，通往鏡我之澤（完成節點一 B 簇後開啟）。

## §4 圖二：鏡我之澤（94-96）

### 4.1 等級段與地貌尺寸

- 等級段：`realmLv 94-96`
- 地貌尺寸：約 110×110 格；淺澤與蘆洲交錯，澤心是一整片圓形靜水；澤的盡頭接白骨岸。
- 通關條件：在澤心擊敗鏡我，完成「澤心照我」。

### 4.2 風景特色（5 要點）

1. 鏡面淺澤：水面平得不像水，天光、蘆影、人影都照得清清楚楚，唯獨照不出魚。
2. 澤心圓湖：湖心無風，落葉不漂；水面像被人反覆打磨過。
3. 人臉浮萍：照心萍聚成人臉輪廓，風一吹散開，風一停又聚回原樣。
4. 白骨岸：澤的盡頭是層層疊疊的白骨灘，骨頭全朝同一個方向躺，像集體面向陵門。
5. 倒影不同步：走在澤邊，水裡那個「你」偶爾會慢半拍，或先一步轉頭。

### 4.3 植物與礦物（5 種）

| 名稱 | 外觀（一句） | 用途 |
|---|---|---|
| 鏡我蓮 | 水面如鏡的墨色睡蓮，花瓣背面是一種金屬灰 | 煉心寧丹、驅幻 |
| 照心萍 | 聚成人臉形狀的浮萍，風吹就散、風停又聚 | 製鏡與定神陣材 |
| 鏡鱗砂 | 澤底細砂，每一粒都有一個極小的反光面 | 打磨法器、書符 |
| 鏡心藕 | 澤底藕節，切開的斷面像一面鏡子，照出的不是藕紋 | 合丹、定神 |
| 垣根沉木 | 被牆根落石壓進澤底的沉木，木心還是乾的 | 製沉穩法器與船材 |

### 4.4 妖獸（5 種，鏡影系）

| 名稱 | 一句特色 |
|---|---|
| 鏡影 | 澤中映影走上岸的無面人形，會模仿路過者的步態 |
| 雙生獸 | 成對出現的水獸，殺其一，另一隻會變成牠的樣子 |
| 照心妖 | 貼在水底的影子，你低頭看水，它也在看你 |
| 拾面客 | 撿走溺者面容的舊人，臉上一層層貼著別人的臉 |
| 回聲蛙 | 叫聲是你自己的聲音，只是慢半拍 |

### 4.5 頭目：鏡我

**四問一·外型**

它和你一模一樣：衣著、兵器、站姿，全都是你這一世的樣子。只有材質不對，像用澤水塑出來的，動作時邊緣會晃出細波。它的動作比你慢半瞬，像一段記得不夠牢的回憶。細節處總有一點不同：腰間掛飾的形狀、手臂舊傷的位置、眼神落點的方向。它不主動開口；一開口，就是用你的聲音。

**四問二·特色（來歷與執念）**

澤心有一條死了的「鏡面法則」，凡走進澤心的人，都會被映出一個「以為的自己」。練氣期寒汐澤的「倒影反吞」是這條法則的殘漏，這裡是它的完整版。鏡我不是怨魂，也不是守關者；它只想確認一件事：走進澤心的這個人，是不是他自己。

- 與地圖的關係：整片澤是一面不願停下來的鏡子；鏡我是澤心的那一問。
- 台詞方向（至多一句）：用玩家的聲音，複述玩家進澤前對池照說過的話（「這句話，你剛才在外面也說過。」）。

**四問三·法術（4 個具名）**

| 法術 | 效果方向 | 對應地圖主題 |
|---|---|---|
| 照式 | 映照玩家上一輪用過的招式，以同樣的形式回敬 | 映影用你自己的招式 |
| 換面 | 把玩家身上的增益與減益狀態對調一瞬 | 鏡面翻轉 |
| 澤心問 | 澤面升起一圈鏡壁圍住玩家，鏡壁上的「你」同時舉起兵器，逼玩家選一個方向突破 | 澤心的那一問 |
| 碎鏡 | 低血階段，鏡我碎成滿澤碎片，每一片都是一個不同選擇的「你」；只有一個會流血 | 你以為的你 |

**四問四·掉落定向**

- 材料：鏡我蓮、照心萍、鏡鱗砂、鏡心藕。
- 部件：映心鏡（法器位）。
- 殘頁：《照心式》殘頁（以對手招式照見自己破綻的反制向功法）。

**鏡我機制意圖（敘事機制級設計，數值留實作層）**

- 敘事邏輯：映影不存在自己的招式庫。它的一切行動都從玩家身上「讀」來；玩家越是依賴一套固定的技能組傾向，它回敬得越順。玩家的習慣就是它的攻略，也是玩家的破綻。
- 機制意圖（只寫意圖，不寫數值）：
  1. 偏好對照：鏡我的行為向玩家的技能組傾向靠攏（偏攻、偏守、偏控、偏拖延，各有不同的映照方式）。
  2. 照見破綻：玩家在戰鬥中透過照式看清自己依賴什麼；擊敗鏡我不靠傷害堆疊，靠打破自己的慣性。
  3. 無背板：同一名玩家第二次進澤，映影也會「記得」他的上一次。
- 敘事用途：鏡我之戰是全遊戲第一次把「玩家自己」當成對手。它不奪走任何東西，只留下一句問。
- 與渡劫期「心魔鏡城」的呼應（只立方向，不展開渡劫內容）：合體期問的是「你以為的你」；渡劫期將要面對的是「你不願看的你」。兩者同源不同層，心魔鏡城的設計權屬渡劫隊，本隊不越界落任何心魔鏡城細節。

**戰鬥定位（機制難點，無數值）**

難點在「無法背板」。映影的節奏跟著玩家走，換血與站位都要臨場應變；打贏它的人，通常是先改變自己的人。

- 入口：垣門外壘北澤口。
- 回城：天垣城鏡巷側門（完成節點二 A 簇後開啟）。
- 出口：白骨岸陵門，通往法骸陵（完成節點二 A 簇後開啟）。

## §5 圖三：法骸陵（97-99）

### 5.1 等級段與地貌尺寸

- 等級段：`realmLv 97-99`
- 地貌尺寸：約 100×120 格；地陵主廊向牆根傾斜，兩側是晶柱墓室；陵心為最大的一塊名碑。
- 通關條件：擊敗葬法老人，取得《補天者名錄》拓文。

### 5.2 風景特色（5 要點）

1. 晶柱成陵：一柱一法，柱身半透，裡頭的光像沒寫完的字。
2. 無聲之地：全圖沒有環境音；技能聲與腳步聲都會被吃掉一半，只剩下自己的心跳。
3. 名碑長廊：主廊兩側立著補天者的名碑，碑上只有名字，沒有生平。
4. 紙灰袍影：四處飄著葬法燒剩的紙灰，落地不散，堆成低低的丘。
5. 陵頂裂光：陵頂一道細縫透下光來，光柱筆直，正好照在陵心那塊最大的名碑上。

### 5.5 頭目：葬法老人

**四問一·外型**

腰背駝得很深的老人，穿的是一件由紙灰與碑屑黏成的長袍。手裡提著一盞沒有火的燈，燈籠以「聲音」的碎片糊成。臉褶裡嵌著細細的晶脈，像陵中的柱紋長到了他身上。走路時腳下不揚塵，因為連塵的法則都埋在這兒了。

**四問二·特色（來歷與執念）**

他不是惡人。天地有法則死去，他負責收葬：一柱一法，一碑一名。他親手立起陵中每一根晶柱，也親手把每一個補天者的結局埋進去。他不反對人用法，他只是想知道，自己埋的東西有沒有白埋。

- 與地圖的關係：整座陵是他的葬場；陵中無聲，是因為「聲音」的法則也埋在這裡。
- 台詞方向（至多一句）：「這些法，你們還在用嗎？」

**四問三·法術（4 個具名）**

| 法術 | 效果方向 | 對應地圖主題 |
|---|---|---|
| 覆土 | 揚起葬法砂覆住目標，被覆住的招式暫時失效或延遲 | 埋法 |
| 立碑 | 在場上立起法骸晶柱，封鎖周邊方向的走位與施法 | 晶柱成陵 |
| 無聲界 | 把場地的聲音法則收走，場內提示與吟唱一併變窄 | 陵中無聲 |
| 收葬 | 低血階段把自己埋進地裡，化成一柱新碑；須先打碎「葬法老人之碑」，他才以殘身再起 | 把自己也埋進去 |

**四問四·掉落定向**

- 材料：法骸晶、啞陵草、葬法砂、法髓乳。
- 部件：無聲甲（衣甲位）。
- 殘頁：《葬法錄》殘頁（斂息與封禁向功法）。
- 任務道具：《補天者名錄》殘卷（主線必得）。

**戰鬥定位（機制難點，無數值）**

難點在「場地會變」。立碑封路加上無聲界，會把玩家的站位與技能節奏切碎；補師與吟唱向的修士尤其難受。正確解法是邊打邊清碑，而不是硬頂。

## §6 圖四：垣心之井（100-102）

### 6.1 等級段與地貌尺寸

- 等級段：`realmLv 100-102`
- 地貌尺寸：約 90×90 格；井道環形而下，井心石台在正中央；井口向上無頂。
- 通關條件：擊敗垣心守並完成「點名交材」儀式，取得第五片補天殘材。

### 6.2 風景特色（5 要點）

1. 豎井通天：井身粗得能塞進一座小山，往上看只有一線亮，越往上越亮。
2. 刻名之壁：井壁每一圈都刻著名字，字體一代與一代不同，越往上刻得越新。
3. 垣髓流金：牆體滲出的乳金色垣髓沿著刻痕往下淌，在井心積成一灘會發光的淺水。
4. 井道環繞：下井的路是一圈一圈的窄道，走一段要過一道斷口，斷口上架著前人留下的舊繩。
5. 井口天痕：站在井心抬頭，天痕像一道沒縫好的傷口橫在天空上，劫風從那裡吹下來。

### 6.3 植物與礦物（5 種）

| 名稱 | 外觀（一句） | 用途 |
|---|---|---|
| 井心苔 | 長在井壁刻名凹痕裡的青白苔，只順著字痕生長 | 續命丹、護脈 |
| 垣髓 | 牆體深處滲出的乳金色髓液，凝後如琥珀 | 合體期核心淬體材 |
| 垣口砂 | 從井口被劫風吹落、積在井底的細砂，摸起來是燙的 | 抗劫符材 |
| 垣絡藤 | 沿井壁攀生的鐵色老藤，結節如指節 | 製索、攀具 |
| 垣名墨 | 井底積著歷代刻名落下的石粉，混水成墨 | 書符、拓印 |

### 6.4 妖獸（6 種，垣石系）

| 名稱 | 一句特色 |
|---|---|
| 井守 | 貼在井壁上的石甲守衛，一生沒有下過井 |
| 攀壁妖 | 背著上一個攀井者遺骸的爬行妖，往上爬一步就往下滑半步 |
| 井底獸 | 井底暗處的巨大者，只以井口落下來的東西為食 |
| 名縫蟲 | 住進名刻凹痕裡的小蟲，會啃掉筆畫 |
| 落名傀 | 由歷代沒刻完的名字聚成的殘影，見人就伸出一隻手要筆 |
| 垣髓蛾 | 被垣髓光吸引的灰蛾群，翅粉沾到皮膚會發癢 |

### 6.5 頭目：垣心守

**四問一·外型**

一個蹲坐在井心平台上的高大身影，全身被厚厚的垣髓結殼包住，像一根立在井心的鐘乳。結殼縫裡透出極細的光，光隨著他的呼吸一明一暗。他的雙眼已經被結殼封死，卻準確地朝著你的方向。手中橫著一根斷了的井繩，繩上還串著幾枚舊名牌。他不站起來。他一站起來，井就要晃。

**四問二·特色（來歷與執念）**

守井大能的餘身。當年補天者最後一次登井，他在井底守著；上面的人再也沒有回來。他守的不是寶物，是「放行」這兩個字：放行必須問一句話，答不出來，誰也別想上去。他與井的關係，如同守垣將與門的關係：一個守門，一個守路，兩個人都守到沒有人可守。

- 與地圖的關係：井壁的名字由他看顧，井心的殘材由他看守。
- 台詞方向（至多一句）：「你上去，是替誰看？」

**四問三·法術（4 個具名）**

| 法術 | 效果方向 | 對應地圖主題 |
|---|---|---|
| 垂繩 | 斷裂的井繩如蛇散開，纏住玩家的移動軸線，把人拉回井壁 | 井道與舊繩 |
| 井晃 | 他撐起半身，豎井震動，井壁刻名同時亮起壓向場中每一位 | 一站起來井就要晃 |
| 點名過井 | 念出井壁上的名字，被念到的補天者殘影出列應戰 | 井壁刻名 |
| 封口 | 低血階段，他將井口的光收進自己的結殼，全場陷入黑暗，只剩他身上那點一明一暗的光在移動 | 井口與天痕 |

**四問四·掉落定向**

- 材料：井心苔、垣髓、垣口砂、垣名墨。
- 部件：守井人殘繩（飾品位）。
- 殘頁：《守井樁》殘頁（站樁與化解向功法）。
- 主線交付：第五片補天殘材（完成點名交材儀式後由垣心守放行取得，非隨機掉落）。

**戰鬥定位（機制難點，無數值）**

難點在「視野與位移」。垂繩把人拉回井壁，井晃逼人移動，封口之後全場只剩他身上一明一暗的光。玩家要在看不見的井裡，跟著那一點光打完最後一段。他先驗你，後放行；這一戰不是為了殺他，是為了讓他放心。

- 出口：登井後自關樓側門回城，再由關樓出關，通大乘期劫風口。

## §9 與前後境界的敘事接縫

### 9.1 前接煉虛

- 舟盟航線順著界隙的裂走到盡頭，撞上的不是虛無，是牆根。舟盟有一句老話：「船到牆根就回頭。」玩家是第一個不回頭的人。
- 無光老祖聽了一輩子的「裂那邊」，原來是牆的背面；這層認知在合體期落地，但不展開解釋。
- 玩家帶著第四片補天殘材上岸，殘材在過牆根時會有輕微的共鳴，這是補天料的呼應，不給出更多資訊。

### 9.2 後開大乘

- 天垣城關樓之外即是劫風口（大乘期 103-105），天痕在井口就已經望見，到了大乘才輪到「看懂症狀」。
- 留痕一·垣衛的調令：節點三收束後，霍守拙依點名舊例簽發「輪戍」調令副卷，命玩家將副本送往鎮涯關備檔；大乘期守望者認得垣衛的印。
- 留痕二·法骸陵殘卷流出：崔醒抄錄的《補天者名錄》副本隨玩家下行；大乘期清點七次補天失敗遺址時，守望者會引用這份名錄。
- 留痕三·人的口述：關復城講述的外壘舊事（哪一年補過哪一段牆、哪一年沒補上），會被往來商旅帶到下一個關口。

### 9.3 被引用的可能性

本境界的後續引用一律以「痕跡」形式出現，不主動替大乘隊補設定：垣衛名籍、輪戍調令、名錄殘卷、照心鏡、第五片殘材。其餘細節留白。
