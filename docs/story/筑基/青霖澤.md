# 青霖澤

青霖澤位於霜刃淵寒鐵側洞之外。地下寒流離開石壁後漫成淺澤，岸邊古木與水草吸住終年不散的雨氣，形成一片木水交纏的築基中期險地。霜刃淵斥候修補了連接兩地的古石棧橋，修士可由側洞東口進入，也能沿原路返回；這條支線不取代霜刃淵通往焚木荒臺的主路。

## 地形與路線

入口位於西側青霖石棧橋。古石棧橋跨過數條水道，先連到北面的蘭雨岸，再經中央泥澤抵達南面的沉礦脊。東北露網汊盤踞凝露蛛母，東南老根島則由盤根泥魈把守。石堤最後分成兩岔，夾住東側蛟眠深潭，青霖蛟主會在潭前截斷去路。

地圖以水、草、泥、沼四種底層交錯，大片泥岸與沿水沼帶打破重複紋理，古石鋪面跨過不可通行水域。採集岸、礦脊、兩處精英區、入口與頭目潭皆在同一可行走網路內；水島之間沒有只能觀看而無法抵達的孤立區域。

## 採集與製作閉環

蘭雨岸與南部泥洲可採青霖蘭、澤心苓；沉礦脊和東側潭岸可挖碧紋銅礦、沉水玉砂。雨蜥鱗、澤螯殼由一般或精英妖物提供，青霖妖丹由蛟主穩定掉落。七種材料都進入青霖澤專屬配方：六件玄階三十七級武防各有一張煉器方，青霖回元丹與凝露養脈丹各有一張煉丹方。

兩件武器分別支援物理與法術路線，防具覆蓋頭、身、腿、飾四槽。青霖回元丹立即回覆靈力並提高靈力回覆，凝露養脈丹立即回覆生命並提高生命回覆。青霖澤圖卷由霜刃淵的探淵斥候販售，使用後永久解鎖本地圖。

## 數值定位

青霖澤以三十五級玩家最終屬性基線，加上一把三十七級玄階武器和四件同階防具校準。三十七級裝備對三十五級玩家套用既有境界效能後為百分之九十點二五。真傷害管線抽樣的歸一化普攻機會約為：普通怪九至十五次、精英二十九至四十五次、頭目七十至八十八次。抽樣含隨機誤差；此數字不是實際秒數，沒有計入走位、技能輪替、控制、延遲、丹藥與操作空窗。

青霖蛟主的平均普攻約為三十五級玩家生命的百分之四點五；兩個預警招單次命中的平均傷害約介於百分之九至十二。其生命與攻擊都低於四十三級金丹支線頭目幻靈真人的五分之一，保留築基至金丹的境界差距。
