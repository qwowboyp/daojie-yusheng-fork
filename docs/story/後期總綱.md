### 1.2 世界分層（後期核心）

凡人篇看到的是「鎮」，練氣期看到的是「帶」（五行錯層帶），築基期看到的是「臺」（雲墟臺）。

從金丹期開始，玩家逐層向上看見世界的**傷口**：

```
雲來鎮（村鎮）
  → 五行錯層帶（天穹殘宮墜落砸出的地脈裂帶）
    → 劫火餘溫帶（天外墜物燒出的焦帶——金丹）
      → 劫潮海（吞掉半座天穹殘宮的海——元嬰）
        → 天涯崖階（世界的邊——化神）
          → 界隙（世界與世界之間的裂縫——煉虛）
            → 天垣（人為築起的擋劫之牆——合體）
              → 天痕（天空上的裂口本體——大乘）
                → 飛昇台（舊仙界通道的殘址——渡劫/飛昇）
```

### 1.3 道劫真相：七層揭示表

道劫＝上古一次「開天門」（仙界通道開啟）的失敗。失敗的餘波砸落人間，是為道劫。天穹殘宮是上一次嘗試的渡台，宮主是那一次的守門人。真相按境界分七層揭開，**前一層永遠只夠解釋眼前，不夠解釋全部**：

| 境界 | 玩家知道的 | 仍不知道的 |
|---|---|---|
| 金丹 | 天穹殘宮不是唯一從天上掉下來的東西 | 誰把它們砸下來 |
| 元嬰 | 劫潮裡有「舊世界的聲音」，劫有源頭 | 源頭在哪 |
| 化神 | 世界有邊，邊外有「天痕」 | 天痕是什麼 |
| 煉虛 | 世界之外還有世界碎片，劫從界隙漏入 | 牆是誰築的 |
| 合體 | 天垣是人為的擋劫之牆，牆後是真相 | 補天計畫為何失敗 |
| 大乘 | 天痕是舊天門的傷口，劫風雷罰皆是症狀 | 能不能補 |
| 渡劫/飛昇 | 道劫全貌；七片殘材合璧可重開天門 | 上去之後是什麼 |

### 1.4 貫穿母題：「涯」

天穹宮主留下的半句遺言與「涯」字有關（`凡人/chapter-06-liu-bai.md` 已鋪）。各境界對「涯」的理解遞進：

- 金丹：匠修說「涯」是老坊志裡的古地名，指的是劫火帶的盡頭。
- 元嬰：潮裡的聲音拖著一個音，像「涯」。
- 化神：玩家**親眼望見**天涯——世界的邊緣。
- 合體：涯外之涯——牆後還有一道涯。
- 渡劫：涯＝天門檻。跨過涯，就是飛昇。

### 1.5 跨境界主線道具：補天殘片

練氣期收的是「五行精粹殘片」（5 片）。後期對稱：**每一境界的圖末各得 1 片「補天殘材」**，共 7 片，是重開天門的七塊拼圖，也是補天一脈七次失敗的遺證。七片合璧在飛昇終章。

### 4.1 金丹期（43-54）— 劫火餘溫帶

**境界主題段**：天穹殘宮不是唯一掉下來的東西。三十年前起，劫火帶上開始「落星」——天外墜物燒穿山嶺，餘火百年不熄。修士與匠戶沿火帶而居，靠劫火鍛體、憑隕鐵煉器，燼燈坊因此而生。金丹修士的「內景」需要一種人間火燒不出的熱——劫火是唯一選擇。本境界主線《補天爐下》：追查隕鐵來源 → 揭出補天一脈重鑄天空的失敗史 → 取得第一片補天殘材。

### 4.2 元嬰期（55-66）— 劫潮海

**境界主題段**：隕落物不只砸在地上。半座天穹殘宮當年沉進了大海，海水從此記住了它——潮起時，整片海會重播舊世界的聲音。元嬰修士神識可離體，第一次聽懂了潮裡的東西：那不是雜音，是「話」。本境界主線《潮裡的聲音》：錄聲尋源 → 沉鐘現世 → 殘片在潮裡發聲 → 循聲入海眼。

### 4.3 化神期（67-78）— 天涯崖階

**境界主題段**：劫潮之上，霧散處是一道望不到頂的崖——那不是山，是世界的邊。化神修士神魂與天地相感，第一次「感覺」到天地的形狀：它有邊。本境界主線《望涯》：登崖會求「上看一眼」，古觀星台記錄了前人的答案——天外有「天痕」。玩家在此親眼見涯，「涯」字第一次有了實體。

| **律動雷原** | 70-72 | 有韻律的雷 | 崖腰草原，雷暴按某種說不清的韻律落下；當地人稱「天在數拍子」 | 律雷晶、聽雷草 | 司律獸、雷符鴉 | **司律雷君**——能背出所有雷的間隔，卻不知誰在打拍子 |

### 4.4 煉虛期（79-90）— 界隙

**境界主題段**：天涯的盡頭不是虛無，是裂縫——界隙。世界與世界之間有薄如蟬翼的夾縫，夾縫裡漂著別的世界碎下來的地方。煉虛修士能以身入隙，於是有了舟盟：以巨舟航行界隙的商旅與拾荒者。本境界主線《界隙行舟》：舟盟雇傭 → 虛獸洄游斷航 → 星骸港的秘密 → 界隙深處看見「劫從外來」的證據。

|---|---|---|---|---|---|---|
| **碎界灘** | 79-81 | 世界的碎屑 | 界隙灘地，腳下混雜著別處的瓦、別處的樹、別處不知名的骨 | 碎界砂、異壤（不屬於此界的土） | 拾荒妖、界屑蟲 | **拾界人**——撿了一輩子別人世界的碎片，想拼出「家」 |

### 4.5 合體期（91-102）— 天垣

**境界主題段**：界隙深處的盡頭，是一道牆。不是崖，不是山——是牆，有人築的。牆上有一道門，門後無人知。合體修士天人合一，第一次觸到了這道牆的「意圖」：它在擋什麼。本境界主線《垣門》：垣衛的規矩 → 鏡我之澤的自我審問 → 法骸陵看見歷代「補天者」的結局 → 垣心之井望見天痕。

### 4.6 大乘期（103-114）— 天痕之下

**境界主題段**：井口之外，天空上橫著一道裂——天痕。劫風從痕裡吹下來，雷罰從痕裡落下來，劫獸從痕裡爬下來。人間絕巔的修士在此明白：自己不是最強的，是**最後一排**。本境界主線《守關》：鎮涯關守望 → 清點七次補天失敗的遺址 → 殘片合鳴 → 天痕使現身，說出「上面」的第一句話。

**境界主題段**：最後的城叫薪火城。相傳每一次道劫前夜，都有人把一簇火留在人間——火種不斷，人族就能重來。渡劫修士面對的是自己的三劫：雷劫、心魔劫、天人劫。本境界主線《薪火》：三劫備戰 → 心魔鏡城中與「心中我」了斷 → 天人五衰崖上確認最後一願 → 登飛昇台。

### 4.8 飛昇終章（127）— 天門遺址

非刷圖，是終章儀式序列（任務＋場景演出）：

1. 七片殘材合璧於飛昇台；薪火城全城熄燈，只留薪火。
2. 天門（舊仙界通道）自天痕中重開——真相全貌在此揭曉：道劫＝上一次開天門的失敗；天穹殘宮＝上一次的渡台；宮主＝上一次的守門人。

4. 結局收束在「上去之後是什麼」的留白——為未來版本留門，不寫死。

## 5. 頭目設計規格（全體通用）

每張圖的頭目必須包含：

1. **名號**（總綱已定，不得改）
2. **外型**：3-5 句，具體到身形、材質、穿戴、異相；避免「很強很猛」的空話。
3. **特色**：他的來歷、執念、與地圖的關係；一句可引用的台詞方向。
4. **法術攻擊**：3-4 個**具名**法術，每個註明效果方向（傷害/控制/召喚/環境）；機制上要能體現地圖主題。
5. **掉落定向**：殘材/功法殘頁/裝備部件/材料，指向該境界的成長線。
6. **戰鬥定位**：數值口徑交給實作層，文檔只寫「機制上的難點」。

**頭目命名稱謂規則**（修仙階梯）：金丹＝真人/匠/姥姥；元嬰＝真君/客/魃；化神＝尊者/君/瞽者；煉虛＝老祖/傀儡/母獸；合體＝大能/將/老人；大乘＝大士/使/王；渡劫＝準仙/守/法身。**不得越級使用高階稱謂**（如元嬰圖不得出現「老祖」）。

**妖獸家族基調**（每圖 4-6 種普通妖獸，由各隊展開，家族基調不得串用）：
金丹＝灰燼/熔渣/爐火系；元嬰＝潮聲/海骨/沉沒系；化神＝風雷/石階/星砂系；煉虛＝界屑/虛空/無光系；合體＝鏡影/法晶/垣石系；大乘＝劫風/雷罰/獸潮系；渡劫＝劫雲/雷液/心魔系。

**植物／礦物命名**：每圖 3-5 種，命名帶該境界家族字（金丹＝燼/燈/琉璃/劫鐵；元嬰＝聲/潮/沉/月；化神＝律/階/星/風；煉虛＝隙/骸/光；合體＝垣/鏡/法；大乘＝劫/罰/潮/痕；渡劫＝劫/雷/心/衰/薪），避免與既有 40 圖材料撞名。

## 7. 敘事紅線（承接既有）

1. 不設一語道破的總答案；每個 NPC 只知道自己那一層。
2. 世界不毀滅，秩序勉強運轉；寫「劫餘」的堅韌，不寫末世。
3. 玩家不是唯一主角；多數玩家默認共存。
4. 反派多有「修壞了的人」底色（承接練氣五失控者口徑），非臉譜化邪惡。
5. 文案繁體（台灣用語），地名/功法/材料命名遵循 §5 家族規則。
6. 不搬用任何既有小說的專有名詞。
7. 頭目台詞最多一句「記得住但聽不完全懂」的話，禁止長篇獨白揭秘。
